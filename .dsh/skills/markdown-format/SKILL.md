仓库里每一个 markdown 文件都按 `STYLES.md` 的版式写
本技能给出检查与批量调整的手段

## 何时用

(1) 新建任何 markdown 之前, 先读仓库根目录的 `STYLES.md`
(2) 写完一篇之后, 走本技能「自检流程」一节, 四步都要过
(3) 旧笔记整批整理格式, 先跑 `scripts/reflow.py`, 再走自检流程
(4) 用户说格式乱了, 或说按规范过一遍, 也走这里

## 检查什么

| 项 | 要求 |
| --- | --- |
| 标点 | 无全角标点, 无顿号, 无破折号 |
| 行 | 一行一句, 不超过 60 字符, 中文与公式之间有空格 |
| 空行 | 开头无空行, 无连续空行 |
| 分隔线 | 不出现 `------` `***` `---` |
| 标题 | 只有一个 `#`, 后续 `##` `###`, 不跳级 |
| 目录 | 紧跟标题, 与 `##` `###` 一一对应 |
| 公式 | 含等号或不等号的式子用 `$$` 独行, 其余用单个 `$` |
| 公式渲染 | 定界符配对, 不被换行切断, 不用 `\(` `\)` |
| 代码 | 三个反引号围栏并标语言 |
| 例题 | `例N-M:` 起头, `解:` 或 `证明:` 另起一行, 不用引用块 |
| 表格 | 表题在表上方, 单元格竖线转义 |
| 图片 | 空占位 `![图N-M]()`, 编号连续 |
| 强调 | 无加粗, 无斜体, 无 emoji |

## 自检流程

写完或改完一篇, 按顺序做四步

1 跑 `scripts/check_style.py`, 要全 0 问题
2 看它报的 `公式未闭合` 与 `裸 LaTeX` 两项, 这两项说明公式渲染不出来
3 打开文件读一遍公式, 每行 `$` 必须成对, 行内公式不能跨行
4 在 Obsidian 里打开, 确认公式显示为排版好的样子, 而不是一段 `\dfrac` 原文

前两步是脚本能查的, 后两步要看一眼
第 4 步不能省, 因为公式只有在渲染器里才看得出好坏

## 检查脚本

```text
python .dsh/skills/markdown-format/scripts/check_style.py 笔记.md
python .dsh/skills/markdown-format/scripts/check_style.py 目录
```

逐项输出计数, 全部为 0 才算通过
给出 `FAIL` 的项, 按 `STYLES.md` 对应小节逐条改

脚本能查的公式问题
- `公式未闭合`: 同一行 `$` 个数为奇数, 行内公式被换行切断
- `裸 LaTeX`: 行里有 `\dfrac` 这类命令但没有 `$`, 公式不会渲染

`$$` 跨多行的显示块不算错, 脚本会自己在块内跳过

## 批量调整脚本

```text
python .dsh/skills/markdown-format/scripts/reflow.py 笔记.md
python .dsh/skills/markdown-format/scripts/reflow.py 目录 --write
```

不加 `--write` 只做演练, 打印将要改动的条数
脚本处理的是机械部分: 去开头空行, 删分隔线, 压连续空行, 去引用块前缀
标题降级并补一级标题, 生成目录, 去掉加粗, 中文与公式之间补空格
把独行的含等号公式包成 `$$`

断长句时避开三处, 反引号里的代码, `$` 里的公式, 以 `](` 出现的链接
改完照样要走自检流程

脚本不做的事, 留给人判断
(1) 表格单元格内容
(2) 代码块里的内容
(3) 句子里夹带的含等号公式要不要提到独行

## 注意

(1) 只改格式, 不改意思. 措辞, 顺序, 结论一律不动
(2) 带 YAML frontmatter 的文件 (例如各技能的 `SKILL.md`) 不要整篇跑 `reflow.py`
(3) 断行最容易切坏公式与代码, 改完必须看 `check_style.py` 的公式两项
(4) 拿不准的保持原样, 在报告里列出来

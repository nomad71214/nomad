## 定义

数列是按正整数编号排列的一列数, 记作 $\{a_n\}$

数列的极限
设 $\{a_n\}$ 是数列, $a$ 是常数
若对任意 $\epsilon>0$, 存在正整数 $N$
当 $n>N$ 时都有 $|a_n-a|<\epsilon$
则称 $a$ 是 $\{a_n\}$ 的极限, 记作

$$\lim_{n\to\infty}a_n=a$$

[$\epsilon$ 是允许的误差, $N$ 由 $\epsilon$ 决定
先给 $\epsilon$ 再找 $N$]

常用数列的极限列在表 1-1

表1-1 常用极限 ($n\to\infty$)

| 数列              | 极限 |
| ----------------- | ---- |
| $\dfrac{1}{n}$    | $0$  |
| $q^n$ $(|q|<1)$   | $0$  |
| $\sqrt[n]{n}$     | $1$  |

## 例题

例1-1: 用定义证明 $\lim_{n\to\infty}\dfrac{1}{n}=0$

解: 任给 $\epsilon>0$
取 $N=\left\lfloor\dfrac{1}{\epsilon}\right\rfloor+1$
当 $n>N$ 时, 有 $0<\dfrac{1}{n}<\dfrac{1}{N}<\epsilon$
即 $\left|\dfrac{1}{n}-0\right|<\epsilon$
故 $\lim_{n\to\infty}\dfrac{1}{n}=0$

## 2.1 四种数值类型

Python 的数值类型包括整数 `int`, 浮点数 `float`,
复数 `complex` 和布尔数 `bool`;
其中 `bool` 是 `int` 的特例(`True` 即 1, `False` 即 0)

(1) 转换函数: `int(x)`, `float(x)`, `complex(x)`, `bool(x)`,
字符串两端空白会被自动忽略
(2) 整数常量四种进制: 十进制 `123`; 二进制 `0b101`; 八进制 `0o35`
十六进制 `0xFA`
(3) 整数无位数上限, 可表示任意大数值(自动扩展精度)
(4) `bool`: 非 0 数值, 非空字符串为 `True`; `0`, `0.0`, `0j`, `''`,
`None` 为 `False`. 注意 `bool('0')` 是 `True`(非空字符串)
(5) 浮点常量: 小数形式 `3.14`, `10.`, `.001`; 科学计数法 `1e-6`
`3.14e-10`
(6) 复数常量: `3+4j`, `1.1-2.2j`, `4j`; 错误写法 `j`(未定义),
`4*j`(`*` 不能省略)
(7) 复数属性: `c.real` 实部, `c.imag` 虚部, `c.conjugate()` 共轭复数

```python
print(int(3.14), int(' 123 '))     # 3 123，字符串空白被忽略
print(float(3), float(' 3.14 '))   # 3.0 3.14
print(complex(1.2))                # (1.2+0j)
print(bool(1.2), bool(0), bool('0'))   # True False True

c = 8 + 10j
print(c.real, c.imag, c.conjugate())   # 8.0 10.0 (8-10j)
```

[注意] 浮点数是有限精度的二进制表示, `0.1 + 0.1 + 0.1 == 0.3` 结果为 `False`.
判断浮点相等要用容差: `abs(a - 0.3) < 1e-6`

## 2.2 算术运算符

算术运算符完成数值计算, 其中 `/` 是真除(结果必为浮点数), `//` 是整除(向下取整), `%` 是求余,
`**` 是幂运算

表2-1 算术运算符 (Python 3)

| 运算符 | 说明 | 示例 |
| --- | --- | --- |
| `+` `-` | 加, 减(双目); 取正, 取负(单目) | `35+4`, `-c` |
| `*` | 乘法, 不能省略 | `(35+4)*5` |
| `/` | 真除, 结果一定是浮点数 | `4/2 → 2.0`, `5/2 → 2.5` |
| `//` | 整除, 结果向下取整 | `5//2 → 2`, `-5//2 → -3` |
| `**` | 幂运算, 右结合 | `4**0.5 → 2.0`, `2**2**3 → 256` |
| `%` | 取余, 余数符号跟随除数 | `20%3 → 2`, `-20%3 → 1`(余数≥0), `2.3%2.2 → 0.1` |

(1) 复合赋值运算符: `+= -= *= /= //= **= %=`
1. 语义: `a θ= b` 等价于 `a = a θ (b)`
2. 注意 `a /= 6` 结果是浮点数(真除), `a //= 6` 结果是整数
(2) 混合运算类型提升: 含 `complex` → 结果为 `complex`;
否则含 `float` → 结果为 `float`; 否则为 `int`

```python
a = (3*4+5)*6   # 102
a //= 6         # 整除 → 17（int）
a **= 2         # 289
a %= 3          # 1

print(2 + 2.0)          # 4.0，int 与 float 混合运算提升为 float
print((1+2j) + 3)       # (4+2j)，含 complex 则提升为 complex
```

[注意] `//` 是向下取整而非向零取整: `-5//2` 得 `-3`(不是 `-2`);
`-20%3` 得 `1`(不是 `-2`)

[注意] `**` 是右结合, `2**2**3` 是 `2**(2**3)=256`
不是 `(2**2)**3=64`

## 2.3 运算符优先级与结合性

同一表达式中按优先级由高到低求值, 同级运算符从左向右计算; 括号 `()` 可改变运算顺序且可嵌套

(1) 算术内部优先级: `+ -`(双目)< `* / // %` < `+ -`(单目)< `**`
(2) 总体优先级(低 → 高): 赋值运算符 < `or` < `and` < `not` < 比较运算符 <
算术运算符
(3) 例: `3-4**2+10%5+8*6//7` → `3-16+0+48//7` → `-13+6` =
`-7`
(4) 比较运算符可连用, 但无传递性, 只比较相邻两项: `x<y<z` 意为 `x<y and y<z`;
`x<y>z` 意为 `x<y and y>z`

```python
year = 2020
# 优先级：算术 > 比较 > not > and > or；同时依赖 and/or 的短路特性
leap = year % 4 == 0 and year % 100 != 0 or year % 400 == 0
print(leap)    # True

x, y, z = 12, 18, 13
print(x < y < z)   # False（等价于 x<y and y<z）
print(x < y > z)   # True （等价于 x<y and y>z）
```

## 2.4 比较运算与逻辑运算

比较运算比较两个对象的值并返回 `bool`; 逻辑运算 `and / or / not` 组合多个条件,
并具有短路求值特性

(1) 比较: `< <= > >= == !=`, 可用于数值, 字符串, 列表, 元组, 集合等
(2) `==` 比较值是否相等, `is` 比较是否为同一对象(地址) ,  两者不可混用
(3) `and`: 两侧都为真才为真; 左侧为假时不再计算右侧(短路)
(4) `or`: 两侧都为假才为假; 左侧为真时不再计算右侧(短路)
(5) `not`: 取反; `i != 0` 与 `not i == 0` 等价
(6) 短路是防止运行时错误的常用手段, 如 `i != 0 and j/i > 3` 可避免除零

```python
i, j = 0, 5
print(i != 0 and j/i > 3)   # False，且不会计算 j/i，避免除零错误
ans = 'Y'
print(ans == 'Y' or ans == 'y')   # True，右侧被短路，不再计算
```

## 2.5 模块的导入与使用

模块是函数/类/常量的集合; Python 启动时只加载少量内置模块, 其余需显式 `import`,
以减小运行压力并保持可扩展性

(1) `import 模块名 [as 别名]` → 通过 `模块名.对象名` / `别名.对象名` 访问
(2) `from 模块名 import 对象名 [as 别名]` → 直接使用对象名, 减少属性查找, 速度更快
(3) 一条语句可导入多个模块: `import sys, math`
(4) 导入顺序约定: 标准库(`os`, `sys`, `re`)→ 第三方库(`numpy`,
`scipy`)→ 本地模块; 一般放在程序开头
(5) `sys.modules.items()` 可查看所有已预加载模块
(6) `pip` 是安装/管理扩展模块的工具

```python
import math
print(math.pi)              # 3.141592653589793，模块名.对象名

import random as rnd       # 起别名
print(rnd.random())        # [0,1) 之间的随机小数

from math import sin as f  # 只导入单个对象
print(f(3))                # 等价于 math.sin(3)
```

## 2.6 应用案例: 整数分解与公式计算

应用场景: 从键盘读入一个数, 用整除与取余拆出各位数字; 或用 `eval()` 一次读入多个数值参与数学公式计算

```python
x = int(input('Enter a three-digit number: '))   # 如输入 357
hundred = x // 100          # 357//100 = 3，百位
ten = x // 10 % 10          # 357//10=35，35%10=5，十位
unit = x % 10               # 357%10 = 7，个位
print(hundred, ten, unit)

# eval() 把字符串当表达式执行，可一次为多个变量赋值
a, b, sita = eval(input('Enter 2 sides and angle: '))   # 输入 3,4,90
```

[注意] `eval()` 会把输入当代码执行, 只适用于可信输入;
且输入格式必须与目标一致(`3,4,90` 对应三个变量, `eval` 后是元组)

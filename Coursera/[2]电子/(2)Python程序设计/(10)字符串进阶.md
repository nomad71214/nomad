## 本章要点

- str 是内置类, 方法挂在字符串对象上, string 模块只提供常量
- 检验方法看整串, 有一个字符不合格就为 False, 空串也是 False
- split 与 join 互逆, partition 固定切成三段元组
- strip 的参数是字符集合, 删的是两端出现的这些字符
- find 找不到返回 -1, index 找不到抛 ValueError

## 10.1 str 与 string 模块

str 是内置模块 builtins 里的类, 字符串方法都定义在它上面, 直接可用
string 是另一个模块, 只提供常用字符常量, 用前要 import

规则10-1 `str` 是内置类, `'abc'.upper()` 这类方法不用导入就能调用
规则10-2 `string` 是模块, 提供 `digits` `ascii_letters` 等常量
规则10-3 `string.printable` 含数字, 字母, 标点与空白符, 共 100 个
规则10-4 判断字符类别可用 `c in string.digits`, 也可用 `c.isdigit()`

表10-1 string 模块的常用常量

| 常量 | 内容 |
| --- | --- |
| `digits` | `0123456789` |
| `ascii_lowercase` | 26 个小写字母 |
| `ascii_uppercase` | 26 个大写字母 |
| `ascii_letters` | 大小写字母共 52 个 |
| `punctuation` | 32 个 ASCII 标点 |
| `printable` | 数字, 字母, 标点, 空白 |

例10-1: 打印常量的长度与内容, 看字母表有多少个字符
解: `digits` 与 `ascii_letters` 的长度直接由 `len` 得到

```python
import string
print(len(string.digits), string.digits, '|', len(string.ascii_letters))
```
输出: 10 0123456789 | 52

例10-2: 用字符常量与 `isalnum` 两种办法检验同一个字符
解: 两种办法结果一致, 下划线属于标点, 两处都判为假

```python
import string
chars = string.ascii_letters + string.digits
print([(c in chars, c.isalnum()) for c in 'A7_'])
```
输出: [(True, True), (True, True), (False, False)]

## 10.2 检验与转换

检验方法回答"整串是不是都由某一类字符组成", 只看成分不看长度
转换方法一律返回新串, 原串一个字都不改

规则10-5 `isalpha` 全为字母才真, `isdigit` 全为数字字符才真
规则10-6 `isalnum` 字母或数字, 出现空格与标点即为假
规则10-7 `isspace` 全为空白符才真, 空串对六个检验方法都是假
规则10-8 `isupper` 与 `islower` 要求至少有一个字母, 数字不干扰
规则10-9 `lower` `upper` `capitalize` `title` `swapcase` 返回新串
规则10-10 `capitalize` 只改首字符, `title` 改每个单词的首字母
规则10-11 `ord(c)` 取字符编码, `chr(n)` 由编码取字符, 两者互逆
规则10-12 大小写字母相差 32, 可用 `chr(ord(c) - 32)` 手写转换

表10-2 六个检验方法

| 方法 | 为真的条件 | 例子 |
| --- | --- | --- |
| `isalpha` | 全是字母 | `'abc'` |
| `isdigit` | 全是数字字符 | `'123'` |
| `isalnum` | 全是字母或数字 | `'ab12'` |
| `isspace` | 全是空白符 | `' \t\n'` |
| `isupper` | 有大写字母, 无小写 | `'AB1'` |
| `islower` | 有小写字母, 无大写 | `'ab1'` |

例10-3: 对同一批字符串调用 `isalnum` 与 `isalpha`
解: 小数点不算数字字符, 空串与全空白串一律为假

```python
tests = ['1234abcd', '1234.0', 'ABC', '']
print([t.isalnum() for t in tests], '1234abcd'.isalpha())
```
输出: [True, False, True, False] False

例10-4: 五个转换函数作用在同一个串上, 末尾再打印原串
解: 每个方法都返回新串, `s` 始终是 `hi YOU`

```python
s = 'hi YOU'
print(s.lower(), s.upper(), s.capitalize(), s.title(), s.swapcase(), s, sep='|')
```
输出: hi you|HI YOU|Hi you|Hi You|HI you|hi YOU

例10-5: 用 `ord` 与 `chr` 看大小写字母的编码差
解: 小写字母的编码比对应的大写字母大 32

```python
print(ord('a'), ord('A'), ord('a') - ord('A'), chr(97), chr(65))
```
输出: 97 65 32 a A

## 10.3 分割与连接

split 把整串切成列表, join 把列表拼回整串, 两者互为逆运算
partition 不按次数切, 它固定返回"前, 分隔符, 后"三段

规则10-13 `s.split(sep)` 按 sep 切分, sep 本身不出现在结果里
规则10-14 sep 省略时按任意空白符切, 连续空白算一个, 两端丢掉
规则10-15 `maxsplit` 限制切分次数, 剩下的整块留在最后一个元素
规则10-16 `rsplit` 从右往左切, 只有次数不够时与 split 不同
规则10-17 `sep.join(iterable)` 用 sep 连接元素, 与 split 互逆
规则10-18 `join` 只收一个参数, 元素必须都是 str, 否则抛异常
规则10-19 `partition(sep)` 返回三元组, 找不到得到 `(原串, '', '')`
规则10-20 `rpartition(sep)` 从右找, 找不到得到 `('', '', 原串)`

例10-6: 按逗号切分并限制次数, 再按空白切分
解: 只切一次时剩下的整块保留, 连续空白只算一个分隔

```python
s = 'a,b,c'
t = 'a  b'
print(s.split(','), s.split(',', 1), s.rsplit(',', 1), t.split())
```
输出: ['a', 'b', 'c'] ['a', 'b,c'] ['a,b', 'c'] ['a', 'b']

例10-7: `join` 的几种用法, 分隔符换成不同的串
解: `s.join(t)` 用 `ABC` 逐字分隔 `xyz`, 得到 `xABCyABCz`

```python
s, t = 'ABC', 'xyz'
print(s.join(t), t.join(s), ''.join([s, t]), '-'.join([s, t, s, t]), ' '.join(s), '*'.join(t), sep='|')
```
输出: xABCyABCz|AxyzBxyzC|ABCxyz|ABC-xyz-ABC-xyz|A B C|x*y*z

例10-8: 用 `join` 与推导式删除非字母数字的字符
解: 先筛出要保留的字符放进列表, 一次拼接比反复用 + 更快

```python
def delchar(s):
    return ''.join([c for c in s if c.isalnum()])

print(repr(delchar('a-b c!d2')), repr(delchar('--')))
```
输出: 'abcd2' ''

例10-9: `partition` 与 `rpartition` 的三种情形
解: 分隔符在串里时三段都非空, 不在时必有一段是空串

```python
s = 'a,b,c'
print(s.partition(','), s.rpartition(','), s.partition('x'))
```
输出: ('a', ',', 'b,c') ('a,b', ',', 'c') ('a,b,c', '', '')

## 10.4 消减

strip 系列只删两端, 不删中间, 参数是字符集合而不是子串

规则10-21 `strip()` 省略参数时删两端空白, 含空格, 制表, 换行
规则10-22 `strip(chars)` 的参数是字符集合, 两端在集合里的字符全删
规则10-23 `lstrip` 只删左端, `rstrip` 只删右端, 中间一律不动
规则10-24 删除在遇到第一个不属于集合的字符时停止

例10-10: 默认删空白, 再指定字符集合
解: `strip('a')` 只认 a, `strip('af')` 认 a 与 f 两个字符

```python
s = '\n  abc \t\n'
print(repr(s.strip()), repr('aaaassddf'.strip('a')), repr('aaaassddf'.strip('af')))
```
输出: 'abc' 'ssddf' 'ssdd'

例10-11: 同一个串三种方向的删除结果
解: 中间出现的 a 与 f 不受影响, 只有两端被削

```python
t = 'aaaassafddfaaa'
print(t.strip('af'), t.lstrip('af'), t.rstrip('af'), sep='|')
```
输出: ssafdd|ssafddfaaa|aaaassafdd

## 10.5 对齐

对齐方法按给定宽度补字符, 宽度不够时原样返回, 从不截断

规则10-25 `center(w, fill)` 返回宽度 w 的新串, 原串居中
规则10-26 `ljust` 左对齐, `rjust` 右对齐, fill 默认是空格
规则10-27 宽度不大于原串长度时原样返回, 不会截断
规则10-28 fill 只能是一个字符, 写多个字符抛 `TypeError`
规则10-29 f-string 写法 `f'{s:=^20}'`, 填充符在前, 对齐符居中

例10-12: 三种对齐在宽度 10 下的结果
解: 原串长 6, 两侧共补 4 个空格, 居中时左右各 2 个

```python
s = 'Hello!'
print(repr(s.center(10)), repr(s.ljust(10)), repr(s.rjust(10)))
```
输出: '  Hello!  ' 'Hello!    ' '    Hello!'

例10-13: 换填充符, 改用 f-string, 再看宽度不足
解: 冒号后依次是填充符, 对齐符, 宽度, 宽度不足时原样返回

```python
s = 'Hi'
print(f'{s:=^8}', f'{s:=<8}', f'{s:=>8}', s.center(1), sep='|')
```
输出: ===Hi===|Hi======|======Hi|Hi

把 `'* ' * i` 逐行交给 `center` 并去掉尾部空格, 就能打印三角形与菱形

## 10.6 映射表转换

maketrans 造一张字符到字符的表, translate 按表逐字符替换
表其实是字典, 键与值都是字符编码, 第三个参数还能删字符

规则10-30 `str.maketrans(s1, s2)` 按位置配对 s1 与 s2, 两串等长
规则10-31 第三个参数是要删除的字符, 转换时直接从结果里去掉
规则10-32 `s.translate(table)` 按表替换, 返回新串, 原串不变
规则10-33 映射表是字典, 键为原字符编码, 值为新字符编码
规则10-34 表只做单字符映射, 不能把多个字符换成一个子串

例10-14: 把 a 到 f 与 1 到 3 换成别的字符
解: 两串等长一一对应, 表外的字符原样保留

```python
table = str.maketrans('abcdef123', 'uvwxyz@#$')
s = 'Python is a great programming language. I like it!'
print(s.translate(table))
```
输出: Python is u gryut progrumming lunguugy. I liky it!

例10-15: 在映射表里再加要删除的字符
解: 第三个参数 `gtm` 里的字符在转换后直接消失

```python
table = str.maketrans('abcdef123', 'uvwxyz@#$', 'gtm')
s = 'Python is a great programming language. I like it!'
print(s.translate(table))
```
输出: Pyhon is u ryu proruin lunuuy. I liky i!

## 10.7 查找与替换

查找返回下标, 替换返回新串, 两者都不改动原来的字符串

规则10-35 `find(sub, start, end)` 返回首次出现的下标, 没有则 -1
规则10-36 `rfind` 返回最后一次出现的下标, 同样以 -1 表示没有
规则10-37 `index` 与 `rindex` 找不到时抛 `ValueError`, 不返回 -1
规则10-38 区间 `[start, end)` 左闭右开, 与切片的取法一致
规则10-39 `count(sub, start, end)` 数不重叠出现的次数
规则10-40 `replace(old, new, count)` 返回新串, count 限前几次

例10-16: 在长串里查 peach 与字符 p 的位置
解: 第二个参数是起点, 第三个是终点, 超出区间就返回 -1

```python
s = 'apple,peach,banana,peach,pear'
print(s.find('peach'), s.find('peach', 7), s.find('peach', 7, 20), s.rfind('p'), s.index('pe'))
```
输出: 6 19 -1 25 6

例10-17: 计数与找不到时的异常
解: `count('pp')` 数的是不重叠的两个 p, 只有开头一处

```python
s = 'apple,peach,banana,peach,pear'
counts = (s.count('p'), s.count('pp'), s.count('ppp'))
try:
    pos = s.index('ppp')
except ValueError as e:
    pos = f'{type(e).__name__}: {e}'
print(counts, pos)
```
输出: (5, 1, 0) ValueError: substring not found

例10-18: `replace` 全部替换, 限次替换, 原串不变
解: 只替换前两次时, 第三个 one 被保留下来

```python
s = 'one two one two one'
print(s.replace('one', '1'), '|', s.replace('one', '1', 2), '|', s)
```
输出: 1 two 1 two 1 | 1 two 1 two one | one two one two one

## 10.8 前缀与后缀

判断前后缀比切片比较更直观, 参数还能一次给出多个候选

规则10-41 `startswith(t)` 判前缀, `endswith(t)` 判后缀, 分大小写
规则10-42 等价写法是 `s[:len(t)] == t` 与 `s[-len(t):] == t`
规则10-43 参数可以传元组, 命中其中任一项即为真

例10-19: 区分大小写地判断前缀与后缀
解: `p` 与 `P` 编码不同, 所以第一个判断为假

```python
text = 'Python'
print(text.startswith('p'), text.startswith('Py'), text.endswith('on'), text.endswith('On'))
```
输出: False True True False

例10-20: 用元组一次判断多个前缀或后缀
解: 列表推导式对每个文件名调用一次, 命中一项即为真

```python
files = ['a.py', 'b.txt', 'c.md']
print([f.endswith(('.py', '.md')) for f in files], 'report.pdf'.startswith(('img', 'rep')))
```
输出: [True, False, True] True

## 常见错误

表10-4 本章五类典型错误

| 错在哪里 | 为什么错 | 怎么改 |
| --- | --- | --- |
| `strip('ab')` 想删子串 ab | 参数是字符集合, 逐字删 | 用 `replace` 或正则 |
| `split('')` 想按空串切 | 空分隔符无意义, 抛异常 | 用 `list(s)` 拆成字符 |
| `if s.find(x):` 当布尔用 | 下标 0 也是假, 漏掉开头 | 写 `x in s` 或 `!= -1` |
| `','.join([1, 2])` | 元素不是 str, 抛 `TypeError` | 先 `map(str, ...)` |
| `"It's".title()` 得 `It'S` | 撇号也算单词边界 | 自己切词再改首字母 |

## 对照与迁移

C 用一组库函数处理字符数组, 每个功能一个函数名
Python 把方法挂在字符串对象上, 用点号调用, 都返回新串

表10-5 C 字符串函数与 Python 方法

| 项 | C | Python |
| --- | --- | --- |
| 求长度 | `strlen(s)` | `len(s)` |
| 查找子串 | `strstr(s, t)` | `s.find(t)` |
| 比较 | `strcmp(a, b)` | `a == b`, `a < b` |
| 复制拼接 | `strcpy` `strcat` | `+`, `join` |
| 按分隔符切分 | `strtok(s, ",")` | `s.split(',')` |
| 删除两端字符 | 手写循环 | `s.strip(chars)` |
| 大小写 | `toupper` 逐字符 | `s.upper()` |

C 的 `strtok` 会改写原串, 多次调用靠内部静态指针记住位置
Python 的 `split` 不改原串, 一次返回整个列表, 可以反复使用

## 自测

(1) `'1234abcd'.isalnum()` 与 `'1234.0'.isdigit()` 各是什么, 为什么
(2) `'a,b,c'.split(',', 1)` 的结果是什么
(3) `'aaa'.strip('a')` 与 `'abc'.strip('ab')` 的结果分别是什么
(4) `'Hi'.center(6, '-')` 的结果是什么, 宽度不足时呢
(5) `s.find('x')` 与 `s.index('x')` 在找不到时有什么不同

## 参考答案

(1) 前者 True, 后者 False. 字母数字混合算 alnum, 小数点不算数字
(2) `['a', 'b,c']`. 只切一次, 剩下的整块留在第二个元素
(3) 前者是空串, 后者是 `'c'`. strip 按字符集合删两端
(4) 前者 `'--Hi--'`, 宽度不足时返回原串 `'Hi'`, 不截断
(5) find 返回 -1, index 抛 `ValueError`, 提示 substring not found

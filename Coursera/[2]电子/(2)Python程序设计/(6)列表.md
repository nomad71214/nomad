## 本章要点

- 列表是可变的有序序列, 增删改分原地修改与新建列表两类
- 下标越界抛异常, 切片越界只截断, 两者的边界处理不同
- 查找与计数各有专用方法, 找不到时一个抛异常一个返回0
- 头部与中部插入删除都要搬移元素, 优先在尾部操作
- 排序有两个入口, 一个原地改并返回None, 一个返回新列表

## 6.1 序列与列表

序列 (sequence) 是按位置排列的一组元素, 元素用下标定位
Python 的序列分可变与不可变两族, 列表 (list) 是可变族的代表

表6-1 常用序列类型

| 可变性 | 有序 | 无序 |
| --- | --- | --- |
| 可变 | 列表 | 集合, 字典 |
| 不可变 | 元组, 字符串, range | 无 |

规则6-1 列表用 `[]` 书写, 元素之间用逗号分隔, 类型可同可不同
规则6-2 元素允许嵌套, `['spam', 2.0, [10, 20]]` 仍是合法列表
规则6-3 下标必须是整数, 正向下标从0起, 反向下标从-1起
规则6-4 列表存的是元素值的引用, 元素项连续, 元素值不一定连续
规则6-5 修改元素写 `lst[下标] = 新值`, 只换值, 长度不变

例6-1: 取 `[10, 20, 30, 40]` 的首尾元素, 把首元素改成100后再输出
解: 正向下标0取首, 反向下标-1取尾; 赋值只换值, 不改长度

```python
lst = [10, 20, 30, 40]
print(lst[0], lst[-1], end=' | ')
lst[0] = 100
print(lst, len(lst))
```
输出: 10 40 | [100, 20, 30, 40] 4

## 6.2 创建与常用内置函数

列表可由字面量直接写, 也可由 `list()` 把可迭代对象逐元素取出
`range` 生成等差整数序列, 是构造列表最常用的来源
四个内置函数 (built-in function) 做整体统计, `del` 删除列表名

规则6-6 `list(iterable)` 逐元素转换, 字符串会拆成单字符列表
规则6-7 `range(stop)` 取 0 到 stop-1, 加起点与步长写三个参数
规则6-8 `range` 返回 range 对象, 要当下标序列用需先 `list()` 转换
规则6-9 `max` `min` `sum` `len` 分别求最大, 最小, 和, 元素个数
规则6-10 `sum` 只接受数值元素, `max` `min` 要求元素之间可比较
规则6-11 `del lst` 删除整个列表名, 之后访问抛 `NameError`

表6-2 random 模块常用函数

| 函数 | 返回值 |
| --- | --- |
| `random()` | [0, 1) 区间的随机实数 |
| `uniform(a, b)` | [a, b] 区间的随机实数 |
| `randint(a, b)` | [a, b] 区间的随机整数 |
| `choice(seq)` | seq 中随机取一个元素 |
| `sample(seq, n)` | 取 n 个不重复元素组成的列表 |
| `shuffle(seq)` | 原地打乱 seq, 返回 None |

例6-2: 用 `sample` 取5个不重复整数, 检查个数, 是否去重, 与取值边界
解: `sample` 要求 n 不超过序列长度, 返回值是列表

```python
import random

nums = random.sample(range(1, 100), 5)
print(len(nums), len(set(nums)), min(nums) >= 1, max(nums) < 100)
```
输出: 5 5 True True

例6-3: 对 `[72, 26, 80, 65, 34]` 求最大, 最小, 和与平均
解: 平均用 `sum` 除以 `len`, 结果是浮点数

```python
nums = [72, 26, 80, 65, 34]
print(max(nums), min(nums), sum(nums), sum(nums) / len(nums))
```
输出: 80 26 277 55.4

## 6.3 元素访问与计数

`index` 由值找下标, `count` 由值数次数, 前者找不到抛异常, 后者返回0
下标访问与反向访问共用一套边界, 越界一律抛 `IndexError`

规则6-12 `L.index(value)` 返回首次出现的下标, 找不到抛 `ValueError`
规则6-13 `L.index(value, start, stop)` 只在 [start, stop) 内查找
规则6-14 `L.count(value)` 返回出现次数, 元素不存在返回0, 不抛异常
规则6-15 下标访问越界抛 `IndexError`, 反向越界同样抛

例6-4: 对 `[3, 4, 5, 7, 9, 7]` 找7的首次下标, 数7与1的个数
解: 前两个调用走 `index` 与 `count`, 1不在表里, `count` 返回0

```python
lst = [3, 4, 5, 7, 9, 7]
print(lst.index(7), lst.count(7), lst.count(1))
```
输出: 3 2 0

例6-5: 用 `index` 查找不在表里的元素, 捕获异常并输出信息
解: `index` 找不到抛 `ValueError`, 不想处理就先用 `in` 判断

```python
lst = [3, 4, 5, 7, 9, 7]
try:
    lst.index(1)
except ValueError as e:
    print(type(e).__name__, '|', '1 不在列表里')
```
输出: ValueError | 1 不在列表里

## 6.4 成员判断与遍历

`in` 判断值是否存在, `for` 逐元素遍历, 两者都不用管下标
for 把循环变量的初始化, 终止判断与更新全部交给解释器

规则6-16 `x in 序列` 返回 True 或 False, 适用于所有可迭代对象
规则6-17 `for 变量 in 序列:` 每轮取一个元素, 循环变量自动更新
规则6-18 `for...else` 的 else 只在循环自然结束时执行, 被 break 打断则不执行
规则6-19 for 的循环变量由解释器改写, 在循环体里改它不影响下一轮取值
规则6-20 while 的循环变量由语句自己维护, continue 会跳过后面的自增语句

例6-6: 用 for 与 while 各遍历一次 'hello', 比较两种写法
解: for 只写循环变量与序列, while 还要自己管下标与自增

```python
word = 'hello'
for c in word:
    print(c, end=' ')
print()
index = 0
while index < len(word):
    print(word[index], end=' ')
    index += 1
```
输出: 两行 h e l l o 与 h e l l o

例6-7: 在 `[3, 4, 5, 7, 9]` 里找7, 用 `for...else` 处理找到与没找到
解: 找到就 break, else 块只在没被 break 时执行, 免去设标志变量

```python
nums = [3, 4, 5, 7, 9]
key = 7
for i in range(len(nums)):
    if nums[i] == key:
        print('index', i)
        break
else:
    print(key, 'not found')
```
输出: index 3

## 6.5 增加元素

五种加法分两类, `+` 与 `*` 生成新列表, `append` `extend` `insert` 原地改
尾部追加最快, 中部插入要搬移后面的全部元素

规则6-21 `lst1 + lst2` 复制两边的元素生成新列表, 原列表不变
规则6-22 `L.append(x)` 尾部追加一个元素, 原地修改, 返回 None
规则6-23 `L.extend(seq)` 把可迭代对象的元素逐个追加到尾部, 原地修改
规则6-24 `L.insert(i, x)` 在 i 之前插入, 后面的元素整体后移
规则6-25 `lst * n` 生成重复 n 次的新列表, 重复的是元素值的引用

表6-3 增加元素的五种方法与效果

| 方法 | 别名 | 效果 |
| --- | --- | --- |
| `lst1 + lst2` | 拼接 | 新建列表 |
| `lst.append(x)` | 追加 | 原地修改 |
| `lst.extend(seq)` | 扩展 | 原地修改 |
| `lst.insert(i, x)` | 插入 | 原地修改 |
| `lst * n` | 重复 | 新建列表 |

例6-8: 用 `id` 判断 `+` 与 `extend` 是否换了对象
解: `+` 造新列表所以 id 变, `extend` 原地改所以 id 不变

```python
lst = [3, 4, 5]
before = id(lst)
lst = lst + [7]
print('+ 之后换对象:', id(lst) != before)
```
输出: + 之后换对象: True

```python
lst = [3, 4, 5]
before = id(lst)
lst.extend([7])
print('extend 之后换对象:', id(lst) != before, lst)
```
输出: extend 之后换对象: False [3, 4, 5, 7]

例6-9: 用 `[[1, 2, 3]] * 3` 造三行, 改第一行的首元素
解: 三次重复指向同一个子列表, 改一处三行都变

```python
lst = [[1, 2, 3]] * 3
lst[0][0] = 10
print(lst, lst[0] is lst[1])
```
输出: [[10, 2, 3], [10, 2, 3], [10, 2, 3]] True

## 6.6 删除元素

`del` 按下标删, `pop` 按下标删并返回, `remove` 按值删首个
删除中部元素要搬移后面的元素, 与插入同理

规则6-26 `del lst[i]` 按下标删除元素, 原地修改, 无返回值
规则6-27 `L.pop()` 删除并返回尾部元素, `L.pop(i)` 删下标 i 的元素
规则6-28 列表为空或下标越界时 `pop` 抛 `IndexError`
规则6-29 `L.remove(x)` 删除首个值为 x 的元素, 找不到抛 `ValueError`
规则6-30 `lst[:3] = []` 与 `del lst[:3]` 都能一次删除一段

表6-4 删除元素的三种方法

| 方法 | 删除对象 | 返回值 |
| --- | --- | --- |
| `del lst[i]` | 下标 i 的元素 | 无 |
| `lst.pop(i)` | 下标 i 的元素 | 被删的元素 |
| `lst.remove(x)` | 首个值为 x 的元素 | None |

例6-10: 从水果表弹出尾部元素, 再按值删除 banana
解: `pop` 有返回值, `remove` 返回 None, 结果要看列表本身

```python
fruit = ['apple', 'banana', 'peach', 'grape']
print(fruit.pop(), fruit)
```
输出: grape ['apple', 'banana', 'peach']

```python
fruit = ['apple', 'banana', 'peach', 'grape']
print(fruit.remove('banana'), fruit)
```
输出: None ['apple', 'peach', 'grape']

例6-11: 遍历 `[1, 1, 2, 2, 1]`, 每遇1就删除, 观察结果
解: for 的隐藏下标每轮加1, 删掉元素后后面的值前移, 会跳过一个

```python
lst = [1, 1, 2, 2, 1]
for i in lst:
    if i == 1:
        lst.remove(i)
print(lst)
```
输出: [2, 2, 1]

表6-5 遍历中删除的逐轮推演

| 轮次 | 隐藏下标 | 取到的值 | 删除后列表 |
| --- | --- | --- | --- |
| 1 | 0 | 1 | [1, 2, 2, 1] |
| 2 | 1 | 2 | [1, 2, 2, 1] |
| 3 | 2 | 2 | [1, 2, 2, 1] |
| 4 | 3 | 1 | [2, 2, 1] |
| 5 | 4 | 无 | 下标已超长度, 循环结束 |

例6-12: 用 while 管下标删掉所有1
解: 删掉元素后不增加下标, 保证下一个元素仍被检查

```python
lst = [1, 2, 2, 1, 1]
idx = 0
while idx < len(lst):
    if lst[idx] == 1:
        lst.pop(idx)
    else:
        idx += 1
print(lst)
```
输出: [2, 2]

例6-13: 遍历切片副本 `lst[:]` 删掉所有1
解: 副本长度固定, 删除原列表的元素不影响遍历进度

```python
lst = [1, 2, 2, 1, 1]
for i in lst[:]:
    if i == 1:
        lst.remove(i)
print(lst)
```
输出: [2, 2]

## 6.7 切片

切片取 `[start, stop)` 区间并返回新列表, 放在赋值号左边则原地改
越界不抛异常, 只在首尾截断或返回空表

规则6-31 `lst[start:stop:step]` 取半开区间, step 为步长, 默认1
规则6-32 三个参数都可省, `lst[:]` 是整表的浅拷贝
规则6-33 step 为负时反向取, `lst[::-1]` 得到逆序
规则6-34 切片越界不报错, 起点超出返回空表, 终点超出截断到末尾
规则6-35 切片作左值可原地替换一段, 新片段的长度不必相等
规则6-36 `b = a` 是别名, `b = a[:]` 是副本, 用 `is` 可区分两者

例6-14: 取 `lst[3:6]`, 再取隔一个的 `lst[3:6:2]`, 最后取逆序前三项
解: 切片长度是 stop 减 start, 反向切片先反转再取

```python
lst = [3, 4, 5, 6, 7, 9, 11, 13, 15, 17]
print(lst[3:6], lst[3:6:2], lst[::-1][:3], lst[100:])
```
输出: [6, 7, 9] [6, 9] [17, 15, 13] []

例6-15: 用切片赋值在头部与尾部加元素, 再把前三项换成两项
解: `lst[0:0]` 是空区间, 给它赋值等于插入, 两侧长度可以不等

```python
lst = [3, 5, 7]
lst[len(lst):] = [9]
lst[0:0] = [0, 1]
lst[:3] = [1, 3]
print(lst)
```
输出: [1, 3, 5, 7, 9]

例6-16: 对比赋值与全切片, 改副本是否影响原表
解: 赋值让两个名指向同一对象, 全切片复制出一个新对象

```python
a = [3, 5, 7]
b = a
c = a[:]
b[1] = 8
print(a, c, a is b, a is c)
```
输出: [3, 8, 7] [3, 5, 7] True False

## 6.8 排序与逆序

排序有两个入口, `sort` 改原列表并返回 None, `sorted` 返回新列表
逆序也用两个, `reverse` 原地改, `reversed` 返回迭代器 (iterator)

规则6-37 列表比较逐个元素进行, 首个不同处定大小, 前缀相同则长者大
规则6-38 `L.sort()` 原地升序并返回 None, `reverse=True` 改为降序
规则6-39 `sorted(iterable)` 返回排好序的新列表, 原对象不变
规则6-40 `L.reverse()` 原地逆序并返回 None
规则6-41 `reversed(seq)` 返回迭代器, 要当下标序列用需 `list()` 转换

表6-6 sort 与 sorted 的差别

| 项 | `L.sort()` | `sorted(L)` |
| --- | --- | --- |
| 归属 | 列表方法 | 内置函数 |
| 作用对象 | 只能是列表 | 任意可迭代对象 |
| 返回值 | None | 排好序的新列表 |
| 原对象 | 被修改 | 不变 |

例6-17: 比较两个入口的返回值与原列表
解: `sorted` 只返回结果, `sort` 只改原表, 两者不要混用

```python
nums = [55, 94, 3, 19]
print(sorted(nums), nums)
```
输出: [3, 19, 55, 94] [55, 94, 3, 19]

```python
nums = [55, 94, 3, 19]
print(nums.sort(), nums)
```
输出: None [3, 19, 55, 94]

例6-18: 用 `reversed` 取逆序迭代器, 再用 `reverse` 原地逆序
解: `reversed` 不动原对象, `reverse` 原地改并返回 None

```python
nums = [4, 11, 7]
print(list(reversed(nums)), nums, end=' | ')
nums.reverse()
print(nums)
```
输出: [7, 11, 4] [4, 11, 7] | [7, 11, 4]

例6-19: 判断前缀相同的列表如何比较, 以及整数与浮点混比的结果
解: 一个是另一个的前缀时短的小, 数值相等的整数与浮点判等

```python
print([1, 2] < [1, 2, -1], [1, 2, 3] == [1.0, 2.0, 3.0], 'a' > 'A')
```
输出: True True True

## 6.9 日期计算案例

用列表存每个月的天数, 闰年改二月, 再用切片求前几个月的和
查表加切片替代一长串条件判断, 是列表最常见的用法之一

例6-20: 计算今天是今年的第几天
解: 取年月日, 闰年把二月改成29, 前 month-1 个月求和再加 day

```python
import time

year, month, day = time.localtime()[:3]
days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
if year % 4 == 0 and year % 100 != 0 or year % 400 == 0:
    days[1] = 29
print(sum(days[:month - 1]) + day)
```
输出: 2026年10月23日运行得 296

## 常见错误

表6-7 本章三类典型错误

| 错在哪里 | 为什么错 | 怎么改 |
| --- | --- | --- |
| `lst[4]` 访问长度4的列表 | 下标上界是 `len(lst)-1` | 用 `lst[3]`, 或先判 `len(lst) > 4` |
| `b = a.sort()` 取排序结果 | `sort` 原地改并返回 None | 改用 `b = sorted(a)` |
| `for i in lst: lst.remove(i)` | 隐藏下标每轮加1, 删后元素前移, 会漏删 | 遍历 `lst[:]` 或用 while 管下标 |

## 对照与迁移

C 的数组定长且不检查越界, 列表自动伸缩且越界必抛异常
两者都叫下标访问, 出错后果相反, 移植时不能照搬边界假设

表6-8 C 数组与 Python 列表

| 项 | C 数组 | Python 列表 |
| --- | --- | --- |
| 长度 | 定义时定死, 不能改 | 运行时自动伸缩 |
| 越界 | 读到相邻内存, 不报错 | 抛 IndexError |
| 整体赋值 | 数组名不可赋值 | 赋值是引用别名 |
| 元素个数 | `sizeof(a) / sizeof(a[0])` | `len(lst)` |
| 追加元素 | 无, 自己维护计数 | `append` 与 `extend` |
| 切片 | 无, 用循环或 memcpy | 有, 越界不报错 |

C 的字符串是 char 数组, 用下标改字符是常规操作
Python 的字符串与元组同属不可变序列, 改字符要先转成列表

## 自测

(1) `lst = [1, 2, 3]` 执行 `lst[1:2] = [7, 8]` 后 lst 是什么
(2) 为什么 `b = a.sort()` 之后 b 是 None, 要拿到有序结果怎么写
(3) `lst = [1, 1, 2]` 用 for 循环删掉所有1 会漏删, 写出两种改法
(4) `[1, 2] < [1, 2, 0]` 的结果是什么, 依据哪条比较规则
(5) `lst[100:]` 与 `lst[100]` 的结果差别在哪里

## 参考答案

(1) `[1, 7, 8, 3]`. 切片长度1被长度2的片段替换, 列表变长
(2) `sort` 原地排序, 返回值是 None; 要新列表写 `sorted(a)`,
要原地就写 `a.sort()` 之后继续用 a
(3) 遍历副本 `for i in lst[:]`; 或 while 管下标, 删后不前进下标
(4) True. 前两个元素相同, 前者先用完, 短的小
(5) `lst[100:]` 返回空列表, 不报错; `lst[100]` 抛 IndexError

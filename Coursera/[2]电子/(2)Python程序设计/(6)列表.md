## 6.1 序列与列表概述

列表是 Python 内置的可变有序序列, 把若干元素放在一对 `[]` 中用逗号分隔,
是程序中最常用的数据存储结构

(1) 元素类型可相同也可不同, 可嵌套: `['spam', 2.0, 5, [10, 20]]`
(2) 访问: `列表名[索引]`, 索引必须为整数, 支持正向(0 起)与反向(-1 起)
(3) 修改: `lst[idx] = value`
(4) 序列分类: 有序可变, 列表; 有序不可变, 元组, 字符串, `range`; 无序, 字典, 集合
(5) 列表元素存的是元素值的引用: 元素在内存中连续存放, 元素值本身不一定连续

```python
lst = [10, 20, 30, 40]
print(lst[0], lst[-1])   # 10 40
lst[0] = 100            # 通过下标修改
print(lst)              # [100, 20, 30, 40]
```

[注意] 下标越界会抛
`IndexError: list index out of range`(`lst[4]` 对长度
4 的列表非法); 但切片越界不会报错, 只会截断或返回空列表

## 6.2 列表的创建

列表可由字面量直接创建, 也可由 `list(iterable)` 把任意可迭代对象转换而来;
`range()` 是最常用的整数序列生成器

(1) 直接赋值: `a_list = ['hello', 'world']`; 空列表 `[]` 或 `list()`
(2) `list(iterable)`: 把字符串, 元组, `range` 对象等转为列表(字符串被拆成单字符列表)
(3) `range([start,] stop[, step])`: 返回 `range` 对象,
`start` 默认 0, `step` 默认 1, 不含 `stop`
(4) 删除整个列表用 `del a_list`, 之后访问会抛 `NameError`

```python
print(list('hello'))          # ['h', 'e', 'l', 'l', 'o']
print(list(range(1, 10, 2)))  # [1, 3, 5, 7, 9]
print(list(range(5)))         # [0, 1, 2, 3, 4]

lst = [3, 4, 5]
del lst                       # 删除整个列表对象
```

[注意] `range(1, 10)` 生成 1~9, 不含 10
`range` 对象不能像列表那样切片取值后再当列表用,
需要 `list()` 转换

## 6.3 元素的访问, 计数与成员判断

除下标访问外, 列表提供 `index()` 查找元素首次出现的下标, `count()` 统计出现次数;
成员存在性可用 `count()` 或 `in` 判断

(1) `L.index(value, [start, [stop]])`: 返回首次出现的下标;
不存在时抛 `ValueError`
(2) `L.count(value)`: 返回出现次数; 返回 0 表示不存在
(3) `in / not in`: 返回 `True/False`, 适用于所有可迭代对象
(4) `for 变量 in 序列:` 用于遍历元素, 循环变量每轮自动取下一个元素

```python
lst = [3, 4, 5, 7, 9, 7]
print(lst.index(7))   # 3，首次出现的下标
print(lst.count(7))   # 2
print(7 in lst)       # True

for x in lst:
    print(x, end=' ') # 3 4 5 7 9 7
```

[注意] `index()` 找不到元素时抛异常而不是返回 -1, 用之前应先用 `in` 判断,
或用 `try/except` 捕获 `ValueError`

## 6.4 增加列表元素

`append()` 追加单个元素, `extend()` 追加多个元素, `insert()` 在指定位置插入,
三者都原地修改; `+` 和 `*` 则生成新列表

(1) `lst1 + lst2`: 拼接生成新列表(元素复制, 速度较慢)
(2) `L.append(obj)`: 尾部追加一个元素, 返回 `None`, 原地修改
(3) `L.extend(iterable)`: 把可迭代对象的所有元素追加到尾部, 原地修改, 效率高于 `+`
(4) `L.insert(index, obj)`: 在 `index` 前插入元素, 涉及后续元素整体后移
速度较慢
(5) `lst * n`: 重复生成新列表
(6) 性能建议: 优先 `append()` 在尾部添加; 避免在列表中间插入

```python
lst = [5, 2, 4]
lst.append(9)          # [5, 2, 4, 9]，原地修改
lst.extend([7, 8])     # [5, 2, 4, 9, 7, 8]，原地修改
lst.insert(0, 'x')     # 头部插入，后续元素全部后移

new = [1, 2] + [3]     # 生成新列表 [1, 2, 3]
print(new * 2)         # [1, 2, 3, 1, 2, 3]
```

[注意] `[[1, 2, 3]] * 3` 重复的是引用而非值, 三个子列表指向同一对象,
修改 `lst[0][0]` 会同时改变三行. 正确做法是用列表推导式
`[[1, 2, 3] for _ in range(3)]`

## 6.5 删除列表元素

`del` 按位置删除, `pop()` 删除并返回元素, `remove()` 按值删除首次出现的元素;
删除中间元素涉及大量元素搬移

(1) `del lst[idx]`: 删除指定下标的元素; `del lst` 删除整个列表
(2) `L.pop([index])`: 删除并返回指定位置元素, `index` 默认 -1(尾部);
索引越界或列表为空抛 `IndexError`
(3) `L.remove(value)`: 删除首次出现的指定值; 不存在时抛 `ValueError`
(4) 性能建议: 优先用 `pop()` 删除尾部元素

```python
lst = [3, 5, 7, 9, 5]
del lst[1]          # [3, 7, 9, 5]
print(lst.pop())    # 5（返回被删除的尾部元素）
lst.remove(7)       # 删除首次出现的 7 → [3, 9]
```

[注意] `lst.remove(x)` 只删第一个 `x`; 要删除所有 `x`,
不要在 `for` 循环里直接 `remove` ,  遍历时列表长度在变,
会导致漏删. 应改用 `while` 手动控制下标, 或遍历切片副本 `for x in lst[:]`

## 6.6 切片操作

切片 `lst[start:stop:step]` 从有序序列中截取一段, 返回新列表(浅拷贝);
切片也允许出现在赋值号左侧, 用于原地修改, 删除, 插入元素

(1) `start` 默认 0, `stop` 默认列表长度, `step` 默认 1;
`step` 省略时第二个冒号也可省略
(2) 区间为 `[start, stop)`, 包含 `start` 不含 `stop`
(3) `step` 为负表示反向切片, `lst[::-1]` 得到整个列表的逆序
(4) 切片不会因越界报错: `stop` 超长度会被截断, `start` 超长度返回空列表
(5) `lst[:]` 得到浅拷贝(新列表); `lst2 = lst` 只是别名
(6) 切片赋值: `lst[len(lst):] = [9]` 尾部添加,
`lst[0:0] = [0,1]` 头部添加, `lst[:3] = []` 删除

```python
lst = [3, 4, 5, 6, 7, 9, 11, 13, 15, 17]
print(lst[3:6])    # [6, 7, 9]
print(lst[3:6:2])  # [6, 9]
print(lst[::-1])   # 逆序
print(lst[:100])   # 越界不报错，返回全表
print(lst[100:])   # []

aList = [3, 5, 7]
bList = aList[:]   # 浅拷贝：新列表
bList[1] = 8
print(aList)       # [3, 5, 7]，原列表不受影响
```

[注意] `bList = aList` 让两个名字指向同一列表(`aList is bList` 为 `True`),
改一个另一个也变; 要独立副本必须写 `bList = aList[:]` 或 `list(aList)`

## 6.7 列表排序与逆序

`lst.sort()` 是列表方法, 原地排序且返回 `None`;
内置函数 `sorted()` 不修改原对象, 返回新列表; `reverse()` 原地逆序,
`reversed()` 返回迭代器

(1) `L.sort(key=None, reverse=False)`: 原地稳定排序, 返回 `None`
(2) `sorted(iterable, key=None, reverse=False)`: 返回新的有序列表,
适用于任何可迭代对象
(3) `L.reverse()`: 原地逆序, 返回 `None`
(4) `reversed(seq)`: 返回逆序迭代器对象, 需 `list()` 转换才能当列表用
(5) 列表比较: 逐元素比较, `[1,2,3] < [1,2,4]` 为 `True`;
`[1,2] < [1,2,-1]` 为 `True`(前缀相同, 更长者更大)

```python
lst = [55, 94, 3, 19]
lst.sort()                  # 原地升序，lst 改变
lst.sort(reverse=True)      # 原地降序

nums = [6, 7, 3, 18]
new = sorted(nums)          # 返回新列表，nums 不变
print(new, nums)            # [3, 6, 7, 18] [6, 7, 3, 18]

lst.reverse()               # 原地逆序
print(list(reversed(nums))) # 迭代器转列表
```

[注意] `bList = aList.sort()` 得到的是 `None`(`sort()` 无返回值);
想拿到排序结果应写 `bList = sorted(aList)`

## 6.8 应用案例: 日期计算

应用场景: 用列表保存每月天数, 配合切片求和, 计算"今天是今年的第几天"

```python
import time
date = time.localtime()
year, month, day = date[0], date[1], date[2]

day_month = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
if year % 4 == 0 and year % 100 != 0 or year % 400 == 0:
    day_month[1] = 29       # 闰年二月 29 天

# 切片取前 month-1 个月的天数求和，再加上当月的日
print(sum(day_month[:month - 1]) + day)
```

## 1.1 函数 (Function)

函数是完成指定功能的代码封装; Python 自带的内置函数 (BIF,
Built-in Functions)无需导入即可直接调用, 调用形式为 `函数名(参数...)`,
其计算结果称为返回值

(1) 调用格式: `函数名(参数1, 参数2, ...)`; `()` 是函数的标志, 无参函数也必须写 `()`
(2) 返回值: 函数执行后交回调用处的值, 可作为表达式的一部分继续参与运算
(3) 内置函数优先使用: 成熟, 稳定, 执行速度快, 且不需要 `import`
(4) 两个必备自省函数: `dir(obj)` 查看对象全部属性/方法, `help(obj)` 查看帮助文档
(5) 与数学函数不同: Python 函数可以无参数, 也可以不用于数值计算(如 `print()` 只输出一个空行)

```python
>> type(1)            # 函数名 type，参数 1，返回对象类型
<class 'int'>
>> dir(__builtins__)  # 列出所有内置函数与内置对象
>> help(print)        # 获取 print 的帮助信息
>> print()            # 无参调用：输出一个空行
```

## 1.2 对象模型 (Object)

Python 中一切数据都是对象; 对象一旦创建就有唯一的标识 `id`(内存地址),
并具有类型(决定取值范围与可支持的操作)和值(可变/不可变由类型决定)两个属性

(1) `id(x)`: 返回对象 `x` 的标识(内存地址), 对象存活期间不变
(2) `a is b`: 判断 `a`, `b` 是否为同一对象(`id` 相同); `is not` 取反
(3) 不可变类型: 数值, 字符串, 元组 → 值不可原地修改
(4) 可变类型: 列表, 字典, 集合 → 支持原地增删改
(5) 其他: 布尔型 `True/False`, 空类型 `None`, 文件对象, 函数/模块/类等编程单元类型

```python
a, b = 3, 4
print(a is b)      # False：3 与 4 不是同一对象
x = [1, 2]
y = x              # 别名：y 与 x 指向同一列表对象
print(x is y)      # True
```

## 1.3 常量, 变量与赋值

常量 (Literal, 字面值)是解释器自动识别类型的固定值; 变量是对某个对象的引用, 使用前必须赋值,
类型由所引用对象决定, 故 Python 是动态类型语言

(1) 字面值: 字符串 `'Hello'`, 整数 `2026`, 浮点数 `3.14`, 复数 `1+2j`
(2) 表达式: 由对象与运算符组成, 如 `(3*4+5)*6`
(3) 赋值语句 `LHS = RHS`: LHS 必须是变量, 保存 RHS 对象的引用(地址), 而非复制值
(4) 多元赋值: `i, j = 1, 0`
`x, y, z = 'Mike', 4, 3.14`(左右数量必须一致)
(5) 动态类型: 同一变量可先后引用不同类型的对象
(6) `type(obj)` 返回类型; `isinstance(obj, class)` 判断是否为指定类型的实例
(7) `del x`: 解除变量与对象的绑定; 对象无任何引用后由垃圾回收自动回收

```python
a = (3*4+5)*6     # a 引用整数对象 102
a = a*a           # a 改指向新对象 10404
b = a             # b 与 a 引用同一对象
i, j = 1, 0       # 多元赋值，等价于 i = 1; j = 0

x = 3
print(type(x))    # <class 'int'>
x = 'Hello'
print(type(x))    # <class 'str'>，变量类型随引用对象改变
print(isinstance(3, int))   # True
```

[注意] 交互模式(`>>>`)下输入变量名会自动回显其值, 脚本模式下不会
脚本里必须显式 `print(x)`,
否则程序"什么都不输出"

[注意] `b = a` 只是新增一个引用(别名), 不是复制. 后续修改可变对象 `a` 会同时影响 `b`;
需独立副本时用切片 `b = a[:]` 或 `list(a)`

## 1.4 标识符与命名规范

标识符是变量, 函数, 类, 模块等对象的名字, 必须符合词法规则且不能与关键字冲突

(1) 首字符必须是字母或下划线 `_`, 其后可为字母, 下划线或数字
(2) 不能含空格与标点符号: `99var`, `It'OK`, `first-class` 均非法
(3) 大小写敏感: `student` 与 `Student` 是不同变量
(4) 关键字不可作标识符, 可用 `keyword.kwlist` 查看(`False`, `None`
`and`,
`def`, `for`, `if`, `import`, `lambda`, `not`,
`while` 等 35 个)
(5) 不推荐用内置模块名/类型名/函数名作标识符, 否则会覆盖其原含义
(6) 命名风格: 小写字母 + 下划线连接, 如 `lower_case_with_underscores`;
名字应反映含义(`area`, `keys`), `i/j/k` 仅用于循环

```python
import keyword
print(keyword.kwlist)   # 输出全部关键字列表
# 注意：不要写 list = [1, 2]，这会把内置类型 list 覆盖掉
```

## 1.5 基本输入输出

`input()` 从键盘读入一行并以字符串返回; `print()` 把多个对象转成字符串后按 `sep` 分隔,
以 `end` 结尾输出到 `file`

(1) `input(prompt)`: 先输出提示串 `prompt`, 再等待用户输入回车, 返回的字符串不含回车符
(2) `print(v1, v2, ..., sep=' ', end='\n', file=sys.stdout)`
1. `sep`: 输出项之间的分隔符, 默认一个空格
2. `end`: 输出结束符, 默认换行 `\n`
3. `file`: 输出目标, 默认标准输出(显示器)
4. 参数有默认值, 可按关键字指定, 也可省略
(3) 需要数值时必须显式转换: `int(input(...))`, `float(...)`
`eval(...)`
(4) 嵌套调用由内向外执行: 先 `input()` 得到字符串, 再 `int()` 转换

```python
x = int(input('Enter a number: '))   # input 返回字符串，int() 转为整数
y, z = 1, 2
print(x, '+', y)              # 用逗号分隔各项，输出 "1 + 2"
print(y, '+', z, sep='')      # sep='' 取消分隔符 → "1+2"
print(y, '+', z, sep='', end='=')   # 结束符改为 '='，不换行
```

[注意] `print(x'+'y)` 无法拼接常量与变量, 会报语法错误; 多个值必须用逗号分隔传入,
如 `print(x, '+', y)`

[注意] `input()` 永远返回 `str`. `a = input()` 后 `a + b`
得到的是字符串拼接(`'4'+'2'` 得 `'42'`), 而不是算术加法 `6`

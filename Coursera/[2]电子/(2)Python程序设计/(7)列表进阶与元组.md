## 7.1 列表推导式

列表推导式是用一行表达式从其他序列"生成"新列表的轻量级循环写法, 可带过滤条件,
执行效率高于等价的 `for + append`

(1) 形式: `[表达式 for 变量 in 序列 (if 条件)]`, `if` 子句可选
(2) 语义: 对序列中每个满足条件的元素计算表达式, 结果依次放入新列表
(3) 表达式可以是函数调用或复杂表达式, 也可用条件表达式实现分支
(4) 支持多重循环: `[[x, y] for x in range(3) for y in range(3)]`
(5) 与 `sum()` 配合可替代累加循环

```python
print([x*x for x in range(5)])          # [0, 1, 4, 9, 16]

lst = [-1, -4, 6, 7.5, -2.3, 9]
print([i for i in lst if i > 0])        # [6, 7.5, 9]，过滤非正数

print([v**2 if v % 2 == 0 else v+1 for v in [2, 3, 4, -1] if v > 0])
# [4, 4, 16]，条件表达式 + 过滤

n = 5
print(sum([i*i for i in range(1, n+1)]))   # 55，平方和
```

[注意] 列表推导式的结果总是新列表, 不会修改原序列; 若只需遍历而不需要结果列表, 应直接用 `for` 循环,
避免无谓的内存开销

## 7.2 二维列表

二维列表是"列表的列表", 用行下标, 列下标两级索引访问, 可表示矩阵, 表格;
`for` 循环配合 `range()` 是最通用的构建方式

(1) 访问: `lst[i][j]` 表示第 i 行第 j 列; `lst[i]` 得到整行(一个列表)
(2) 构建: 外层循环枚举行, 内层用列表推导式生成一行, 再 `append`
(3) 按行输出: `print(*matrix, sep='\n')` 利用序列解包逐行打印
(4) 整表求和: `sum(row)` 逐行累加
(5) 排序: `sort()` / `sorted()` 默认按行首元素比较, 相同则比较第二个元素, 依此类推

```python
from random import randint

rows, cols = 3, 4
matrix = []
for i in range(rows):
    row = [randint(0, 99) for j in range(cols)]   # 生成一行
    matrix.append(row)

print(*matrix, sep='\n')            # 每行一个列表
print(matrix[0][1])                 # 第 0 行第 1 列

total = 0
for row in matrix:
    total += sum(row)
print(total)
```

[注意] 用 `[[0]*cols]*rows` 创建二维列表, 所有行都是同一个列表对象的引用
改一行会"全表都变";
必须逐行独立创建

## 7.3 元组的创建与访问

元组是不可变的有序序列, 用 `()` 定义; 创建后不能增删改任何元素, 因此更快, 更安全, 还可作为字典的键

(1) 定义: `TIOBE = ('C', 'Java', 'Python')`;
不引起歧义时括号可省略 `x = 1, 2, 3`
(2) 空元组 `()`; 单元素元组必须加逗号: `('a',)`, 而 `('a')` 只是字符串
(3) `tuple(iterable)`: 把字符串/列表等转换为元组; `tuple()` 创建空元组
(4) 访问: 下标 `x[5]`, 反向 `x[-2]`, 切片 `x[::-1]`,
`len/max/min/sum/sorted` 均可用
(5) 支持 `+`, `*`, `in`, `count()`, `index()`, 比较运算
(6) `del` 只能删除整个元组, 不能删除其中某个元素

```python
TIOBE = ('C', 'Java', 'Python')
print(TIOBE[2])        # Python

a = ('a',)             # 单元素元组，逗号不能省
b = ('a')              # 这其实是字符串 'a'
print(a, b)            # ('a',) a

print(tuple('abc'))    # ('a', 'b', 'c')
print(tuple([1, 2]))   # (1, 2)
print(TIOBE[::-1])     # ('Python', 'Java', 'C')
```

[注意] `('a')` 不是元组而是字符串; `('a',)` 才是单元素元组. 这个逗号是 Python
中最常被漏掉的一个符号

[注意] 元组不可变, `t[0] = 1` 会抛 `TypeError`; 但若元组内元素是列表, 列表内部仍可修改

## 7.4 元组与列表的区别

两者都是有序序列, 索引/切片/遍历方式完全相同, 区别在于可变性: `tuple()` 可"冻结"列表,
`list()` 可"融化"元组

(1) 元组没有 `append/extend/insert/remove/pop` 等修改方法,
也不支持 `del t[i]`
(2) 元组速度比列表快, 适合存放只读的常量序列
(3) 元组可作字典的键, 列表不可(因为可变, 不可哈希)
(4) 元组对数据起"写保护"作用, 使代码更安全
(5) 很多内置函数的返回值是元组(如 `enumerate`, `zip` 的元素, `divmod`)

```python
lst = [1, 2, 3]
t = tuple(lst)     # 冻结：列表 → 元组
new = list(t)      # 融化：元组 → 列表
new.append(4)
print(t, new)      # (1, 2, 3) [1, 2, 3, 4]

d = {(1, 2): 'point'}   # 元组可作字典键
```

## 7.5 序列解包与 zip / enumerate

`*` 可把序列"拆开"成独立参数; `zip()` 把多个序列对应位置的元素组合成元组;
`enumerate()` 在遍历时同时给出下标和值

(1) 解包: `print(*lst)` 等价于把列表元素逐个作为参数传入
(2) `zip(iter1 [,iter2 ...])`: 返回 `zip` 对象(可迭代),
元素为各序列同位置元素组成的元组; 以最短序列为准
(3) `zip` 对象不支持下标访问(`cZip[0]` 抛 `TypeError`)
需先 `list()` 转换;
且只能遍历一次
(4) `enumerate(iterable[, start])`: 返回枚举对象
元素为 `(下标, 值)` 元组,
下标从 `start` 开始(默认 0)
(5) 常用技巧: `for idx, value in enumerate(lst, 1):` 同时取下标与值

```python
lst = [1, 2, 3, 4]
print(*lst)                      # 1 2 3 4，解包

a, b = [1, 2, 3], [4, 5, 6]
z = list(zip(a, b))              # [(1, 4), (2, 5), (3, 6)]
for x, y in z:
    print(x, y)

for i, v in enumerate('abc', 1):  # 下标从 1 开始
    print(i, v)                   # (1, 'a') (2, 'b') (3, 'c')

# 矩阵转置：解包 + zip
matrix = [[1, 2, 3], [4, 5, 6]]
print(list(zip(*matrix)))        # [(1, 4), (2, 5), (3, 6)]
```

[注意] `zip` 返回的是迭代器, 遍历过一次就耗尽
想要重复使用必须先 `list(zip(...))` 缓存下来

## 7.6 应用案例: 查找下标与评分统计

应用场景: 用 `for...else` 实现"查找并给出未找到提示";
用 `zip` 把学生答案与标准答案逐题配对计分

```python
from random import sample
lst = sample(range(100), 10)      # 10 个不重复的随机整数

key = int(input('Enter an integer: '))
for i in range(len(lst)):
    if lst[i] == key:
        print(f'The index of {key} is {i}.')
        break                     # 找到即终止
else:                             # 未被 break 打断 → 没找到
    print(f'{key} is not in the list.')
```

```python
keys = ['D', 'B', 'D', 'C', 'C']
answers = [['A', 'B', 'A', 'C', 'C'],
           ['D', 'B', 'D', 'C', 'A']]

for idx, record in enumerate(answers, 1):   # 枚举学生，从 1 开始编号
    correct = 0
    for ans, key in zip(record, keys):      # 逐题与标准答案配对
        if ans == key:
            correct += 1
    print(f'Student {idx} : {correct}')
```

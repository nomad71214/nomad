## 5.1 while 循环

`while` 在条件为真时重复执行循环体, 适用于循环次数无法预先确定的场景;
写法上必须凑齐"初始化 → 条件 → 更新"三要素

(1) 语法: `while 表达式:` + 缩进循环体
(2) 三要素: 循环变量初始化(循环前), 循环控制条件(`while` 后), 使循环趋于终止的更新语句(循环体内)
(3) 条件为假时循环结束; 循环体可能一次都不执行
(4) 循环变量的变化必须由程序语句显式控制

```python
n = int(input('Enter an integer: '))
total = 0      # 累加器初值
i = 1          # 循环变量初始化
while i <= n:  # 循环控制条件
    total += i * i
    i += 1     # 更新循环变量，否则死循环
print(f'Sum of squares(1~{n}): {total}')
```

[注意] 循环体内漏写 `i += 1` 会导致死循环; `while` 后忘记 `:` 会报语法错误

## 5.2 标志变量与赋值表达式

当循环终止条件复杂时, 可用布尔标志变量控制循环;
Python 3.8+ 的海象运算符 `:=` 可在表达式内部完成赋值并返回该值

(1) 标志变量: `found = False`, 在循环内条件满足时置 `True`,
`while not found:` 控制循环
(2) 海象运算符: `变量 := 表达式`, 赋值并返回该值, 需加括号: `(x := 3)`
(3) 典型用法: 把"读入 + 判断"合并进 `while` 条件, 避免重复写输入语句
(4) 赋值语句 `x = ...` 不能直接放在条件位置, `while x = ...` 是语法错误

```python
# 用标志变量：查找最小满足条件的正整数
num, found = 1, False
while not found:
    if num % 3 == 2 and num % 5 == 3 and num % 7 == 4:
        found = True
    else:
        num += 1
print(num)

# 海象运算符：读入并判零写在同一行
while (x := eval(input('Enter a number: '))):
    print(f'({x})^2 = {x*x}')
print('Good bye!')
```

## 5.3 break / continue 与 while...else

`break` 立即终止整个循环; `continue` 跳过本轮剩余的循环体, 直接进入下一轮判断;
`while...else` 的 `else` 块只在循环自然结束(未被 `break` 打断)时执行

(1) `break`: 提前结束循环, 跳出循环结构
(2) `continue`: 终止本轮, 回到循环顶端开始下一轮
(3) `break/continue` 通常写在嵌套于循环中的 `if` 里, 且常作为该 `if` 块的最后一条语句
(4) `while 表达式: 循环体 else: 语句块` ,  `else` 只在"条件变假而退出"时执行,
`break` 退出时不执行
(5) 除非能让代码更简单清晰, 不要滥用 `break/continue`

```python
n = int(input('Enter an integer(>1): '))
i = 2
while i * i <= n:          # 整数运算优于浮点 n**0.5
    if n % i == 0:
        print(f'{n} is not a prime.')
        break              # 找到约数，提前终止
    i += 1
else:                      # 未被 break 打断 → 自然结束 → 是素数
    print(f'{n} is a prime.')
```

[注意] `while` 中的 `continue` 若跳过了循环变量的更新语句,
就会变成死循环. 例如输出奇数时把 `i += 1` 写在 `continue` 之后:

```python
i = 0
while i < 10:
    if i % 2 == 0:
        continue      # 偶数时直接回到循环头，i 永远不增加 → 死循环
    print(i, end=' ')
    i += 1
```

正确写法是把 `i += 1` 放到 `continue` 之前,
或用 `for i in range(10)`(循环变量自动变化)

## 5.4 循环嵌套与优化

循环体内再写循环构成嵌套, 用于处理二维数据(行 × 列); 嵌套会显著放大执行次数,
需注意把与循环变量无关的计算提到外层

(1) 外层循环每执行一次, 内层循环完整执行一遍
(2) `break` 只跳出它所在的那一层循环
(3) 优化原则: 避免不必要的嵌套; 把与循环变量无关的计算移到循环外; 多重嵌套时尽量把内层的不必要计算向外提

```python
# 九九乘法表（下三角）
i = 1
while i < 10:          # 行循环
    j = 1
    while j <= i:      # 列循环，只到第 i 列
        print(f'{i}*{j}={i*j}', end='\t')
        j += 1
    print()            # 每行结束换行
    i += 1
```

```python
# 水仙花数：各位数字的立方和等于自身
n = 100
while n < 1000:
    units = n % 10
    tens = n // 10 % 10
    hundreds = n // 100
    if units**3 + tens**3 + hundreds**3 == n:
        print(n)       # 153 370 371 407
    n += 1
```

## 5.5 循环的选择: while 还是 for

`while` 用于次数不确定(由条件决定)的循环, `for` 用于次数可确定,
或需要枚举序列/可迭代对象元素的循环

(1) `while`: 循环变量由程序语句控制变化, 条件驱动
(2) `for 变量 in 可迭代对象:` 循环变量每轮自动更新, 无需手写 `i += 1`
(3) 两者可互相嵌套, 也可互换, 但选用更贴合语义的一种可减少出错

```python
# 输入 3 个非零整数求和：for 版本更安全（次数确定）
total = 0
for i in range(3):
    x = int(input('Enter an integer: '))
    if not x:
        continue       # 输入 0 则跳过本轮，但仍占一次循环
    total += x
print('The sum is:', total)
```

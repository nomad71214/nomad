## 3.1 条件表达式

选择与循环结构都依据条件表达式的真假(`True`/`False`)决定执行路径;
Python 中任何合法表达式都可作条件, 非 0, 非空即视为真

(1) 与 `False` 等价的值: `0`, `0.0`, `0j`, `''`, `None`,
空列表/空元组/空字典/空集合
(2) 条件的构成: 算术运算符, 关系运算符, 逻辑运算符(含短路), 测试运算符 `is / is not`
(3) 条件中不允许使用赋值号 `=`
`if a = 3:` 会抛 `SyntaxError`(从语言层面避免 `==`
误写为 `=`)

```python
if 3:                 # 非零整数作条件，等价于 True
    print(5)          # 输出 5

a, b = 3, 4
print(a is b, a is not b)   # False True
```

## 3.2 单分支与双分支

`if` 单分支在条件为真时执行语句块; `if...else` 双分支保证两个语句块中有且仅有一个被执行

(1) 单分支: `if 条件表达式:` + 缩进语句块(≥1 条语句); 条件为假时什么也不做
(2) 双分支: `if 条件:` / `else:`, 两分支互斥
(3) 语句块以 `:` 开始, 以缩进界定, 缩进结束即代码块结束
(4) `pass` 是空语句, 可作占位符(`if x < 0: pass  # TODO`)
(5) 双分支可用条件表达式(三元运算)简写: `expr1 if condition else expr2`

```python
x, y = 3, 5
if x > y:
    x, y = y, x       # 条件成立才交换

if x % 2 == 0:
    print('x is even')
else:
    print('x is odd')

# 双分支表达式：把 if-else 写成一行
print('even' if x % 2 == 0 else 'odd')
```

## 3.3 多分支与嵌套

`elif`(else if 的缩写)实现多路选择, 各分支相互排斥, 一旦某条件成立, 其余条件不再判断;
选择结构可层层嵌套, 但嵌套过深会显著降低可读性

(1) 结构: `if 表达式1:` / `elif 表达式2:` / `elif 表达式3:` / `else:`,
`elif` 可有任意多个
(2) 判断自上而下短路: 命中即跳出整个结构
(3) 嵌套时各层缩进必须正确且逐层加深(每层 4 个空格)
(4) 能用 `elif` 平铺时不要用嵌套, Python 官方建议尽量避免深层嵌套条件

```python
score = int(input('Enter score (0<=score<=100): '))
if score > 100:
    print('Wrong score which must <= 100.')
elif score >= 90:      # 已隐含 score <= 100
    print('A')
elif score >= 80:
    print('B')
elif score >= 70:
    print('C')
elif score >= 60:
    print('D')
elif score >= 0:
    print('F')
else:
    print('Wrong score which must >= 0')
```

[注意] `elif` 分支的条件不必重复写上下界(如 `90 <= score <= 100`)
因为前面的分支已被排除;
重复写反而容易写错区间导致漏判

## 3.4 代码缩进规范

Python 用缩进(而非花括号)表示语句块的从属关系,
缩进错误会直接导致程序逻辑错误或 `IndentationError`

(1) 行尾出现 `:` 表示缩进即将开始(选择结构, 循环结构, 函数定义等)
(2) 同一级别的代码块缩进量必须完全相同; 以 4 个空格为基本缩进单位
(3) 反缩进表示当前代码块结束(由程序员手动控制)
(4) 建议: 运算符两侧留空格(`1 + 2`), 逗号后留空格(`1, 2`), 不同功能段之间空一行

```python
a, b, c = 3, 4, 5
if a + b > c and b + c > a and c + a > b:   # 三条边能构成三角形
    s = (a + b + c) / 2
    area = (s*(s - a)*(s - b)*(s - c)) ** 0.5   # 海伦公式
    print('area =', area)
else:
    print("Can't make a triangle.")
    area = 0
```

[注意] Tab 与空格混用在同一文件中极易产生"看起来对齐, 实际不对齐"的缩进错误; 统一使用 4 个空格

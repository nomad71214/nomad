## 本章要点

- 函数把重复代码封成模板, 定义时不运行, 调用时才执行函数体
- 形参是定义时的占位名, 实参是调用时传入的对象, 按位置一一对应
- return 结束函数并交回结果, 没有 return 或空 return 都得到 None
- 默认值, 关键参数与 `*para` 让调用更灵活, 可变默认值要写成 None
- lambda 是单表达式的匿名函数, 常配 map 与 sorted 的 key 使用

## 8.1 函数定义与调用

函数把完成某一功能的代码封成模板, 起一个名字, 需要时按名字调用
定义用 `def`, 冒号后换行缩进; 调用写函数名加实参, 实参的值交给形参

讲义用 Fibonacci 数列演示: 把循环里的个数换成形参 m, 结果用 return 交回

规则8-1 `def 函数名(形参列表):` 定义函数, 冒号后换行, 函数体统一缩进
规则8-2 定义只是登记功能, 不调用就不运行函数体, 也不产生结果
规则8-3 调用写 `函数名(实参列表)`, 实参按位置依次交给形参
规则8-4 无参函数也要写空括号, 函数名全小写, 用下划线分词
规则8-5 def 下第一行的字符串是文档注释, 用 `函数名.__doc__` 可读
规则8-6 需要的数据写成形参, 处理过程写成函数体, 结果用 return 交回

例8-1: 把 Fibonacci 数列的前 m 项写成函数, 调用时传入 8
解: 形参 m 控制个数, 返回值是列表, 调用一次就得到一个结果

```python
def fib(m):
    a, b, result = 0, 1, []
    while len(result) < m:
        a, b = b, a + b
        result.append(a)
    return result
print(fib(8))
```
输出: [1, 1, 2, 3, 5, 8, 13, 21]

定义与调用是两件事, 程序走过 def 时只把函数体存起来

例8-2: 在定义之后, 调用之前各放一个 print, 看函数体什么时候运行
解: 输出里 body runs 夹在两个 print 之间, 说明它在调用那一刻才执行

```python
def show():
    print('body runs', end=' ')
print('before', end=' ')
show()
print('after')
```
输出: before body runs after

## 8.2 return 语句

`return` 有两个作用: 立刻结束函数, 把后面的表达式交回调用处
函数可以没有 return, 可以有多条, 也可以让 return 后面什么都不写
讲义还讲了 `if __name__ == '__main__':`, 让文件既能直接运行也能被导入

规则8-7 return 立即结束函数, 它后面的语句不再执行
规则8-8 一个函数可有 0 到多条 return, 走到哪条就在哪条返回
规则8-9 `return a, b` 返回一个元组, 接收时可直接解包
规则8-10 没有 return, 或只写 `return`, 函数返回 None
规则8-11 `if __name__ == '__main__':` 内的语句只在直接运行时执行

例8-3: 三个分支各有一条 return, 分别返回元组与空值
解: 正数, 负数各返回 `(值, 说明)` 元组, 0 走到空 return 得到 None

```python
def split_sign(x):
    if x > 0:
        return x, 'positive'
    if x < 0:
        return x, 'negative'
    return
print(split_sign(5), split_sign(-2), split_sign(0))
```
输出: (5, 'positive') (-2, 'negative') None

例8-4: 直接运行时打印 `__name__`, 再看 `__main__` 块的写法
解: 脚本直接运行, `__name__` 的值就是 `__main__`, 块内语句照常执行

```python
def fib(m):
    return [1, 1, 2, 3, 5][:m]
if __name__ == '__main__':
    print(__name__, fib(3))
```
输出: __main__ [1, 1, 2]

## 8.3 形参与实参

定义函数时写下的名字是形参 (parameter), 调用时给的值是实参 (argument)
实参按位置把值交给形参, 个数要相等, 顺序决定谁得到谁

Python 定义时不写类型, 类型不合适要到调用时才抛 `TypeError`

规则8-12 形参是定义时的名字, 实参是调用时传入的对象
规则8-13 实参个数与形参个数必须一致, 顺序决定对应关系
规则8-14 实参可以是任意对象, 能做什么由函数体内的操作决定
规则8-15 形参与实参同名互不影响, 各在各的作用域里

例8-5: 计算圆面积, 先判断参数是不是数值
解: `isinstance` 一次判断两种类型, 不符就返回提示串, 不抛异常

```python
from math import pi as PI
def circle_area(r):
    if isinstance(r, (int, float)):
        return PI * r * r
    return 'Radius must be an integer or a float!'
print(round(circle_area(2), 4), circle_area('2'))
```
输出: 12.5664 Radius must be an integer or a float!

例8-6: 接收一个可迭代对象, 返回平均值与大于平均值的元素
解: 形参 para 只要支持 `sum` 与 `len` 就行, 列表与元组都能传

```python
def above_avg(para):
    avg = sum(para) / len(para)
    g = [i for i in para if i > avg]
    return (avg,) + tuple(g)
print(above_avg([1, 2, 3, 4, 10]), above_avg((2, 4, 6)))
```
输出: (4.0, 10) (4.0, 6)

## 8.4 参数类型

讲义把参数玩法分成四类: 默认值, 关键参数, 可变长度参数与序列解包, 见表8-1

表8-1 四类参数一览

| 写法 | 出现位置 | 作用 |
| --- | --- | --- |
| `形参=值` | 定义 | 不传就用默认值 |
| `形参名=值` | 调用 | 按名字传, 顺序无关 |
| `*para` | 定义 | 多出的实参收成元组 |
| `*序列` | 调用 | 把序列摊成多个实参 |

### 8.4.1 默认值参数

默认值让常用的取值不必每次写, `print` 的 `sep` 与 `end` 就是例子
`函数名.__defaults__` 以元组形式给出全部默认值, 便于核对
默认值只在 def 执行时求值一次, 可变对象当默认值会被多次调用共享

规则8-16 默认值写在形参后面, 写成 `形参=值`, 不传就用它
规则8-17 带默认值的形参必须排在没有默认值的形参右边
规则8-18 默认值在 def 执行时求值一次, 之后所有调用共用这个对象
规则8-19 可变类型不作默认值, 需要时写 None, 进函数后再新建

例8-7: 第一次把列表当默认值, 第二次改用 None, 各连调两次
解: 前者两次共用同一个列表, 后者每次进函数都新建, 互不影响

```python
def func(item, lst=[]):
    lst.append(item)
    return lst
def func2(item, lst=None):
    lst = [] if lst is None else lst
    lst.append(item)
    return lst
print(func('a'))
print(func('b'), func.__defaults__)
print(func2('a'), func2('b'), func2.__defaults__)
```
输出: ['a']
      ['a', 'b'] (['a', 'b'],)
      ['a'] ['b'] (None,)

### 8.4.2 关键参数

调用时写 `形参名=值` 就是关键参数, 名字对上了, 顺序就不再重要
`print` 的 `sep` 与 `sorted` 的 `reverse` 只能这样传, 不能按位置传

规则8-20 关键参数写成 `形参名=值`, 顺序可与定义不同
规则8-21 关键参数必须跟在位置参数后面, 同一形参不能赋两次
规则8-22 内置函数带默认值的参数, 只能用关键参数方式传

例8-8: 同一个函数分别用位置参数与关键参数调用
解: 三种写法的实参对应关系相同, 只是书写的顺序不同

```python
def demo(a, b, c=5):
    return a, b, c
print(demo(3, 7), demo(a=7, b=3, c=6), demo(c=8, a=9, b=0))
```
输出: (3, 7, 5) (7, 3, 6) (9, 0, 8)

### 8.4.3 可变长度形参

形参前加一个星号就能接收任意多个实参, 收进一个元组, 不传就是空元组
写在 `*para` 位置的形参负责兜底, 调用时实参个数不限

规则8-23 `*para` 把多出的实参收进一个元组, 可以一个都不收
规则8-24 几种参数混用时, 默认值形参排在 `*para` 的左边

例8-9: 定义一个收任意个实参的函数, 再与普通形参混用
解: 位置参数先分给 a, b, c, 剩下的全部进入 p

```python
def demo(*para):
    return para
def func(a, b, c=4, *p):
    return a, b, c, p
print(demo(1, 2, 3), demo(), func(1, 2, 3, 4, 5, 6))
```
输出: (1, 2, 3) () (1, 2, 3, (4, 5, 6))

### 8.4.4 序列解包传参

调用时在序列前加星号, 元素摊开按位置分给形参, 列表与元组都能摊
字符串也能摊, 摊开的个数与形参不符时抛 `TypeError`

规则8-25 调用时 `*序列` 把元素摊开, 按位置分给各形参
规则8-26 摊开的元素个数与形参个数不符时抛 `TypeError`

例8-10: 用列表, 元组与字符串分别摊开传参
解: 三个元素恰好对上三个形参, 字符串摊开得到三个单字符

```python
def total(a, b, c):
    return a + b + c
lst, tup = [1, 2, 3], (4, 5, 6)
print(total(*lst), total(*tup), total(*'abc'))
```
输出: 6 15 abc

## 8.5 变量作用域

变量能起作用的范围叫作用域, 分局部与全局两种
函数内赋值的变量是局部变量, 外面定义的是全局变量, 外面找不到局部名

### 8.5.1 局部变量

函数内定义的变量只在函数内有效, 形参也算局部变量
不同函数可以给形参起同一个名字, 各用各的互不干扰

规则8-27 函数内赋值的名字是局部变量, 函数结束即销毁
规则8-28 形参也是局部变量, 不同函数的同名形参互不干扰

### 8.5.2 全局变量

函数内只读取全局变量时, 可以直接用这个名字; 一旦赋值就变成局部变量
要在函数内改外面的变量, 先用 `global` 声明

规则8-29 函数内只读全局变量可直接用, 一旦赋值就变成局部变量
规则8-30 要在函数内改全局变量, 先用 `global` 声明
规则8-31 可变对象作实参时, 函数内的原地增删改会反映到函数外

例8-11: 一个函数只赋值, 另一个函数用 global 声明
解: 前者改了局部的 x, 外面的仍是 5; 后者才真正改到全局

```python
x = 5
def local():
    x = 3
    return x
def change():
    global x
    x = 3
print(local(), x, end=' | ')
change()
print(x)
```
输出: 3 5 | 3

例8-12: 一个函数原地改列表, 另一个函数只是重新绑定名字
解: 追加元素改的是同一个列表, 重新赋值只改了形参指向

```python
def modify(lst):
    lst.append(0)
def rebind(lst):
    lst = [9]
a, b = [2], [2]
modify(a)
rebind(b)
print(a, b, a is b)
```
输出: [2, 0] [2] False

## 8.6 lambda 表达式

lambda 用来声明匿名函数, 适合只在一处用一次的小函数
写法是 `lambda 形参: 表达式`, 表达式就是返回值, 只能写一个表达式
它和 def 定义的小函数等价, 只是没有名字, 用完即弃

规则8-32 `lambda 形参: 表达式` 生成匿名函数, 值是返回值
规则8-33 lambda 体只能是一个表达式, 不能写赋值与循环语句
规则8-34 lambda 可带默认值形参, 也可用关键参数调用
规则8-35 lambda 可放进列表等容器, 用下标取出后加括号调用
规则8-36 `map(func, iterable)` 把函数作用到每个元素, 返回迭代器
规则8-37 `sorted(iterable, key=函数)` 按 key 的返回值排序, reverse 反向

例8-13: 用 lambda 写加法, 放进列表, 再交给 map
解: `lst[1]` 取出第二个 lambda, 加括号才是调用; map 要用 list 转

```python
f = lambda x, y, z: x + y + z
lst = [lambda x: x ** 2, lambda x: x ** 3]
print(f(1, 2, 3), lst[1](2), list(map(lambda x: x + 5, [1, 2])))
```
输出: 6 8 [6, 7]

例8-14: 按长度排序, 再让元组先按首项升序, 首项相同按第二项降序
解: key 收到每个元素, 返回什么就按什么比大小, 负号翻转次序

```python
names = ['Tom', 'Bob', 'Alice', 'Ed', 'Anna']
lst = [(5, 78), (2, 22), (7, 73), (2, 77), (5, 31)]
print(sorted(names, key=len))
print(sorted(lst, key=lambda x: (x[0], -x[1])))
```
输出: ['Ed', 'Tom', 'Bob', 'Anna', 'Alice']
      [(2, 77), (2, 22), (5, 78), (5, 31), (7, 73)]

## 8.7 案例精选

把要做的处理写进函数体, 把操作对象留给实参, 是本节几个例子的共同点

规则8-38 循环左移 k 位可写成 `lst[k:] + lst[:k]`
规则8-39 `enumerate` 配 `min` 可一次取出最小值的全部下标

例8-15: 列表循环左移 3 位, 用切片与逐位搬移两种写法
解: 切片写法生成新列表; 逐位写法把首元素弹出再接到尾部

```python
def rotate_slice(lst, k):
    return lst[k:] + lst[:k]
def rotate_inplace(lst, k):
    for _ in range(k):
        lst.append(lst.pop(0))
a = list(range(1, 11))
b = a[:]
print(rotate_slice(a, 3))
rotate_inplace(b, 3)
print(b == rotate_slice(a, 3), b[:3])
```
输出: [4, 5, 6, 7, 8, 9, 10, 1, 2, 3]
      True [4, 5, 6]

例8-16: 找最小值及它的全部下标
解: 推导式筛出所有等于最小值的下标, 再与最小值拼成元组

```python
def search_min(lst):
    result = [i for i, v in enumerate(lst) if v == min(lst)]
    return tuple([min(lst)] + result)
print(search_min([3, 1, 4, 1, 5, 1]))
```
输出: (1, 1, 3, 5)

## 常见错误

表8-3 本章五类典型错误

| 错在哪里 | 为什么错 | 怎么改 |
| --- | --- | --- |
| `def f(a=1, b):` | 带默认值的形参不在最右 | 把 b 放到 a 前面 |
| `def f(x, lst=[])` | 默认列表只建一次, 多次调用共享 | 改成 `lst=None` 再新建 |
| 函数内 `x = 3` 想改全局 | 赋值后 x 成了局部变量 | 先写 `global x` |
| `demo(1, a=2)` | 同一形参被位置与名字各赋一次 | 一个形参只赋一次 |
| `f(*[1, 2])` 而 f 要三个参数 | 摊开后元素个数不足 | 补齐元素或改形参 |

## 对照与迁移

C 的函数要写返回类型, 参数要写类型; Python 都不写, 类型到运行时才核对
C 传值是复制, 想改调用者的变量得传指针; Python 传的是对象引用
改可变对象的内部会反映出去, 给形参重新赋值则不会

C 的函数指针与 Python 的函数对象对应, lambda 相当于就地写的小函数
C++ 的默认参数与函数重载, 在 Python 里靠默认值与 `*para` 完成

表8-4 C 与 Python 的函数对照

| 项 | C | Python |
| --- | --- | --- |
| 定义 | `int f(int a)` | `def f(a):` |
| 返回类型 | 必须写 | 不写, 由 return 决定 |
| 无返回值 | `void` | 返回 None |
| 默认参数 | 无 | `def f(a, b=2)` |
| 可变参数 | `...` 与 `va_list` | `*para` |
| 传参 | 值传递, 指针模拟引用 | 传对象引用 |
| 小函数 | 函数指针 | lambda 表达式 |

## 自测

(1) 只写 def 而不调用, 函数体会不会执行, 为什么
(2) 函数没有 return, 或只写 `return`, 调用结果分别是什么
(3) `def f(a, b=2, *c)` 被 `f(1, 3, 4, 5)` 调用时, 三个形参各是什么
(4) 函数内写了 `x = 3`, 外面的 x 会不会变, 怎样才会变
(5) `sorted(lst, key=lambda x: -x[0])` 的排序效果是什么

## 参考答案

(1) 不会. def 只登记函数体, 不调用就不运行, 也不产生任何结果
(2) 都返回 None. 前者没有 return 语句, 后者 return 后没有表达式
(3) a 为 1, b 为 3, c 为 `(4, 5)`. 位置参数先分, 多余的进元组
(4) 不变. 函数内赋值得到的是局部变量, 要先 `global x` 才改到外面
(5) 按每个元素的第一项降序排列, 第一项相同时保持原有先后

## 4.1 字符编码与源文件编码

字符在计算机中以编码保存; Python3 源文件默认 UTF-8, 若需兼容其他编码, 可在文件首行加编码声明

(1) 常见编码: ASCII(单字节, 仅英文), UTF-8(1~6 字节表示一个字符),
GB2312/GBK(英文 1 字节, 中文 2 字节), CP936(微软在 GBK 上扩展)
(2) `locale.getencoding()` 可查看本机默认编码(中文 Windows 通常为 `cp936`)
(3) Python2 默认 ASCII, Python3 默认 UTF-8
(4) 编码声明(魔法注释)写在首行或第二行: `# coding: utf-8` 或
`# -*- coding: utf-8 -*-`
(5) 显式编码声明优先于默认声明

```python
# -*- coding: utf-8 -*-
import locale
print(locale.getencoding())   # 如 'cp936'
```

## 4.2 字符串的表示与转义

字符串是由字符组成的有序序列; 单行用 `'...'` 或 `"..."`,
多行用 `'''...'''` 或 `"""..."""`, 反斜杠 `\` 用于转义特殊字符

(1) 单行字符串不能跨行; 界定符(引号)本身不输出; 空串 `''` 或 `""`
(2) 多行字符串保留换行, 交互模式下显示为带 `\n` 的形式, `print()` 输出真实换行
(3) 常见转义: `\'` 单引号, `\"` 双引号, `\\` 反斜杠, `\n` 换行, `\t` 制表符,
`\ddd` 三位八进制, `\xhh` 两位十六进制
(4) `\141` 与 `\x61` 都表示字符 `'a'`
(5) 原始字符串 `r'...'`: `\` 不转义, 但最后一个字符不能是 `\`

```python
a = '''first line
line 2'''
print(a)              # 输出两行

print('c:\note')      # \n 被转义成换行 → 输出 c: 换行 ote
print(r'c:\note')     # 原始字符串 → 原样输出 c:\note
print('Name\tAge\nLucas\t18')   # \t 对齐，\n 换行
print('\141b\x61')    # aba：八进制与十六进制转义
```

[注意] 路径 `'c:\note'` 中的 `\n` 会被当成换行符;
写路径要用 `'c:\\note'` 或 `r'c:\note'`. 另注意 `/`(斜杠)与
`\`(反斜杠)含义完全不同

## 4.3 字符串运算

字符串支持 `+`(拼接), `*`(重复), 比较运算以及成员测试, 但不支持与其他类型直接相加

(1) `+`: 把两个字符串合并为新字符串(不修改原对象)
(2) `*`: 字符串与整数相乘表示重复; 整数 `<= 0` 时得到空串
(3) 比较运算 `> >= < <= == !=`: 按字符的编码值逐个比较, 前缀相同则更长的字符串更大
(4) `in / not in`: 成员测试, 判断子串是否存在
(5) 与数值运算的区别: `'4' + '2'` 得 `'42'`, `4 + 2` 得 `6`

```python
print('abc' + '123')   # abc123，生成新对象
print('*-' * 3)        # -*-*-*-
print('ab' < 'ac')     # True，逐字符比较编码
print('ab' < 'abc')    # True，前缀相同则更长者更大
print('bcd' in 'abcde')   # True
```

[注意] 整数 `2` 与字符串 `'2'` 是完全不同的数据 ,  前者存二进制 `10`,
后者存字符 `'2'` 的 ASCII 码 50 的二进制. 混用会得到拼接结果或 `TypeError`

## 4.4 字符串分割与格式化

格式化把对象按指定样式转换为字符串, Python 有三代方案: `%` 格式化, `str.format()`,
f-string(3.6+, 最简洁)

(1) `s.split(sep=None, maxsplit=-1)`: 按分隔符切分为列表;
`sep` 默认为任意空白符(空格/换行/制表符)
(2) `%` 方式: `format_str % obj`,
需用转换符 `%s %d %f %c %x %o %e %%` 指定类型
1. 格式描述: `%[+][-][0][width][.precision]d/f`, 如 `%07.3f`(宽 7,
    保留 3 位小数, 补 0)
(3) `str.format()` 方式: `'...{}...'.format(obj)`, 可用 `{:c}`,
`{:07.2f}` 等格式符, 无需关心类型
(4) f-string 方式: `f'{obj:format_str}'`, 对象直接嵌入, 最简洁
(5) 通用格式描述符: `{obj:[填充][对齐][+][宽度][.精度][格式符]}`, 对齐用 `^`(居中),
`<`(左), `>`(右)

```python
s = 'apple,peach,banana'
print(s.split(','))        # ['apple', 'peach', 'banana']
print('Fudan\tUniversity \n 220'.split())   # ['Fudan', 'University', '220']

name, age = 'Lucas', 15
print('%s is %d' % (name, age))             # % 方式
print('{} is {}'.format(name, age))         # format 方式
print(f'{name} is {age}')                   # f-string 方式（推荐）

a = 3.1415926
print(f'{a:07.2f}')   # 0003.14，宽 7、2 位小数、补 0
print(f'{a:+.2f}')    # +3.14，带正号
print(f'{a:x^10.2f}') # xxx3.14xxx，居中填充
print(f'{1000000:,}') # 1,000,000，千分位
print(f'{0.25:.2%}')  # 25.00%，百分比
```

[注意] `%` 方式只有一个占位符时右侧直接给值(`'%d' % 5`);
多个占位符时右侧必须是元组(`'%d %d' % (1, 2)`), 单元素元组不能漏逗号

## 4.5 字符串成员访问与常用 BIF

字符串是有序序列, 支持双向索引与切片; 长度, 最大/最小, 进制转换等由内置函数完成

(1) 正向索引从 0 开始, 反向索引从 -1 开始: `s[0]`, `s[-1]`
(2) `len(obj)` 元素个数; `max()/min()` 按编码比较最大/最小字符
(3) `str(x)` 转字符串; `bin(x)`, `oct(x)`,
`hex(x)` 转二/八/十六进制字符串(带前缀)
(4) `type(a) is str` 与 `isinstance(a, str)` 均可判断类型

```python
s = 'hello'
print(s[0], s[-1])      # h o
print(len(s), max(s), min(s))   # 5 o e
print(str(3.4000))      # '3.4'
print(bin(4), oct(25), hex(75)) # 0b100 0o31 0x4b
```

[注意] 字符串是不可变对象, `s[0] = 'H'` 会抛 `TypeError`;
要"改"字符串只能重新赋值生成新字符串

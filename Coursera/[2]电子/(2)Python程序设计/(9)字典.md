## 本章要点

- 字典按键存取, 键须不可变且不重复, 值可以是任意对象
- 创建有四路: 字面量, `dict()` 转换, 关键字参数, `fromkeys`
- `d[k]` 缺键抛 `KeyError`, `get` 与 `setdefault` 则给默认值
- 增删改都围绕键: `update` 合并, `pop` 带返回值, `clear` 清空
- 遍历默认给键, `items()` 给键值对, 统计类问题靠它累积

## 9.1 字典的创建与删除

电话簿存成 `[('Alice', '2341'), ('Beth', '9102')]` 时, 取 Beth 的号码要写 `phonebook[1][1]`
下标 1 与姓名没有关系, 换个顺序就错, 我们希望直接写 `phonebook['Beth']`
字典把"位置"换成"键", 键是什么, 取的时候就写什么, 查找与存放的顺序无关
Python 内部也大量用字典, `globals()` 与 `locals()` 返回的就是变量名到值的映射

规则9-1 字典用 `{键: 值, ...}` 书写, 键值之间用冒号, 元素之间用逗号
规则9-2 键须不可变且不重复, 值可以是任意对象, 列表与字典不能作键
规则9-3 `dict(iterable)` 要求每个元素恰有两个子元素, 二元组与双字符字符串都行
规则9-4 `dict(**kwargs)` 把 `name=value` 形式的关键字参数转成 `'name': value`
规则9-5 `dict.fromkeys(iter, value)` 用 iter 的元素作键, 值统一为 value
规则9-6 字典可以嵌套, `d[k1][k2]` 先取外层字典, 再按内层键取值
规则9-7 `del d[k]` 删除一个键值对, `del d` 删除整个字典名
规则9-8 序列解包字典只取键, `a, b = d` 拿到的是键, 值被丢弃

表9-1 创建字典的几种写法

| 写法 | 示例 | 说明 |
| --- | --- | --- |
| 字面量 | `{'a': 1}` | 直接写出键值对 |
| 二元组序列 | `dict([('a', 1)])` | 每个元素含键与值 |
| 关键字参数 | `dict(a=1)` | 键是参数名 |
| 视图配对 | `dict(zip(ks, vs))` | 两个序列按位置配对 |
| `fromkeys` | `dict.fromkeys('ab', 0)` | 键来自序列, 值相同 |

例9-1: 用五种写法各建一个字典, 再按键取同一个值
解: 后四种都由现成的序列或参数生成, 字面量则直接写出

```python
d1 = {1: 'food', 2: 'drink', 3: 'fruit'}
d2 = dict([('Alice', '2341'), ('Beth', '9102')])
d3 = dict(zip(['Alice', 'Beth'], ['2341', '9102']))
d4 = dict(Alice='2341', Beth='9102')
d5 = dict.fromkeys(['name', 'age'], 0)
print(d1[2], d2['Beth'], d3['Beth'], d4['Beth'], d5['age'])
```
输出: drink 9102 9102 9102 0

例9-2: 建一个带地址的嵌套字典, 取城市与邮编
解: 外层键 `address` 对应的值又是字典, 第二个下标作用在内层

```python
d = {'name': 'Steve', 'age': 25,
     'address': {'city': 'shanghai', 'zipcode': '200433'}}
print(d['address']['city'], d['address']['zipcode'], len(d))
```
输出: shanghai 200433 3

例9-3: 删掉一个键, 再用序列解包把剩下的键分给两个变量
解: `del` 按名删除, 解包按插入顺序把键依次赋给变量

```python
d = {'name': 'Olson', 'gender': 'male', 'age': 19}
del d['gender']
a, b = d
print(a, b, len(d))
```
输出: name age 2

## 9.2 键的读取

字典里的元素没有"第几个"的说法, 取值一律写键
键写错时程序不会给 `None`, 而是直接中断, 所以读取分"确定有"与"可能没有"两种写法
字典保持插入顺序, 遍历按写入的先后输出, 但取值仍只认键

规则9-9 `d[k]` 按键取值, 键不存在时抛 `KeyError`, 错误信息里带键名
规则9-10 `d.get(k, v)` 键不存在时返回 v, v 缺省为 `None`, 字典不变
规则9-11 `d.setdefault(k, v)` 键不存在时写入 `k: v` 再返回 v, 相当于先查后补
规则9-12 `k in d` 判断键是否存在, 等价于 `k in d.keys()`, 与值无关
规则9-13 `keys` `values` `items` 返回视图, 可迭代, `list()` 可转成列表

表9-2 三种取值方式的对比

| 写法 | 键存在 | 键不存在 | 改字典 |
| --- | --- | --- | --- |
| `d[k]` | 返回值 | 抛 KeyError | 否 |
| `d.get(k, v)` | 返回值 | 返回 v | 否 |
| `d.setdefault(k, v)` | 返回值 | 写入并返回 v | 是 |

例9-4: 用下标取已有的键, 再用 `get` 取不存在的键
解: 第二次 `get` 忘了给默认值, 于是得到 `None`, 而不是异常

```python
d = {'name': 'Olson', 'age': 19}
print(d['name'], d.get('address'), d.get('address', 'FDU'))
```
输出: Olson None FDU

例9-5: 用下标取一个没有的键, 捕获 `KeyError` 并打印
解: 异常对象的文本就是键名, 可以拿来提示用户

```python
d = {'name': 'Olson'}
try:
    d['address']
except KeyError as e:
    print(type(e).__name__, e)
```
输出: KeyError 'address'

例9-6: 对比 `setdefault` 在键存在与不存在时的两种行为
解: 第一次什么也不改, 第二次补上 `address`, 所以长度从 2 变成 3

```python
d = {'name': 'Olson', 'age': 19}
print(d.setdefault('name'), d.setdefault('address', 'FDU'), len(d))
```
输出: Olson FDU 3

## 9.3 元素的增删改

`d[k] = v` 一条语句管两件事: 键在就改值, 键不在就新增
删除有四条路, 区别在是否要返回值, 以及键不存在时的行为

规则9-14 `d[k] = v` 键存在时修改值, 键不存在时新增一个键值对
规则9-15 `d.update(other)` 把 other 的键值对逐项写入, 返回 `None`, 原字典被改
规则9-16 `d.pop(k, v)` 删除并返回对应的值, 键不存在时返回 v, 无 v 则抛 `KeyError`
规则9-17 `d.popitem()` 删除并返回最后一对, 顺序是后进先出, 空字典抛 `KeyError`
规则9-18 `d.clear()` 清空全部元素, 字典对象仍在, 只是长度变成 0

表9-3 删除元素的四种写法

| 写法 | 删除什么 | 返回什么 | 键不存在 |
| --- | --- | --- | --- |
| `del d[k]` | 指定键 | 无 | 抛 KeyError |
| `d.pop(k, v)` | 指定键 | 对应的值 | 返回 v |
| `d.popitem()` | 最后一对 | (键, 值) 元组 | 空字典抛 KeyError |
| `d.clear()` | 全部 | None | 无 |

例9-7: 先改已有的 `age`, 再添一个 `address`
解: 两条赋值写法相同, 是改是增由键在不在决定

```python
d = {'name': 'Olson', 'age': 19}
d['age'] = 20
d['address'] = 'FDU'
print(d['age'], d['address'], len(d))
```
输出: 20 FDU 3

例9-8: 用 `update` 一次改一个键, 同时加一个键
解: `update` 返回 `None`, 说明它是原地修改, 不在返回值上做文章

```python
d = {'age': 19, 'name': 'Olson'}
r = d.update({'age': 20, 'city': 'shanghai'})
print(r, d['age'], d['city'], len(d))
```
输出: None 20 shanghai 3

例9-9: 用 `popitem` 弹出最后一对, 用 `pop` 按名删除并取默认值
解: `popitem` 按后进先出, 缺键的 `pop` 拿到默认值 0, 字典此时不变

```python
d = {'age': 20, 'name': 'Olson', 'gender': 'male'}
print(d.popitem(), d.pop('age'), d.pop('c', 0), d)
```
输出: ('gender', 'male') 20 0 {'name': 'Olson'}

## 9.4 遍历与内置函数

遍历字典默认拿到键, 想要值有两条路: 用键再取一次, 或直接遍历 `items()`
内置函数对字典分两类, 只看键的 (len, max, sum) 与可指定 `key` 的排序

规则9-19 `for k in d` 逐个给出键, 循环里写 `d[k]` 才拿到值
规则9-20 `sorted(d)` 按键排序, `sorted(d.items())` 先比键, 键同再比值
规则9-21 `len` `max` `min` `sum` 作用在字典上时只看键, 算值要写 `d.values()`
规则9-22 `zip(d.keys(), d.values())` 与 `d.items()` 的结果相同
规则9-23 `enumerate(d)` 给键配下标, `enumerate(d.items())` 给键值对配下标
规则9-24 `sorted` 的 `key` 参数可换成按值排, 前面加负号就是降序

例9-10: 对一个乱序的字典按键排序, 再对键值对排序
解: `sorted` 不改编原字典, 返回的是新列表

```python
d = {2: 'b', 1: 'a', 3: 'c'}
print(sorted(d), sorted(d.items()))
```
输出: [1, 2, 3] [(1, 'a'), (2, 'b'), (3, 'c')]

例9-11: 对字典求长度, 最大值, 最小值与和
解: 前四个都只看键, 取值的极值要显式写 `d.values()`

```python
d = {2: 'b', 1: 'a', 3: 'c'}
print(len(d), max(d), min(d), sum(d), max(d.values()))
```
输出: 3 3 1 6 c

例9-12: 用 `zip` 配对键与值, 用 `enumerate` 给键编号
解: 前者与 `d.items()` 等价, 后者等于给每个键加一个从 0 起的序号

```python
d = {2: 'b', 1: 'a'}
print(list(zip(d.keys(), d.values())), list(enumerate(d)))
```
输出: [(2, 'b'), (1, 'a')] [(0, 2), (1, 1)]

例9-13: 按分数从高到低输出姓名
解: 排序依据换成 `item[1]`, 加负号把升序变成降序, 再取回姓名

```python
report = {'Thomas': 72, 'Olson': 90, 'Vaughn': 81}
result = sorted(report.items(), key=lambda item: -item[1])
print([name for name, score in result])
```
输出: ['Olson', 'Vaughn', 'Thomas']

## 9.5 字典推导式

推导式把"建空字典, 循环, 赋值"三步压成一行, 大括号里写 `键: 值`
与列表推导式只差括号和冒号, 其余规则照旧

规则9-25 `{键表达式: 值表达式 for 变量 in 序列}` 生成新字典, 原数据不动
规则9-26 末尾加 `if 条件` 过滤, 条件为假的键值对不进入结果
规则9-27 循环可写 `for k, v in d.items()`, 用来按键值互换或按值筛选

例9-14: 用推导式生成 `0` 到 `3` 的"值等于键加一"的字典
解: 表达式两侧都可写算式, 左边是键, 右边是值

```python
print({i: i + 1 for i in range(4)})
```
输出: {0: 1, 1: 2, 2: 3, 3: 4}

例9-15: 用 `zip` 造字典, 再筛出值等于 `'b'` 的键值对
解: 左序列进键, 右序列进值, 筛选写在循环之后

```python
d = {i: j for i, j in zip(range(5), 'abcab')}
print({k: v for k, v in d.items() if v == 'b'}, len(d))
```
输出: {1: 'b', 4: 'b'} 5

## 9.6 字典与函数

字典是可变对象, 传参传的是同一个对象的引用, 函数内改元素等于改外面
这与列表一致, 与整数, 字符串这类不可变对象相反

规则9-28 字典作实参时, 函数内写 `d[k] = v` 改元素, 外部实参同步变化
规则9-29 函数内给形参整体重新赋值, 只换局部名字, 外部字典不变
规则9-30 `**kwargs` 把多余的关键字实参收成一个字典, 与 `dict(**kwargs)` 同源

例9-16: 在函数内给传入的字典加一个键, 看外部的变化
解: 形参与实参指向同一个字典, 加键就是对外部加键

```python
def modify(d):
    d['age'] = 18
a = {'name': 'Mary', 'gender': 'F'}
modify(a)
print(a)
```
输出: {'name': 'Mary', 'gender': 'F', 'age': 18}

例9-17: 用 `**para` 接收任意多个关键字实参, 再与 `dict()` 对比
解: 两者得到的字典相同, `demo` 只是把收集到的参数原样返回

```python
def demo(**para):
    return para
print(demo(x=1, y=2), dict(x=1, y=2))
```
输出: {'x': 1, 'y': 2} {'x': 1, 'y': 2}

## 9.7 两个统计应用

统计类问题的套路相同: 遍历数据, 用键记录"是谁", 用值累积"多少"
没有的键先用 `get(k, 0)` 取一个 0, 加一后再写回, 省掉 if 分支
写成 `if ch not in freq` 的版本结论一样, 只是多一次判断

例9-18: 统计字符串里每个字符出现的次数
解: 每个字符当键, 首次出现记 1, 之后在旧值上加 1

```python
def stat(text):
    freq = {}
    for ch in text:
        freq[ch] = freq.get(ch, 0) + 1
    return freq
print(stat('Hello'))
```
输出: {'H': 1, 'e': 1, 'l': 2, 'o': 1}

例9-19: 求一组成绩的最高分, 最低分, 平均分与最高分学生
解: 三个统计量都作用在 `values()` 上, 姓名则回头遍历 `items()` 筛选

```python
records = {'Moo': 45, 'Norman': 78, 'Olson': 40, 'Peerson': 96}
high = max(records.values())
avg = sum(records.values()) / len(records)
studs = [n for n, s in records.items() if s == high]
print(high, min(records.values()), avg, studs)
```
输出: 96 40 64.75 ['Peerson']

| `d.pop(k, v)` | 删除并返回对应的值 |
| `d.popitem()` | 删最后一对并返回元组 |
| `d.clear()` | 清空全部元素 |

## 常见错误

表9-6 本章五类典型错误

| 错在哪里 | 为什么错 | 怎么改 |
| --- | --- | --- |
| `d['address']` 取不存在的键 | 下标方式没有默认值 | 用 `d.get('address')` |
| `d[[1, 2]] = 1` 用列表作键 | 键须可哈希, 列表可变 | 换成元组 `d[(1, 2)]` |
| 把 `{}` 当成空集合 | `{}` 是空字典 | 空集合写 `set()` |
| 遍历字典时增删键 | 遍历中改长度会抛 RuntimeError | 先 `for k in list(d)` |
| `d2 = d` 后改 `d2` 以为 `d` 不变 | 两个名字指向同一个字典 | 用 `d.copy()` 复制 |

## 对照与迁移

C 里没有内置的键值容器, 按键存值要手写哈希表或写一串 if 比较
Python 的字典把哈希藏在内部, 键的类型放宽到任意不可变对象
C 的数组下标只能是整数, 这与列表一样, 也正是字典要解决的问题

表9-7 C 与 Python 的对应与差异

| 项 | C | Python |
| --- | --- | --- |
| 键值容器 | 手写哈希表或查表函数 | 内置 `dict` |
| 键的类型 | 整数或固定字符串 | 任意不可变对象 |
| 缺键处理 | 返回错误码或 NULL | `KeyError` 或 `get` 默认值 |
| 遍历 | 用下标扫数组 | 遍历键或 `items()` |
| 给默认值 | 三目运算 | `get(k, d)` |

用 C 写词频统计要先定表长, 再处理冲突, 代码量在百行以上
Python 六行就够, 代价是哈希与扩容的开销交给解释器管

## 自测

(1) `{}` 与 `dict()` 分别得到什么, 两者相等吗
(2) `d.get('b', 0)` 与 `d.setdefault('b', 0)` 对 d 的影响有何不同
(3) 为什么列表不能作字典的键, 元组却可以
(4) 写出把 `{'a': 1, 'b': 2}` 的键与值互换的推导式
(5) `sorted({3: 'c', 1: 'a'}.items())` 的结果是什么, 按什么排序

## 参考答案

(1) 都得到空字典, `{} == dict()` 为 True, 但 `{}` 不是空集合
(2) `get` 只读, d 不变; `setdefault` 会写入 `'b': 0`, d 多一个键
(3) 列表可变, 不可哈希; 元组不可变, 可哈希, 所以能作键
(4) `{v: k for k, v in d.items()}`, 结果为 `{1: 'a', 2: 'b'}`
(5) `[(1, 'a'), (3, 'c')]`, 按键从小到大排

## 3.1 switch 语句的穿透

`case` 只是入口标签, 不是边界; 匹配到某个标签后会一路向下执行,
直到遇到 `break` 或 `switch` 的右花括号

(1) `switch (表达式)` 的表达式只能是整型, 字符型或枚举, 不能是浮点或字符串
(2) `default` 可以写在任意位置, 写在前面的 `default` 同样向下穿透
(3) 没有 `break` 就继续执行下一个分支, 这叫穿透 (fall-through)
(4) 最后一段分支不写 `break`, 结果与写 `break` 相同, 因为穿透到 `}` 就结束
(5) 内层的 `break` 只结束内层 `switch`, 外层照常继续穿透
(6) `continue` 不属于 `switch`, 它跳过的是最近外层循环的剩余部分

```c
switch (c) {
default: nn++;          /* default 写在最前面 */
case '0': n0++;         /* 无 break, 继续往下 */
case '1': n1++;
case '2': n2++;         /* 最后一段, 穿透到 } 自然结束 */
}
```

[注意] 判断这类题只需确定"从哪个标签进入", 然后从那里一直加到最后一段

例3-1: 程序统计字符串 `"120119110"` 中各类字符, 循环体为
`switch (s[i++]) { default: nn++; case '0': n0++; case '1': n1++;`
`case '2': n2++; }`, 写出运行结果

解: `n0=3,n1=8,n2=9,nn=1`. 进入标签决定执行链:
`'0'` 进 `case '0'` 加 n0, n1, n2; `'1'` 进 `case '1'` 加 n1,
n2;
`'2'` 只加 n2; `'9'` 进 `default` 四个都加.
9 个字符中 `'1'` 出现 5 次, `'0'` 2 次, `'2'` 1 次, `'9'` 1 次

例3-2: `int i, v1 = 0, v2 = 1, v3 = 2;` 之后循环 9 次,
循环体 `switch (i % 4) { case 1: v1++; case 2: v2++; break;`
`default: v3++; }`, 输出 `v1,v2,v3` 为

解: `3,6,6`. 初值不是全 0, `v2` 与 `v3` 要带上 1 和 2.
`i%4==1` 的 1, 5, 9 三次同时加 v1 与 v2, 得 v1=3, v2=1+3+2=6,
v3=2+2+2=6

例3-3: `int x = 2, y;` 之后 `do switch (x) { case 1: y = 0;`
`case 2: y = 1; case 3: x += 2; continue;`
`case 4: x += y--; default: x++; }`
`while (y >= 1);` 执行后 x 为
A. 3  B. 4  C. 5  D. 6

解: D. 首轮进 `case 2` 得 y=1, 穿透到 `case 3` 使 x=4,
`continue` 跳到 `y>=1` 判断成立; 次轮进 `case 4`, `x += y--` 使 x=5,
y=0,
穿透到 `default` 使 x=6, 条件 `0>=1` 不成立退出

例3-4: `x = 1, y = 0` 时执行外层
`switch (x) { case 1: switch (y) {`
`case 0: a++; break; case 1: b++; break; }`
`case 2: a++; b++; break; case 3: a++; b++; }` 后输出
A. a=1,b=0  B. a=2,b=1  C. a=1,b=1  D. a=2,b=2

解: B. 内层 `break` 只跳出内层, 回到外层 `case 1` 之后,
那里没有 `break` 便穿透到 `case 2`,
再执行 `a++` 与 `b++` 后遇 `break` 退出;
`case 3` 到不了

## 3.2 悬挂 if 与花括号

`if` 不带花括号时, 语句体只有紧跟其后的那一条语句;
而 `if` 本身也是一条语句, 所以嵌套 `if` 中外层条件不成立时, 内层整体被跳过

(1) 外层条件为假, 内层条件根本不会被求值
(2) `else` 永远与离它最近的那个尚未配对的 `if` 结合
(3) 想让 `else` 属于外层 `if`, 必须给内层 `if` 加花括号
(4) 出现嵌套 `if` 时一律加 `{}`, 这是唯一可靠的写法

```c
if (a < b)
    if (b > c)      /* 这是外层 if 唯一的语句体 */
        { a = c; c = b; }
/* 后面的 printf 不属于任何 if, 总会执行 */

if (a < b) {
    if (b > c) x = 1;
} else {
    x = 2;          /* 加括号后 else 才属于外层 */
}
```

[注意] 两个 `if` 的缩进看起来像并列, 实际是嵌套, 不能让"都成立才执行"

例3-5: `int a = 8, b = 7, c = 6;` 之后执行
`if (a < b) if (b > c) { a = c; c = b; }` 再
`printf("%d,%d,%d")` 输出
A. 6,7,7  B. 6,7,8  C. 8,7,6  D. 8,7,8

解: C. `a<b` 即 `8<7` 为假, 整个内层 `if` 被跳过, 三个变量保持初值;
选项 A 是漏看外层条件的结果, 把 `a` 改成 1 才会输出 6,7,7

## 3.3 do-while 与循环条件的恒真

`do-while` 先执行循环体再判断条件, 循环体至少执行一次;
而 `1 <= x <= 2` 这类连写不等式的值恒为真, 常被用来制造"靠 break 退出"的循环

(1) `1 <= x <= 2` 即 `(1 <= x) <= 2`, 左边的结果 0 或 1 都小于等于 2, 恒真
(2) 表达区间必须写 `x >= 1 && x <= 2`
(3) `do-while` 的循环体先跑一遍, 条件不成立也至少跑一次
(4) 循环靠 `break` 提前结束时, 循环后的变量要按最后一轮重新算
(5) `!y` 等价于 `y == 0`, 是"取到 0 就停"的常见写法

```c
int y, x = 3;
do {
    y = x--;              /* 先取值再自减 */
    if (!y) { printf("*"); break; }
    printf("#");
} while (1 <= x <= 2);    /* 恒真, 实际靠 break 退出 */
/* 输出 ###*, 退出时 x = -1, y = 0 */
```

[注意] 判断退出条件时不要按数学直觉, 要按 `(1<=x)<=2` 算

例3-6: 上面这段代码的输出是
A. `###*`  B. `###`  C. `##`  D. 以上都不对

解: A. x 依次为 3, 2, 1, 0, 前四轮 y 得 3, 2, 1, 0,
只有第四轮 `!y` 成立, 所以打三个 `#` 后打一个 `*` 并 break

例3-7: 同一段代码末尾再加 `printf("\nx=%d,y=%d", x, y);`, 输出为

解: 第一行 `###*`, 第二行 `x=-1,y=0`.
最后一轮 `y = x--` 取走 0 之后 `x` 已减到 -1

## 3.4 for 循环的执行顺序

`for (初值; 条件; 增量)` 的执行顺序是 初值 → 条件 → 循环体 → 增量 → 条件,
增量在循环体之后才执行, 循环体里也能改循环变量

(1) 循环结束时变量的值, 就是第一个使条件失败的取值, 不必再推一步
(2) 增量表达式可以是任意表达式, 如 `n = 2 * n + 1`, 不限于 `n++`
(3) 三个表达式都可省略, 但两个分号不能少
(4) 中间条件省略即恒真, `for (;;)` 与 `while (1)` 等价
(5) 两个分号把三个位置隔开, 写错位置语义完全不同
(6) 循环体是分号时为空语句, 循环只做条件与增量的迭代

```c
int n;
for (n = 0; n < 100; n = 2 * n + 1);   /* 分号即空循环体 */
/* n 依次 0, 1, 3, 7, 15, 31, 63, 127, 到 127 时条件失败 */

int a;
for (a = 0; a <= 5; a++)
    a += 2;            /* 循环体也在改 a, 退出时 a = 6 */
```

[注意] 循环体改循环变量时不要心算, 逐轮列表最稳;
初值 `int a = 5;` 会被 `for` 的初始化立刻覆盖

例3-8: `int a = 5;`
`for (a = 0; a <= 5; a++) a += 2;` 执行后 a 为
A. 5  B. 6  C. 7  D. 8

解: B. 第一轮 a 从 0 加到 2 再自增得 3, 第二轮 3 加到 5 再自增得 6,
条件 `6<=5` 失败退出

例3-9: `int n;`
`for (n = 0; n < 100; n = 2 * n + 1);` 执行后 n 为
A. 125  B. 126  C. 127  D. 128

解: C. n 取 0, 1, 3, 7, 15, 31, 63, 127,
到 127 时条件已失败, 不会再算 2*127+1

## 3.5 continue 与 break

`continue` 结束本次循环直接进入下一轮, `break` 结束整个循环;
`continue` 跳过后面的语句, 所以累加类程序用它做筛选

(1) `continue` 跳过本轮剩余语句, 立刻求下一次条件
(2) `break` 跳出整个循环, 循环后的语句继续执行
(3) 功能类题目要用完整句子描述, 不能只写"求和"
(4) 先累加再更新的循环里, 每轮取的是更新前的值
(5) 交替符号题用 `s = -1 * s` 配合分母步长 2
(6) 浮点除法要写 `4.0 / i`, 写 `4 / i` 会得整数商

```c
int i, sum = 0, a[5] = {2, 4, 6, 8, 10};
for (i = 0; i < 5; i++) {
    if (a[i] % 4 == 0) continue;   /* 能被 4 整除的跳过 */
    sum += a[i];
}
printf("sum = %d", sum);           /* sum = 18 */
```

[注意] 把 `continue` 改成 `break`, 结果会变成 `sum = 2`;
前者结束本次, 后者结束整个

例3-10: 上面这段程序的功能与输出是

解: 功能为把数组 `a` 中所有不能被 4 整除的元素累加求和, 输出 `sum = 18`.
4 与 8 被跳过, 2 + 6 + 10 = 18

例3-11: `int a = 1, b = 2, c = 10, s = 0;` 之后
`for (i = 0; i < c; ++i) { s += a; a += b; }` 输出 s 为

解: `100`. a 依次取 1, 3, 5, ..., 19 共 10 个奇数, 由前 n 个奇数之和为
n 的平方得 100; b 恒为 2, 只当步长用

例3-12: 用 π = 4/1 - 4/3 + 4/5 - 4/7 + ... 求近似值, 函数
`double PI()`
内 `for (i = 1, s = 1; fabs(t) > EPS; i += 2, s = -1 * s)`
的循环体,
填三处空缺

解: (1) `pi = 0; t = 1;` 两处都要初始化, 只写 `pi = 0;` 时 t 为 0,
条件首次判断即假, 输出 `pi=0.000000`;
(2) `t = 4.0 / i * s;` 必须写 4.0, 否则 `4/3` 走整数除法;
(3) `return pi;`

## 3.6 死循环的判定

判断死循环只看两件事: 循环条件是否恒真, 循环变量是否永不改变;
两条中任意一条成立就是死循环

(1) `while (1)` 与空条件的 `for (;;)` 都是恒真
(2) `for` 的三个位置省略后语义改变, `i < 2` 落在增量位置就只是比较
(3) `k;` 是空转的表达式语句, 不改变 k, 与 `k--;` 完全不同
(4) 取模会把变量压到固定值, 如 `m = m % 10` 对 100 得 0 后再也不变
(5) 递减到 0 的循环会正常结束, `while (s)` 在 s 为 0 时退出

```c
for (i = 0; ; i < 2);   /* 条件空缺为恒真, 增量只是比较 i<2 */
/* i 恒为 0, 死循环 */

int s = 36;
while (s) --s;          /* s 递减到 0 后退出, 共 36 轮 */
```

[注意] 看清三个表达式落在哪个分号之间, 别把增量位置的 `i < 2` 当成条件

例3-13: 下列没有构成死循环的程序是
A. `int m = 100; while (1) { m = m % 10; if (m > 100) break; }`
B. `int s = 36; while (s) --s;`
C. `int k = 1000; do { k; } while (k >= 1000);`
D. `for (i = 0; ; i < 2);`

解: B. `s` 每轮减 1, 减到 0 时条件为假, 共 36 轮.
A 的 m 变成 0 后不再变, `m > 100` 永不成立;
C 的 `k;` 是空转语句, k 恒为 1000;
D 的条件空缺恒真, 增量只比较不赋值

## 8.1 文件打开模式与常用库函数

文件操作固定三步: fopen 打开并判空, 读写, fclose 关闭;
打开模式决定了能不能读, 能不能写, 原内容会不会被清空

(1) r 系列要求文件已存在, 不存在时 fopen 返回 NULL
(2) w 系列不存在就新建, 已存在就先清空, 内容全丢
(3) a 系列不清空, 只能在末尾追加, 改不了中间内容
(4) 就地修改只能用 `"r+"`, 可读可写且不清空
(5) `"w+"` 也能读能写, 但它打开就清空, 原内容保不住
(6) `"rb"` `"wb"` 是二进制模式, 不做换行符转换
(7) 更新流写后要读或读后要写, 中间必须插 fseek, rewind 或 fflush

表8-1 文件打开模式 (C89)

| 模式 | 读 | 写 | 不存在时 | 已存在时 |
| --- | --- | --- | --- | --- |
| "r" | 是 | 否 | 返回 NULL | 从头读, 不清空 |
| "w" | 否 | 是 | 新建 | 先清空 |
| "a" | 否 | 是 | 新建 | 追加到末尾 |
| "r+" | 是 | 是 | 返回 NULL | 不清空, 就地改 |
| "w+" | 是 | 是 | 新建 | 先清空 |
| "a+" | 是 | 是 | 新建 | 读从头, 写只在末尾 |

表8-2 常用文件库函数 (C89)

| 函数 | 作用 | 备注 |
| --- | --- | --- |
| fopen / fclose | 打开与关闭 | 返回 FILE *, 必须判空 |
| fgetc / fputc | 读写一个字符 | 读到结尾返回 EOF |
| fgets | 读一行 | 最多 n-1 字符, 保留换行 |
| fscanf | 格式化读 | 返回成功项数 |
| fprintf | 格式化写 | f 即 formatted |
| fread / fwrite | 二进制块读写 | 文本文件也能用 |
| fseek | 重新定位 | SEEK_SET/CUR/END |
| ftell / rewind | 取位置, 回开头 |  |

```c
FILE *fp = fopen("data.txt", "r");
if (fp == NULL) {            /* 必须判空 */
    printf("Can not open\n");
    return 1;
}
...
fclose(fp);                  /* 不关闭可能丢数据 */
```

[注意] 函数名中间带 f 的就是"文件版" printf 与 scanf:
fprintf, fscanf, fgetc, fputc, fgets, fputs
`#define MAXN 101;` 会连分号一起替换, 宏定义末尾不加分号

例8-1: 以下文件操作正确的是
A. fread 只能用于文本文件  B. fseek 用于重新定位文件流位置
C. fopen 返回整型文件描述符  D. fprintf 不支持格式化输出

解: B. fread 是二进制块读写但文本文件也能用; fopen 返回 `FILE *`;
fprintf 的 f 就是 formatted, 用法同 printf 只多一个文件指针

例8-2: 要打开已存在的非空二进制文件 hello.txt 并修改, 正确语句是
A. `fopen("hello.txt","r")`  B. `fopen("hello.txt","ab+")`
C. `fopen("hello.txt","w")`  D. `fopen("hello.txt","r+")`

解: D. 已存在且要修改且非空, 三条约束只有 `"r+"` 全满足.
`"r"` 写不进去, `"w"` 先清空, `"ab+"` 写位置被强制到末尾

例8-3: 打开文件写入内容, 哪项正确
(`fp = fopen("file.txt","w"); fprintf(fp, "Hello, world!"); fclose(fp);`)
A. 文件不会被覆盖  B. 文件不存在时会创建空文件
C. fprintf 把文本写入文件  D. 以上都是

解: 材料给 B, 但这题没有唯一答案: 按标准 C 的 B 与 C 都成立,
A 错在 `"w"` 一打开就清空. 需记住的两条: `"w"` 不存在则新建,
已存在则清空重写; fprintf 是向 FILE * 写格式化文本

## 8.2 逐字符读写

逐字符遍历的标准写法是 `while ((ch = fgetc(fp)) != EOF)`,
返回值必须存进 int, 因为 EOF 是负值

(1) `fgetc` 读到文件尾返回 EOF, 这是"读到尾"的判据
(2) `ch` 要声明为 int, 声明成 char 可能装不下 EOF 而死循环
(3) `scanf("%s%*c", s)` 里的 `%*c` 表示读入但丢弃, 用来跳过残留换行符
(4) 打开失败必须立即返回, 否则对 NULL 调用 fgetc 会崩溃
(5) 判断是否字母要写全 `(ch>='A'&&ch<='Z')||(ch>='a'&&ch<='z')`
(6) 用 `fgets` 读行时换行符会被保留, 需要自己处理

```c
int count = 0, ch;                       /* ch 必须是 int */
while ((ch = fgetc(fp)) != EOF)
    if ((ch>='A'&&ch<='Z')||(ch>='a'&&ch<='z'))
        count++;                          /* 只数英文字母 */
fclose(fp);
printf("%d\n", count);
```

[注意] 描述功能要精确到"英文字母(大小写)", 不能笼统说"统计字符个数",
那就把数字也算进去了

例8-4: 说明下面程序的功能 (`scanf("%s%*c", fname)`,
`fopen(fname,"r")` 判空后 `while ((ch = fgetc(fp)) != EOF)`
数字母)

解: 从键盘读入文件名, 以只读方式打开该文本文件,
统计其中英文字母 A 到 Z 与 a 到 z 的总个数并输出.
文件不存在时打印 Can not open 后返回 1;
`%*c` 丢弃缓冲区里残留的换行符

## 8.3 定位与就地改写

要改文件中已有的内容, 必须用 `"r+"` 打开, 趁读到该字符时
用 fseek 回到它的位置再写回, 位置用 ftell 或计数器维护

(1) `"r+"` 可读可写且不清空, 是就地修改的唯一选择
(2) `"w"` 一打开就清空, `"a"` 只能追加, 都改不了中间内容
(3) `fseek(fp, offset, SEEK_SET)` 把位置移到文件的第 offset 字节
(4) fputc 写完位置自然停在下一字节, 但标准要求写后读前要定位
(5) `ch + ('a' - 'A')` 即 ch+32, 比写魔法数字 32 清楚
(6) 计数器 pos 记录当前读到的字节偏移, 改完再移回 pos+1

```c
FILE *file = fopen(filename, "r+");      /* 就地改写的必要条件 */
...
while ((ch = fgetc(file)) != EOF) {
    if (ch >= 'A' && ch <= 'Z') {
        fseek(file, pos, SEEK_SET);       /* ① 回到该字符 */
        fputc(ch + ('a' - 'A'), file);    /* ② 写入小写 */
        fseek(file, pos + 1, SEEK_SET);   /* ③ 移到下一个 */
    }
    pos++;
}
fclose(file);
```

[注意] 更新流(`"r+"` `"w+"` `"a+"`)在写之后要读, 或读之后要写,
中间必须插一个 fseek, rewind 或 fflush, 否则行为未定义

例8-5: 说明程序功能 (以 `"r+"` 打开, 逐字符读到 EOF,
遇大写字母就 fseek 回去改写为小写)

解: 把该文本文件中所有大写字母就地改写成对应的小写字母,
其余字符不变. 不是"统计大写字母", 也不是"大小写互换",
因为题干没有反向操作

## 8.4 文件输出与链表写出

把链表内容写进文件的模板是 fopen 打开判空, 遍历结点 fprintf, 
最后 fclose; 带辅助表元的链表从 `h->next` 开始

(1) `fprintf(fp, "%s\t%d\n", p->word, p->number)` 用制表符与换行分列
(2) 输出到文件用 `"w"`: 不存在就新建, 已存在就清空重写
(3) 打开失败要 `return;` 立即退出, 否则后面会向空指针写入
(4) 覆盖所有字符的数组要开 `长度 + 1`, 留一格给 `'\0'`
(5) 带辅助表元时循环初值写 `p = h->next`, 写 `p = h` 会多输出一行垃圾
(6) `fclose(fp)` 不能省, 否则缓冲区内容可能没落盘

```c
if ((fp = fopen(fname, "w")) == NULL) {
    printf("Can't open %s\n", fname);
    return;                              /* 失败必须返回 */
}
for (p = h->next; p; p = p->next)         /* 跳过辅助表元 */
    fprintf(fp, "%s\t%d\n", p->word, p->number);
fclose(fp);                              /* 不能省略 */
```

[注意] 题目说"单词长度不超过 100"时, 数组要开 101;
`#define MAXN 101` 末尾不加分号

例8-6: 把带辅助表元的链表中 word 与 number 逐行输出到文件,
填 4 处空 (`#define ...`, 打开失败后的语句, 循环初值, 收尾)

解: `#define MAXN 101`; `return;`; `p = h->next`;
`fclose(fp);`.
101 是给 `'\0'` 留位; 失败返回避免向 NULL 写;
辅助表元的 word 是垃圾值不能输出; 不 fclose 会丢缓冲区数据

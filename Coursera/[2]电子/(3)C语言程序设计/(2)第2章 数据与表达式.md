## 2.1 类型转换与整除

表达式结果的类型由参与运算的操作数决定, 与赋值号左边的变量类型无关;
赋值时才发生转换, 浮点转整型一律向零截断

(1) 两个 `int` 相除是整数除法, 余数直接丢弃: `3/2` 得 `1`
(2) 任一操作数为 `double` 则为浮点除法: `3.0/2` 得 `1.5`
(3) 浮点赋给 `int` 向零截断, 不是四舍五入: `(int)2.6` 得 `2`,
`(int)-2.6` 得 `-2`
(4) `%` 只接受整型, 浮点取模必须先强制转换: `(int)f % 3`
(5) 八进制转义 `\010` 按八进制读, 等于 8, 不是 10
(6) 混合类型运算按精度提升: `int` 与 `float` 运算先转 `float`

```c
int i = 3.0 / 2.0;   /* 1.5 赋给 int → 截断为 1 */
double d = 3 / 2;    /* 整数除法得 1 → 1.0 */
int n = (int)13.8 % 3;   /* 13 % 3 = 1 */
```

[注意] 想得到 1.5 必须写 `3.0/2`, `3/2.0` 或 `(double)3/2`;
写成 `double d = 3/2;` 不会把除法变成浮点除法

例2-1: 设有 `int i = 3.0/2.0; double d = 3/2;`, 则 `i` 与 `d` 为
A. 1, 1.0  B. 2, 1.0  C. 1, 1.5  D. 2, 1.5

解: A. 先算右边再转换, `3.0/2.0` 得 1.5 截断为 1,
`3/2` 是整数除法得 1 再转 1.0

例2-2: 若 `int n; float f = 13.8;`
执行 `n = (int)f % 3;` 后 `n`
为
A. 1  B. 4  C. 4.333333  D. 执行报错

解: A. `(int)f` 得 13, `13 % 3` 余 1; 不转换直接 `f % 3` 才编译报错

例2-3: 设有 `char c = '\010'; int x = 10; float y = 1.2;`, 则
`(int)(1.0f*x - c + y/2)` 的值为
A. 1  B. 2  C. 3  D. 4

解: B. `'\010'` 是八进制 8, `10.0 - 8` 得 2.0, `1.2/2` 得 0.6,
相加 2.6, 截断为 2

## 2.2 格式输出与输入

格式串的转换符必须与实参类型匹配, 不匹配不报错但结果错误;
`scanf` 要求传地址, `printf` 要求传值

(1) `scanf("%d", &x)` 必须带 `&`, 漏掉即写坏内存
(2) `scanf` 读 `double` 必须用 `%lf`, 用 `%f` 会按 4 字节写 8 字节变量
(3) `printf` 输出 `double` 时 `%f` 与 `%lf` 都可, 因为可变参数有默认提升
(4) `%d` 打印 `float*` 等指针属实现定义行为, 结果无意义
(5) `%s` 依赖字符串的 `'\0'` 结束符, 数组必须留出这一字节
(6) `char d[2] = {'c', 'h'};` 没有结束符, `printf("%s", d)` 会越界
(7) 字符常量按 `int` 参与运算: `'A' - 'a'` 为 `-32`

```c
double x;
scanf("%lf", &x);        /* double 必须用 %lf 且带 & */
printf("%.2f", x);       /* 输出时 %f 与 %lf 等价 */

printf("%d", 'A' - 'a'); /* 字符按 int 参与运算, 输出 -32 */
```

[注意] `scanf("%f", &x)` 中 `x` 是 `double` 时, 读入的数据本身就错了,
之后无论怎么输出都不对, 这类题的答案常是"以上均不是"

例2-4: 程序 `double x; scanf("%f", &x); printf("%.2f", x);`
输入 `1 .234` 回车, 输出
A. 1.234  B. 1.23  C. 1.00  D. 以上答案均不是

解: D. `%f` 要 `float*`, `&x` 是 `double*`, 读入的字节已被写坏,
换成 `%lf` 才会输出 1.23

例2-5: 同一程序, 输入 `1234 .5678` 回车, 输出
A. 1234.5678  B. 1234.56  C. 1234.00  D. 以上答案均不是

解: D. 错误来自格式串与实参类型不匹配, 与输入的具体数字无关

例2-6: 下列能正确运行的输入输出语句是
A. `int a, *b; scanf("%d", b);`
B. `char d[2]={'c','h'}; printf("%s\n", d);`
C. `float a = 5.0; printf("%d\n", &a);`
D. `float c; scanf("%f", c);`

解: C. A 的 `b` 是野指针, B 缺 `'\0'` 会越界读, D 漏了取地址符 `&`;
C 只是把地址当整数打印, 属于能跑通但无意义

例2-7: 下列代码片段可以正确输出内容的是
A. `printf("%d", 'A'-'a');`
B. `scanf("%d", NULL);`
C. `char str[3]="abc"; printf("%s", str);`
D. `printf("%f", "123.45");`

解: A. `'A'-'a'` 得 -32, 用 `%d` 输出合法;
C 装不下结束符, D 用 `%f` 打字符串地址, 都是未定义行为

## 2.3 自增自减与短路求值

`++` 与 `--` 分为前缀与后缀, 二者对变量的副作用相同, 但作为表达式的值不同;
`&&` 与 `||` 按左到右求值并在结果已定时提前停止

(1) `++a` 的值是自增后的新值, `a++` 的值是自增前的旧值
(2) 优先级: `++` `--` 高于 `&&` 高于 `||`, `&&` 高于 `||`
(3) `&&`: 左边为假即停; `||`: 左边为真即停
(4) 短路是判断"哪个变量被改成什么"的唯一依据
(5) `?:` 只求值被选中的那个分支, 另一分支完全不执行
(6) 非 0 即为真, `-1` 也是真

```c
int a = -1, b = 1, c = 0;
a++ && ++b || c++;   /* 等价于 ((a++) && (++b)) || (c++) */
/* a++ 取 -1 为真, a 变 0; ++b 使 b 变 2 为真;
   || 左边已真 → c++ 不执行, c 仍为 0 */
```

[注意] 只把 `a++` 的值记成旧值还不够, 还要记住它已经把 `a` 加过了

例2-8: 设 `a=-1, b=1, c=0`, 执行 `a++&&++b||c++;` 后三者依次为
A. 0,1,1  B. 0,1,0  C. 0,2,0  D. 0,2,1

解: C. `a++` 取 -1 为真并把 `a` 变 0, `++b` 使 `b` 变 2,
`||` 左边为真直接短路, `c` 不变

例2-9: 设 `int a=0,b=1,c=2,x;` 执行 `x = ++a ? b++ : c++;` 后
A. a=1,b=2,c=3,x=2  B. a=1,b=2,c=2,x=2
C. a=1,b=2,c=2,x=1  D. a=1,b=1,c=3,x=3

解: C. `++a` 使 `a` 变 1 为真, 只求值 `b++`, 其值为旧值 1,
`b` 随后变 2, `c` 完全不参与

例2-10: 执行 `a = b = c = 1; ++a || ++b && ++c;`
后 `a` 与 `b` 为
A. a 不正确, b=1  B. a=0, b=2  C. a=2, b=1  D. a=1, b=0

解: C 与 A. `&&` 高于 `||`, 式子即 `++a || (++b && ++c)`;
`++a` 使 `a` 变 2 为真, 右边整段短路, `b` 与 `c` 保持 1

## 2.4 求值顺序与未定义行为

C 标准只规定运算符的优先级与结合性, 不规定操作数的求值顺序;
两个序列点之间对同一变量修改两次, 或修改后读取, 属未定义行为

(1) 序列点包括 `;`, `&&`, `||`, `?:`, 逗号运算符与函数调用返回处
(2) `j = (++i) + (i++)` 修改两次无确定结果, 属未定义行为
(3) `printf("%d,%d", i, i++)` 实参求值顺序未指定, 结果不确定
(4) 不同变量各自自增一次不构成未定义行为, 结果确定
(5) 判断标准是"同一对象在两个序列点之间被改两次或改后读",
与"表达式里有没有 `++`"无关

```c
int i = 3;
j = (++i) + (i++);    /* 未定义行为: 同一变量两次修改无序列点 */
printf("%d,%d", i, i++);   /* 实参顺序未指定, 结果不确定 */

int a = 5, b = 3;
printf("%d", (a++) + (++b));   /* 两个不同变量, 结果确定为 9 */
```

[注意] 遇到"未定义行为"的题, 不要按"先算左边再算右边"推出具体数字

例2-11: `int i = 3, j; j = (++i) + (i++);` 执行后
A. i=4, j=8  B. i=5, j=9  C. i=5, j=10  D. 结果未定义

解: D. 同一表达式内对 `i` 两次自增且无序列点, 标准判为未定义行为

例2-12: `int i = 3; printf("%d,%d\n", i, i++);` 输出
A. 3,4  B. 3,3  C. 4,4  D. 结果不确定

解: D. 实参求值顺序未指定, 从右往左得 `4,3`, 从左往右得 `3,3`

例2-13: `int a = 5, b = 3;`
`printf("%d\n", (a++) + (++b));` 输出
A. 8  B. 9  C. 10  D. 未定义行为

解: B. `a++` 取 5, `++b` 取 4, 相加 9;
两个自增作用在不同变量上, 不是未定义行为

## 2.5 逗号运算符与复合赋值

逗号表达式的值等于最后一个子表达式的值, 且逗号优先级最低;
`op=` 形式的赋值表达式, 其值等于赋值之后该变量的新值

(1) `(a, b, c)` 的值为 `c` 的值
(2) 逗号优先级低于赋值: `x = a+1, b++` 等价于 `(x = a+1), (b++)`
(3) 复合赋值右结合: `a += a -= a*a` 即 `a += (a -= (a*a))`
(4) 一串复合赋值从最右往左算, 每算一层都在更新同一个变量
(5) `a op= b` 的表达式值就是 `a` 的新值, 可直接参与外层运算

```c
int a = 1, b = 2, c = 3, x;
x = (a+1, b++, ++c);   /* x 取 ++c 的值 4, b 变 3 */

int a2 = 6;
a2 += a2 -= a2 * a2;   /* a2 -= 36 得 -30; a2 += -30 得 -60 */
```

[注意] 复合赋值左侧读的是"赋值那一刻"的当前值,
内层已经把它改过, 外层就不能再用最初的值

例2-14: 设 `int a=1,b=2,c=3,x;` 执行 `x = (a+1, b++, ++c);` 后
`x` 为
A. 2  B. 3  C. 4  D. 报错

解: C. 括号内是逗号表达式, 取最后一个子表达式 `++c` 的值 4

例2-15: `int a = 6; a += a -= a * a; printf("%d", a);` 输出
A. -132  B. -60  C. -24  D. 0

解: B. 右结合, 先 `a -= 36` 使 `a` 为 -30, 再 `a += -30` 得 -60

例2-16: 设 `int k = 7, x = 12;`, 能使表达式值为 3 的是
A. `x %= (k %= 5)`  B. `x %= (k - k % 5)`
C. `x %= k - k % 5`  D. `(x %= k) - (k %= 5)`

解: D. 先 `x %= k` 得 5, 再 `k %= 5` 得 2, 相减为 3;
B 与 C 等价, 都因 `%` 高于 `-` 而得 2

例2-17: 执行 `int i, j, x = 0; i = 3, j = i + 6;`
`x -= j += i;`
后 `x` 为
A. 15  B. -12  C. 10  D. 3

解: B. 先得 `i=3`, `j=9`; `j += i` 使 `j` 变 12 并作为右值,
`x = 0 - 12` 得 -12

## 2.6 优先级与关系运算的结合方向

单目运算符优先级最高; 关系运算符左结合, 因此数学上的连写不等式在 C 中不成立

(1) 单目 `++ -- ! & *` 高于任何二元运算符
(2) 二元由高到低: `* / %` > `+ -` > 关系 > `&&` > `||` > `?:` > 赋值
(3) `10 < a < 15` 即 `(10 < a) < 15`, 恒为 1
(4) 表达"a 在 10 到 15 之间"必须写 `10 < a && a < 15`

```c
int a = 20;
printf("%d", 10 < a < 15);   /* 输出 1, 并非 0 */
printf("%d", 10 < a && a < 15);   /* 这才是范围判断, 输出 0 */
```

例2-18: 下列运算符中优先级最高的是
A. `<`  B. `+`  C. `%`  D. `++`

解: D. `++` 是单目运算符, 高于一切二元运算符

例2-19: 与表达式 `10 < a < 15` 值相等的是
A. `1`  B. `a==11||a==12||a==13||a==14`
C. `0`  D. `!(a<10) && !(a>=15)`

解: A. 左结合使式子恒为 1; D 表达的是数学含义, 值随 `a` 变化

## 2.7 浮点数的比较

浮点数无法精确表示多数十进制小数, 用 `==` 判断相等几乎总是错的

(1) `3.0 - 2.1` 的实际结果是 `0.8999999999999999`
(2) 判断相等应改用容差: `fabs(a - b) < 1e-6`
(3) 关系运算 `<` `>` 可以直接用, 只有判等有风险
(4) 赋值表达式的值等于赋给变量的值: `c = (a>b)` 的值为 1.0

```c
double a = 3.0, b = 2.1, c = 0.9;
printf("%d", a - b == c);          /* 输出 0, 不相等 */
printf("%d", fabs(a - b - c) < 1e-6);   /* 输出 1, 容差比较 */
```

例2-20: 设 `a=3.0, b=2.1, c=0.9`, 下列表达式的值为 0 的是
A. `a>b`  B. `a-b==c`  C. `b++>c`  D. `c=(a>b)`

解: B. 浮点误差使 `a-b` 与 `c` 不等;
A 与 C 为真得 1, D 是赋值表达式, 值为 1.0

## 2.8 逻辑等价与德摩根定律

德摩根定律把"整体的否定"拆成"逐项的否定并翻转连接词",
是化简与判断等价表达式的核心工具

(1) `!(X && Y)` 等价于 `!X || !Y`
(2) `!(X || Y)` 等价于 `!X && !Y`
(3) 取反时比较符同时翻转: `!(a > b)` 即 `a <= b`
(4) `!x` 可读作 `x == 0`, 也可写作 `!(x != 0)`
(5) 区间否定: `|a+b| < 5` 的反面是 `a+b >= 5 || a+b <= -5`

```c
/* 判断 a+b 的绝对值小于 5 */
if (!((a + b) >= 5 || (a + b) <= -5))
    printf("in range\n");

/* 与 !(a > b && a < c) 等价 */
int t = (a <= b) || (a >= c);
```

[注意] 只取反比较符而不换连接词是典型错误,
`!(X && Y)` 写成 `!X && !Y` 不再等价

例2-21: 与 `!(a > b && a < c)` 等价的是
A. `(a<=b)||(a>=c)`  B. `(a>=b)||(a<=c)`
C. `(a>b)||(a<c)`  D. `!(a<b && a>c)`

解: A. 按德摩根拆开, 两个比较符同时翻转

例2-22: `while (!x && !y)` 的条件等价于
A. `!(x==0 && y==0)`  B. `!(x==0 || y==0)`
C. `!(x!=0 || y!=0)`  D. `x = 0 && y = 0`

解: C. 把 `!x` 写成 `!(x != 0)` 后整体取反, `&&` 随之变 `||`

例2-23: 能表示 `|a+b| < 5` 的逻辑表达式是
A. `(a+b) < 5 && (a+b) < -5`
B. `!((a+b) >= 5 && (a+b) <= -5)`
C. `!((a+b) >= 5 || (a+b) <= -5)`
D. `(a+b) < 5 && !((a+b) < -5)`

解: C. 先写出越界条件 `>= 5` 或 `<= -5`, 再整体取反;
A 两个互斥条件用 `&&` 串起来恒为假

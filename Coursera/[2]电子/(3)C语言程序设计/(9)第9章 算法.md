## 9.1 数组的插入与查找

有序数组的插入是"从后往前边找位置边后移", 二分查找是"双闭区间收缩";
两者的共同前提是数组已经有序

(1) 插入要从后往前搬, 从前往后会覆盖还没搬走的数据
(2) 循环条件写 `i >= 0 && a[i] > x`, 用严格大于时新元素插在等值元素之前
(3) 落位写 `a[i + 1] = x`, 因为循环结束时 i 已停在插入点的前一位
(4) 函数返回的是新的实际长度 n, 不是下标
(5) 边界要先处理: 数组已满返回原长度, 数组为空直接写 `a[0]`
(6) 二分用双闭区间, 循环条件必须是 `left <= right`
(7) 收缩必须写 `mid - 1` 与 `mid + 1`, 否则区间不缩小会死循环
(8) `(left + right) / 2` 整数除法自动向下取整, 工程上写
`left + (right - left) / 2` 防溢出

```c
for (i = n - 1; i >= 0 && a[i] > x; i--)
    a[i + 1] = a[i];        /* 边找位置边后移 */
a[i + 1] = x;               /* 落位 */
return n + 1;               /* 返回新长度 */

while (left <= right) {
    int mid = (left + right) / 2;
    if (a[mid] == key) return mid;
    else if (a[mid] > key) right = mid - 1;
    else left = mid + 1;
}
return -1;
```

[注意] 二分的三个条件错一个就死循环: `<=`, `mid - 1`, `mid + 1`;
插入题里把返回值写成下标, 调用处等于把数组截断

例9-1: 在升序数组 a[N] 中原地插入 x, 插入后仍升序,
已满不插入返回原长度, 为空则插入

解: 先判 `n >= N` 返回 n, 再判 `n == 0` 写 `a[0]` 返回 1;
然后 `for (i = n - 1;i >= 0 && a[i] > x; i--) a[i + 1] = a[i];`
最后 `a[i + 1] = x` 并 `return n + 1`.
自测清单: 空数组, 已满, 比所有元素都小, 比所有元素都大, 与已有元素相等

例9-2: 补完 `binary_search`, 找到返回下标, 否则返回 -1

解: 初值 `left = 0` 与 `right = N - 1`
循环条件写 `left <= right`
取 mid 与 key 比较后收缩区间
大于 key 就 `right = mid - 1`
小于就 `left = mid + 1`
出循环返回 -1
验算时 mid 依次为 4, 1, 2, 3, 第四次命中

## 9.2 双指针与有序归并

双指针划分把"该在左边的"和"该在右边的"各找一个再交换;
归并把两条有序链每次取较小的一个, 一条走完就整段接上

(1) 求元素个数的惯用法是 `sizeof(b) / sizeof(int)`
(2) 外层条件是 `i < j`, 两指针相遇就停
(3) 内层两个 while 都必须带 `&& i < j`, 漏了会越界
(4) 交换前再判一次 `i < j`, 否则会把刚换好的又换回去
(5) 每 k 个换一行写 `(k+1) % 5 == 0` 或 `k % 5 == 4`
(6) 归并的两个收尾 while 不能省, 剩余元素要原样搬过去
(7) 比较用 `<=` 保证稳定性, 相等时先取前一个数组的
(8) 输出末尾不带空格要把最后一个单独打印

```c
while (i < j) {
    while (b[i] > 0 && i < j) i++;        /* 跳过已在左边的 */
    while (b[j] <= 0 && i < j) j--;       /* 跳过已在右边的 */
    if (i < j) { int t = b[i]; b[i] = b[j]; b[j] = t; }
}

while (i < n && j < m) {                  /* 归并主体 */
    if (nums1[i] <= nums2[j]) merged[k++] = nums1[i++];
    else                      merged[k++] = nums2[j++];
}
while (i < n) merged[k++] = nums1[i++];   /* 收尾 */
while (j < m) merged[k++] = nums2[j++];
```

[注意] 双指针划分与快排 partition 是同一个模板;
归并的复杂度是 O(n+m) 时间, 数组版多花 O(n+m) 空间, 链表版可做到 O(1)

例9-3: 把 b[M] 中大于 0 的数移到左边, 小于等于 0 的移到右边,
每 5 个一行输出, 补 6 处空

解: `sizeof(b)`; `i < j`; `b[i] > 0`; `j--`; `i < j`;
`(k+1) % 5 == 0`.
例: 输入 `{3,-2,0,5,-1,4,-3,2,0,-5}`
结果为 `3 2 4 5 -1 0 -3 -2 0 -5`
两个 `&& i < j` 不能漏, 漏了 i 会一直加到 M 而越界

例9-4: 合并两个有序数组并按空格分隔输出 (题面未留存, 由代码反推)

解: 双指针 `i, j` 各走一条, 每次取小的写入 merged, 两条收尾 while 搬剩余;
前 n+m-1 个后面跟空格, 最后一个单独 printf 不带空格

## 9.3 前缀和与多数投票

前缀和把区间求和变成两次减法, 用容斥扣除重复加的部分;
多数投票用"抵消法", 不同的数两两抵消, 剩下的候选就是多数元素

(1) 一维前缀和: `s[i] = s[i-1] + a[i]`, 区间和是 `s[r] - s[l-1]`
(2) 二维前缀和: `p[i][j]= m[i][j] + p[i][j-1] + p[i-1][j] - p[i-1][j-1]`
(3) 容斥里左上角那块被加了两次, 最后要减掉 `p[i-1][j-1]`
(4) scanf 读二维数组元素要写 `&matrix[i][j]`, 二维元素是值不是地址
(5) 向上或向左取值的条件是两个下标都 `>= 1`, 用 `&&` 连接
(6) 投票法里 target 是候选, count 是净票数, 相同加一不同减一
(7) count 减到 0 说明候选被抵消光, 重置 target 为 -1 由后面的数接手
(8) 多数元素个数超过一半时, 抵消后剩下的必然还是它

```c
/* 二维前缀和 */
p[i][j] = m[i][j] + p[i][j - 1] + p[i - 1][j] - p[i - 1][j - 1];

/* 多数投票, 抵消法 */
if (target != -1 && target != nums[i]) {
    if (--count == 0) target = -1;
} else {
    target = nums[i];
    count++;
}
```

[注意] 前缀和的 `-1` 下标要靠 `p >= 1 && q >= 1` 挡住;
投票法只选出候选, 严格来说还要再扫一遍确认它真的超过一半

例9-5: 二维前缀和填空 (题面与代码均未留存, 只有 6 个空的答案)

解: `&matrix[i][j]`; `prefixSum[i][j - 1]`;
`prefixSum[i - 1][j]`;
`&&`; `q >= 1`; `prefixSum[p - 1][q - 1]`.
前两空顺序可换, 因为加法满足交换律

例9-6: 说明程序功能与输出 (20 个数的数组, target 与 count 抵消)

解: 求出现次数大于一半的元素, 不存在时为 -1; 输出 4.
4 在 20 个数里出现 11 次, 超过 10

## 9.4 链表排序与归并

链表冒泡只交换 data 而不动结点, 交换结点要改三个指针容易出错;
链表归并复用原有结点, 任何 malloc 新结点的写法都不合要求

(1) 读文件建表用 `while (fscanf(fp, "%d", &x) == 1)`, 不用 `feof`
(2) 尾插两步不能少: `tail->next = p; tail = p;`
(3) 带辅助表元的链表返回 head 而不是 head->next
(4) 冒泡外层用 swapped 标志, 一轮没有交换就提前退出
(5) 内层条件写 `p != NULL && p->next != NULL`, 否则访问
`p->next->data` 会段错误
(6) 数组版冒泡内层边界是 `n - 1 - i`, 每轮末位已就位
(7) 归并只改 next 指针, 一条走完就把另一条整段挂上
(8) 不带辅助表元时在栈上造 dummy, 最后返回 `dummy.next`

```c
while (p != NULL && p->next != NULL) {
    q = p->next;
    if (p->data > q->data) {              /* 只换数据, 不换结点 */
        int t = p->data; p->data = q->data; q->data = t;
        swapped = 1;
    }
    p = p->next;
}

while (h1 && h2) {                        /* 归并 */
    if (h1->data <= h2->data) { tail->next = h1; h1 = h1->next; }
    else                      { tail->next = h2; h2 = h2->next; }
    tail = tail->next;
}
tail->next = h1 ? h1 : h2;                /* 接上剩下的一段 */
return dummy.next;
```

[注意] `while (!feof(fp))` 会多处理一次, 因为 feof 要等读失败之后才置位;
归并时用 `<=` 才稳定, 相等时保持 h1 在前

例9-7: 从文本文件读数据建带辅助表元的链表, 再用冒泡排序 (5 分 + 10 分)

解: 建表用 `while (fscanf(fp, "%d", &x) == 1)` 配 `malloc` 与尾插,
最后 `fclose` 并返回 head; 排序用 do-while 加 swapped,
只交换 data. 也可以拷进数组排完再写回, 代价是多一份 O(n) 空间.
样例 `5 2 8 1 9` 排序后为 `1 2 5 8 9`

例9-8: 把 h2 归并进 h1, 不新建链表

解: 带辅助表元时 p1 停在 h1 有序部分的尾, 遇到
`p1->next->data > p2->next->data`
就把 h2 的结点摘下插到 p1 之后; 不带辅助表元时用栈上的 dummy 当哨兵,
最后 `return dummy.next`. O(n+m) 时间, O(1) 额外空间

## 9.5 多项式加法

多项式相加是归并模板加一处差别: 指数相等时要合并同类项,
系数相加后为 0 的项不建结点

(1) 链表按指数从大到小排列, 结果也保持该顺序
(2) 指数大的先取, 取完那条链前进
(3) 指数相等时系数相加, 两条链同时前进
(4) 某条链走完就继续搬另一条的剩余项
(5) 系数为 0 的项丢弃, 否则会输出 `0.0x^5`
(6) 结果为空要打印 0, 不能什么都不打
(7) 输出按三支: 指数 0 打系数, 指数 1 打 `系数x`, 其余打 `系数x^指数`

```c
if (ha->exp > hb->exp)      { coef = ha->coef; exp = ha->exp; take_a = 1; }
else if (hb->exp > ha->exp) { coef = hb->coef; exp = hb->exp; take_b = 1; }
else { coef = ha->coef + hb->coef; exp = ha->exp; take_a = take_b = 1; }

if (coef == 0.0) continue;               /* 同类项抵消后为 0 */
node = malloc(sizeof(struct poly));      /* 尾插 */
```

[注意] 题面第 3 条写 `output`, 框架代码 main 里调用的却是 `outprint`,
以框架代码为准, 写成 output 会链接失败

例9-9: A = 3.2x^3 + 2.1x, B = 1.1x^4 + 1, 求 C 并打印

解: 定义 `struct poly {double coef; int exp; struct poly *next; }`;
`sumpoly` 用归并式双指针加尾插, `outprint` 按三支输出.
实际输出串是 `1.1x^4 + 3.2x^3 + 2.1x + 1.0`,
一次项不带指数, 常数项按 `%.1f` 打成 1.0

## 9.6 聚类算法

kmeans 三步循环: 随机选初始中心, 按最近距离分配, 用各簇质心更新中心,
直到迭代上限或聚类不再变化

(1) 初始中心用 `rand() % numPoints` 从数据点里随机取
(2) 比较距离用平方 `dx*dx + dy*dy` 即可, 省一次开方
(3) `bestDist` 初值给 -1, 配 `bestDist < 0 ||` 才能正确初始化第一个中心
(4) changed 标志位要在赋值之前比较聚类编号
(5) 更新质心前要判 `cnt > 0`, 空簇否则除零
(6) 两个终止条件都要写: 迭代上限, 或者 changed 为 0
(7) 坐标与累加都用 double, 用 int 接收会让 1/2 变成 0

```c
for (j = 0; j < k; j++) {
    dx = points[i].coordinates[0] - centers[j].coordinates[0];
    dy = points[i].coordinates[1] - centers[j].coordinates[1];
    dist = dx * dx + dy * dy;            /* 比平方, 不开方 */
    if (bestDist < 0 || dist < bestDist) { bestDist = dist; bestCluster = j; }
}
if (cnt > 0) {                            /* 空簇要跳过, 否则除零 */
    centers[j].coordinates[0] = sumX / cnt;
}
```

[注意] 所有点重合, k 大于点数, k 等于 1 都要能跑;
质心的分母 cnt 必须大于 0

例9-10: 实现 kMeans 函数
参数为数据点数组, 点数, 中心点数组与 k

解: 按题面三步逐段翻译. 先是随机取 k 个初始中心,
然后是 `for (iter = 0; iter < MAX_ITER; iter++)` 大循环:
分配最近中心并置 changed, changed 为 0 就 break,
最后按簇累加坐标求平均更新中心

## 9.7 矩阵与字符串处理

矩阵范数是"外层定行列, 内层累加", 列和要外层列内层行;
字符串里找最大字符存的是下标而不是字符值

(1) 字符串比较必须用 `strcmp`, 不能写 `==`
(2) 宏定义要加括号: `#define max(a,b) ((a)>(b)?(a):(b))`
(3) `char s[10] = {0}` 清零, 避免残留脏数据
(4) 求最大值时初值不能随便取 0, 元素可能全是负数
(5) 列和是外层列内层行, `A[i][j]` 两个下标顺序容易写反
(6) `strlen` 数的是 `'\0'` 之前的个数, 末字符下标是 `len - 1`
(7) 定位最大字符要存下标, 只存字符值最后还得回头找位置
(8) 数组名作参数后已退化为指针, 函数内 `sizeof(str)` 得到的是指针大小

```c
int len = strlen(str);
if (len <= 1) return;                     /* 空串与单字符 */
maxIdx = 0;
for (i = 1; i < len; i++)
    if (str[i] > str[maxIdx]) maxIdx = i;  /* 比 ASCII 码 */
if (maxIdx != len - 1) {                  /* 已在末尾就不换 */
    char t = str[maxIdx]; str[maxIdx] = str[len - 1]; str[len - 1] = t;
}
```

[注意] ASCII 里 `'a'` 是 97 大于 `'Z'` 的 90, 所以混有大写时"最大"落在小写,
如 `ZzAa` 交换后是 `ZaAz`; 直接访问 `str[-1]` 是越界

例9-11: 输入 m, n 与类型串 s 和矩阵, 输出列和范数或行和范数
(题面未留存, 由代码反推)

解: `strcmp(s, "Col") == 0 || strcmp(s, "1") == 0` 走列和,
`"Row"` 或 `"Infinity"` 走行和, 否则打印类型不合法;
列和是外层 j 内层 i 累加, 每列求完与 norm 取大

例9-14: 在字符串中找到最大的字符并与最后一个字符交换

解: `strlen` 求长, `if (len <= 1) return;` 挡住空串,
扫一遍记下最大字符的下标, 再与 `str[len - 1]` 三行交换.
例: `helloworld` 得 `hellodorlw`, `abcd` 不变

## 9.8 递推与递归

冒泡排序是"控制趟数的外层加比较交换的内层", 递归是"出口加递归式";
级数求和的关键是通项的写法, 用递推项既快又不溢出

(1) 降序冒泡的交换条件是 `a[j] < a[j + 1]`, 升序则反过来
(2) 外层 `n - 1` 趟, 内层 `n - 1 - i` 次, 写成 n 会越界
(3) 递归出口 `n <= 1` 返回 1, 递归式 `n * fac(n - 1)`
(4) `1 / fact` 是整数除法, 结果是 0, 必须写 `1.0 / fact`
(5) 阶乘会溢出: `int` 存 13! 已错, `long long` 能到 20!
(6) 递推通项 `term /= i` 的中间值始终在 (0, 1], 永不溢出
(7) e 的初值写 1.0, 即级数开头那个 1/0!, 写成 0 会少一项

```c
int fac(int n) {
    if (n <= 1) return 1;                 /* 递归出口 */
    return n * fac(n - 1);                /* 递归式 */
}

double e = 1.0, term = 1.0;
for (i = 1; i <= n; i++) {
    term /= i;                            /* 1/i! = 1/(i-1)! / i */
    e += term;
}
```

[注意] `int` 最大约 2.1e9, 13! 已超, 溢出后被当 double 参与除法,
程序照样编译运行并输出一个看似正常的错值;
函数定义在 main 之后且无原型, gcc 14 起是硬错误

例9-12: 冒泡把数组降序排列, 再递归求最大值的阶乘

解: `sort` 双层循环, 交换条件 `a[j] < a[j + 1]`;
`fac` 出口 `n <= 1` 返回 1. 降序后 `a[0]` 就是最大值.
注意 `sort` 与 `fac` 要在 main 之前声明

例9-13: 计算 e = 1 + 1/1! + 1/2! + ... + 1/n!, n = 20

解: `double e = 1.0, term = 1.0;` 循环里
`term /= i; e += term;`,
输出 `e = 2.718281828`. 用 long long 存阶乘也可行,
但 n 开大后只有递推写法不受影响

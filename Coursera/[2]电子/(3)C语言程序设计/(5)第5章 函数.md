## 5.1 函数参数传递

C 只有值传递, 形参是实参的副本; 传指针时副本是地址,
所以改 `*p` 能改到实参指向的数据, 改 `p` 本身无效

(1) 值传递改不动实参本身
(2) 传指针改不动指针本身, 但能改指针指向的内容
(3) 数组作参数传递的是首元素地址, 形参与实参是同一块内存
(4) 传结构体指针的目的正是避免拷贝整个结构体
(5) 二维数组作参数可以省略第一维, 第二维必须写
(6) 下标记为 `a[j][i]` 就是按列处理, 按行还是按列只看下标顺序

```c
void f(int x)  { x = 100; }      /* 改不动实参 */
void g(int *p) { *p = 100; }     /* 能改到实参指向的数据 */
void h(int a[]) { a[0] = 1; }    /* 同 g, 数组退化为指针 */

void fun(int a[][N], int b[], int flag)   /* 第二维必须给出 */
```

[注意] "值传递不会改变实参"只对"改形参本身"成立,
传指针时改的是指向的内容, 不违反这条

例5-1: 关于参数传递说法正确的是
A. 值传递不会改变实参的值
B. 参数是结构体指针时需传递整个结构体
C. 指针传递不能用于传递数组
D. 数组作参数时传递的是数组的副本

解: A. B 说反了, 传指针正是为了避免拷贝; 数组传的是首地址, 不是副本

例5-2: 程序用 `fun(x, y, 1)` 与 `fun(x, y, 0)` 对 4x4 矩阵按列求最值,
`x[i][j] = i*4 + j + 1`, 写出两次输出

解: `1,2,3,4,13,14,15,16,`. 外层 `i` 走列, 内层 `a[j][i]` 走上下的行,
`flag` 为 1 取该列最小值, 为 0 取最大值;
第二次调用把 y 整块覆盖, 不是追加

## 5.2 递归的执行顺序

递归的语句位置决定执行顺序: 写在递归调用之前是"递"时执行,
写在之后是"归"时执行, 因此累加与打印的方向常常相反

(1) 递归函数必须有出口, 且每次调用的参数要向出口收敛
(2) `*a += k` 写在调用之后, 累加发生在回溯阶段, 由内向外
(3) 打印写在调用之后, 输出顺序与调用顺序相反
(4) 参数不缩小就是无限递归, 最终栈溢出
(5) `n + "a"` 是整数加指针, 类型错误, 应为 `n + 'a'`
(6) 双引号是字符串, 单引号是字符常量, 两者不能混用

```c
void sub(int *a, int n, int k) {
    if (k <= n) sub(a, n / 2, 2 * k);   /* 先递归 */
    *a += k;                            /* 回溯时才累加 */
}
/* sub(&x, 4, 1) 后 x = 4 + 2 + 1 = 7 */
```

[注意] 参数不变的 `digit(n)` 永远不会到达 `n < 10` 的出口,
必须写成 `digit(n / 10)`

例5-3: `sub(&x, 4, 1)` 中
`if (k <= n) sub(a, n/2, 2*k); *a += k;`
输出 x 为

解: 7. 调用链为 (4,1) → (2,2) → (1,4), 最后一层不递归,
依次 `x += 4`, `x += 2`, `x += 1`

例5-4: `add(&x, 3, 2)` 中
`if (k > 0) add(a, n-1, k-1); *a += (n+k);`
输出 x 为

解: 9. 回溯顺序是由内向外, 依次加 1, 3, 5

例5-5: 要求 `digit(1234)` 输出 `edcb`, 指出错误行并改正

解: 第 4 行 `n + "a"` 改为 `n + 'a'`; 第 8 行 `digit(n)` 改为
`digit(n / 10)`.
前者类型错误, 后者参数不收敛会无限递归;
`1234 % 10 + 'a'` 即 `4 + 97 = 101` 对应 `'e'`

## 5.3 递归求最大公约数

辗转相减法用三条分支: 相等即出口, 大减小, 递归调用自身;
每次递归两数之和严格变小, 必然收敛

(1) `m == n` 是出口, 返回 m
(2) `m > n` 时返回 `gcd(m - n, n)`
(3) `m < n` 时返回 `gcd(m, n - m)`
(4) 两个分支的条件不能写反, 否则会减出 0 或负数
(5) 收敛性靠"和严格变小", 这是这类递归能终止的理由

```c
int gcd(int m, int n) {
    if (m == n) return m;
    else if (m > n) return gcd(m - n, n);
    else return gcd(m, n - m);
}
/* gcd(24, 36) → gcd(24, 12) → gcd(12, 12) → 12 */
```

例5-6: `printf("Gcd=%d", gcd(24, 36));` 的输出是

解: `Gcd=12`. 24 < 36 走 `gcd(24, 12)`, 24 > 12 走
`gcd(12, 12)`,
相等返回 12, 再逐层原样传回

## 5.4 static 局部变量

`static` 局部变量只初始化一次, 生命周期是整个程序, 作用域仍是本函数;
普通局部变量每次进入都重新初始化

(1) 初始化只做一次, 之后每次进入沿用上次的值
(2) 作用域限于本函数, 别的函数看不见
(3) 未显式初始化时自动为 0, 普通局部变量则是垃圾值
(4) `static` 修饰全局变量或函数时, 限定只在本文件可见
(5) 要"保留上次的值得又不让别人访问", 唯一的答案就是 `static` 局部变量
(6) 函数内不写存储类别的局部变量默认是 `auto`

```c
void f(int j) {
    static int a = 10;   /* 只初始化一次, 跨调用保留 */
    int b = 1;           /* 每次进来都重新置 1 */
    b++;
    printf("%d,%d,%d", a, b, j);
    a += 10;
}
/* 三次调用输出 10,2,1 与 20,2,2 与 30,2,3 */
```

[注意] 别把 `static` 局部变量当成"每层递归各一份",
全程只有一份, 所以递归回溯时打印出的都是同一个值

例5-7: `func(3)` 与 `func(2)` 中 `static int count = 0;` 加
`count++`,
打印写在递归调用之后, 输出为

解: 第一行 `3 3 3`, 第二行 `5 5`.
count 全程只有一份, 第二组从 3 接着数; 打印在回溯阶段, 所以是逆序

例5-8: 关于静态变量说法正确的是
A. 函数调用结束后被销毁  B. 运行期间只初始化一次
C. 可在不同函数间共享  D. 必须在函数外部声明

解: B. static 局部变量函数返回后依然存在, 作用域仍限于本函数

例5-9: 希望变量保留上次退出函数时的值, 又不希望其他函数访问, 应定义为
A. auto  B. register  C. extern  D. static

解: D. 保留值要生命周期贯穿程序, 不被访问要作用域限于本函数

例5-10: `fun(x++)` 中
`int y = 0; static int z = 3; z++; ++y;`
`return x + y + z;`, 主函数循环两次 `printf("%5d", fun(x++))`,
输出为

解: 两个数依次为 7 与 9, 各占 5 格右对齐.
第一次 z 由 3 变 4, 返回 2+1+4=7; 第二次 z 由 4 变 5, 返回 3+1+5=9;
`x++` 是后缀, 两次传入的是 2 与 3

例5-11: `main` 循环调用 `f(i)`, `f` 内
`static int a = 10; int b = 1;`
`b++; printf("%d,%d,%d"); a += 10;`, 写出三行输出

解: `10,2,1` 与 `20,2,2` 与 `30,2,3`. `a += 10` 在打印之后,
所以打印的是加之前的值; `b` 每次重置后自增, 恒为 2

## 5.5 extern 与全局变量

全局变量在所有函数之外定义, 从定义处起本文件内处处可见;
函数内用 `extern` 声明是引用别处定义的全局变量, 不是新建变量

(1) 函数内的 `extern int x;` 是声明, 绑定到已有的全局 x
(2) 同名时局部变量会遮蔽全局变量, 形参与全局同名也互不影响
(3) 全局变量与 static 变量未初始化时自动为 0
(4) 局部变量不写存储类别时隐含 `auto`
(5) `extern` 的用途恰恰是跨文件访问, 与"不许别人访问"相反
(6) 形参改名可以避免与全局变量混淆, 如 `x1` 与 `x`

```c
int x = 5;
int func(int x1, int x2) {
    extern int x;         /* 声明, 指向全局 x */
    x1 > x2 ? (x = 3) : (x = 4);
    return x + x1;        /* 4 + 6 = 10 */
}

int a = 10;               /* 全局, 各函数都能直接引用 */
```

[注意] 漏看 `extern` 会以为 x 是未定义的局部变量;
另外 `x1` 是形参不是全局的 5

例5-12: `int x = 5;` 与 `func(6, 7)` 中 `extern int x;`
`x1 > x2 ? (x = 3) : (x = 4); return x + x1;` 输出为
A. 9  B. 10  C. 11  D. 12

解: B. `6 > 7` 为假, 全局 x 被改为 4, 返回 4 + 6 = 10

例5-13: `int a = 10;` 定义在所有函数之外, 函数内 `printf("%d", a);`
则 a 的作用域是
A. 仅在 func 内  B. 仅在函数外  C. 整个程序  D. 在 func 中无效

解: C. 全局变量在本文件内处处可见

例5-14: 未指定存储类别的变量, 隐含的存储类别是
A. auto  B. static  C. extern  D. register

解: A. 只有局部变量适用这条默认规则

例5-15: 全局 `a1 = 300, a2 = 400`, 主函数 `a3 = 100, a4 = 200`,
`sub1` 内 `a1 = x; x = y; y = a1;` 先后调用 `sub1(a3, a4)` 与
`sub1(a1, a2)`, 输出为

解: `100,400,100,200`. 只有全局 a1 被改成 100,
`x` 与 `y` 是副本改不动 a3 与 a4; 第二次调用的实参在调用前求值,
a1 此时已是 100

## 5.6 编译预处理与宏

宏是预处理阶段的纯文本替换, 没有类型检查也没有优先级保护;
展开后的表达式完全按 C 的运算符优先级运算

(1) 每个参数都要加括号, 写成 `((x) * (x))`
(2) 整个表达式还要再加一层括号
(3) 参数会被求值多次, `SQUARE(i++)` 会让 i 自增两次
(4) 能不用宏就不用, 优先 `static inline` 函数或 `const` 常量
(5) `#include` 是原样插入头文件内容, `#define` 与 `#undef` 是定义与取消
(6) 条件编译 `#ifdef` 与 `#endif` 用于头文件卫士

```c
#define SQUARE(x) x * x          /* 错: 得 2+3*2+3 = 11 */
#define SQUARE2(x) ((x) * (x))   /* 对: 得 25 */

#define ADD(x, y) x + y          /* 错: 3+4*2 = 11 */
#define ADD2(x, y) ((x) + (y))   /* 对: 得 14 */
```

[注意] 只给参数加括号还不够, `#define M(x) (x)*(x)` 在 `100/M(10)`
里仍会错成 100, 整体括号不能省

例5-16: `#define SQUARE(x) x * x` 时 `SQUARE(2 + 3)` 的结果是
A. 25  B. 13  C. 9  D. 11

解: D. 展开为 `2 + 3 * 2 + 3`, 先算 `3*2` 得 11;
选 25 是把它当函数算

例5-17: `#define ADD(x, y) x + y` 时
`printf("%d", ADD(3, 4) * 2)`
的输出是
A. 14  B. 11  C. 18  D. 7

解: B. 展开为 `3 + 4 * 2` 得 11;
这一题错在宏整体没有括号, 与上一题错在参数没有括号相对照

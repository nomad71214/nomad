## 6.1 指针的基本概念

指针存放地址, 有类型; 合法的运算只有加减整数与两指针相减,
加减的步长按所指类型的大小走, 不是按字节

(1) 指针可以做 `p + n`, `p - n`, `p - q`, `p++`, `p--`
(2) 不能做 `p * q`, `p / q`, `p + q`, 没有意义且编译报错
(3) `p + 1` 是加一个元素, `int *` 在 32/64 位平台上实际加 4 字节
(4) `p - q` 的结果是两指针之间的元素个数, 类型为 `ptrdiff_t`
(5) 指针可以指向变量与函数, `void *` 才能无条件承接任意类型
(6) 数组名在表达式里退化为首元素地址, 但它是地址常量, 不能被赋值
(7) 用指针的次序是"先指向, 再解引用", 颠倒就是野指针

```c
int a[5] = {1, 2, 3, 4, 5};
int *p = a;          /* p 指向 a[0], 没有拷贝任何元素 */
printf("%d %d", *p, p[4]);   /* 1 5 */

int n = 4, *q = &n;
*q = 100;            /* 通过指针改 n, 合法 */
```

[注意] `sizeof(arr) == 20` 而 `sizeof(p) == 8`, 地址值相同但类型不同;
`int *p[5]` 是指针数组, `int (*p)[5]` 是数组指针

例6-1: 关于指针的说法不正确的是
A. 可以指向任何类型的变量  B. 可以指向函数
C. 可以进行加减乘除运算  D. 可以作为函数参数

解: C. 指针只能加减整数或两指针相减, 不能乘除, 也不能两指针相加

例6-2: `int arr[5] = {1,2,3,4,5}; int *p = arr;` 则
A. p 指向第一个元素  B. p 是数组的副本
C. p 指向最后一个元素  D. p 是一个指针数组

解: A. 数组名退化为 `&arr[0]`, 没有元素被拷贝;
要让 p 指向末元素得写 `p = arr + 4`

例6-3: 有 `int *p, a = 4, n;` 下面正确的程序段是
A. `p=&n; scanf("%d", &p);`  B. `p=&n; scanf("%d", *p);`
C. `scanf("%d", &n); *p=n;`   D. `p=&n; *p=a;`

解: D. A 的类型是 `int **`, B 把值当地址传, C 是野指针未初始化就解引用

例6-4: 以下说法错误的是
A. 字符串比较不能用比较运算符  B. 指针可以指向任意类型的变量
C. sizeof 可得到变量或类型的大小  D. 数组名是地址但不能修改

解: B. 指针有类型, `int *` 与 `double *` 不能无条件互赋;
A 对, `s1 == s2` 比的是地址, 内容比较要用 strcmp

例6-5: `char b[5]="abcd", *p="abcd";` 则正确的语句是
A. `b=p;`  B. `strcpy(p,b);`  C. `b==p;`  D. `strlwr(p);`

解: C. A 是给数组名赋值, 编译不过; B 与 D 都在写只读的字面量区;
本题问的是"合法", 不是"值为真", `b == p` 的值其实是 0

## 6.2 数组名与指针遍历

二维数组按行优先存储, `a[i]` 是一维数组名, 退化为 `int *`,
因此只需一个列下标就能取到元素

(1) `a[i]` 的类型是 `int[N]`, 退化后指向 `a[i][0]`
(2) 初始化列表没写到位的元素自动补 0
(3) `*(a + i)` 等价 `a[i]`, 两者都是地址
(4) `a + index` 是地址, 取元素必须写成 `*(a + index)` 或 `a[index]`
(5) 循环边界写 `< n` 而不是 `<= n`, 差一错误会多跑一轮
(6) 循环移位用取模: `index = (起始 + i) % 长度`
(7) 循环次数与下标越界是两件事, 要分开判断

```c
int a[2][3] = {1, 2, 3, 4, 5, 6};
int *p = a[1];              /* 指向第二行首元素 */
printf("%d", p[2]);         /* 6, 即 a[1][2] */

int array[5] = {5, 3, 1};   /* 实际是 {5,3,1,0,0} */
```

[注意] 循环移位取模时 `index` 恒在范围内, 错的是循环次数,
别把两者混为一谈

例6-6: `int a[2][3] = {1,2,3,4,5,6}; int *p; p = a[1];`
`printf("%d", p[2]);` 输出为
A. 4  B. 5  C. 6  D. 超出数组

解: C. `a[1]` 退化为 `int *` 指向 `a[1][0]`, 再偏移 2 得 `a[1][2]`

例6-7: `int array[5] = {5,3,1};` 循环中 `*ptr` 为 0 输出 X,
否则输出 `'A' + *ptr`, 写出输出

解: FDBXX. 后两个元素补 0 得 {5,3,1,0,0};
5/3/1 分别偏移成 F/D/B, 两个 0 走 if 分支各打一个 X

例6-8: 要让 `int a[5] = {1,2,3,4,5};` 输出 34512,
下面是 `for (i = 0; i <= 5; i++) index = (3+i)%5;`
`printf("%d", (a+index));` 找出 3 处错误

解: 第 4 行 `i <= 5` 改为 `i < 5`; 第 5 行 `3 + i` 改为 `2 + i`;
第 6 行 `(a+index)` 改为 `*(a+index)`.
循环多跑一轮会多打一个字符, `a+index` 是地址

## 6.3 指针遍历字符串

`*p++` 先取值再把指针后移, 是遍历字符串的标准写法;
遇到结尾的 `'\0'` 时 `*p` 为 0, 循环条件自动变假

(1) `while (*p) putchar(*p++);` 等价于按字符遍历直到串尾
(2) `*p++` 取的是自增前的字符, 指针自增的是变量自己
(3) `(*p)++` 是把所指的字符加 1, 与上一条完全不同
(4) 只有 `p` 是独立的指针变量才能自增, 数组名不能
(5) `(char *p = "abcd")` 指向只读字面量, 只能读不能写
(6) 越界是否崩溃要看数组开了多大, 而不是字符串有多长

```c
char str[] = "world";
char *p = str;
while (*p) putchar(*p++);    /* 输出 world, 一个字都不多 */
```

[注意] `(*p)++` 的括号不能省, 漏了就变成移动指针,
字符串内容一个字符都不会改

例6-9: `char str[] ="world"; char *p = str; while (*p) putchar(*p++);`
则
A. 输出 world  B. 输出 world 加换行  C. 输出 drow  D. 先换行再输出

解: A. 代码里没有输出换行的语句, 顺序也不是逆序

例6-10: `char str[] = "Hello";` 用
`while (*p) printf("%c", *p++);`
则
A. 输出 Hello  B. 输出 Hello 加换行  C. 输出 hello  D. 输出 hello 加换行

解: A. C 语言区分大小写, `'H'` 是 72, `'h'` 是 104, 输出不会变小写

例6-11: `char str[100] = "I am a pig."; char *p = &str[7];`
循环条件为 `str[i] != '\0'`, 循环内小写字母后移一位, `'z'` 绕回 `'a'`,
写出输出

解: `I am a qjh.`. 两个游标相差固定偏移 7, 所以 p 指向 `str[i+7]`;
循环跑 11 轮, p 走到 `str[17]` 仍在 100 字节的零填充区内, 既不越界也不影响输出

## 6.4 指针算术与原地修改

`*s1++` 会先把指针移开, 若在同一轮里接着写 `*s1`, 写的位置已经错位;
交换数组元素要"先交换, 后移动"

(1) `t1 = *s1++;` 等价于 `t1 = *s1; s1++;`
(2) 三个赋值都带 `++` 时, 后两个写的位置都已偏移
(3) 正确写法分四行: 先交换, 再 `s1++; s2--;`
(4) 也可一行解决: `*s1++ = *s2; *s2-- = t1;`, 但可读性差
(5) `p - x` 得到的是下标, `*p - *x` 得到的是元素值之差
(6) 比较要写 `*p == key`, 不能写 `p == key`

```c
void fun(char *w, int n) {
    char *s1 = w, *s2 = w + n - 1;
    while (s1 < s2) { *s1++ = *s2; *s2-- = *s1; }
}
/* 这样写仍会错位, 稳妥的是四行: 先交换, 再移动 */
```

[注意] 逆序, 删除这类"双指针"题, 一定先算清每一步移动后指针停在哪,
再决定下一步写哪个地址

例6-12: `fun` 内 `t1 = *s1++; *s1 = *s2--; *s2 = t1;` 对
`char p[8] = "1234567"` 原地逆序, 输出为

解: `1711717`, 不是 `7654321`.
`s1` 与 `s2` 在赋值前就移动了, 每次写的位置都偏移一格, 三处互相抵消不了

例6-13: 下面按值查找下标的函数有 3 处错误, 要求返回下标
`for (p = x; p < x+n; p++) if (p == key) return *p - *x;`
主函数 `n = search(a[0], 8, 4);` 写出改正

解: 第 5 行改 `if (*p == key)`; 第 6 行改 `return p - x;`;
第 11 行改 `search(a, 8, 4)`. 指针减指针才是下标,
`a[0]` 是值不是地址

## 6.5 指针处理字符串

指针版的插入, 删除都靠"定位 + 整体挪位"两步;
删字符是左移覆盖, 插字符是从末尾右移腾位, 方向都不能反

(1) 删除: 从待删位置起把后面的字符整体左移一位, 源下标自增
(2) 插入: 从串尾往前整体右移一位, 再写目标位置
(3) 撤位循环必须从后往前, 从前往后会覆盖尚未搬走的数据
(4) 插入时 `i = strlen(s1)` 而不是 `strlen(s1) - 1`, 连同 `'\0'` 一起挪
(5) 就地修改必须用 `char s[]`, 用 `char *` 指向字面量写只读区
(6) 二进制转十进制用秦九韶: `v = v * 2 + (c - '0')`, 只能从左往右

```c
int j = 0;
while (s1[j] && c >= s1[j]) j++;        /* 定位 */
for (i = strlen(s1); i >= j; i--)
    s1[i + 1] = s1[i];                  /* 从后往前右移一位 */
s1[j] = c;                              /* 插入 */
```

[注意] `char *str = "AmGhl";` 想就地删字符会写只读区,
必须改成 `char str[] = "AmGhl";`; 而 `p+1;` 只是算了值, 指针不动

例6-14: 删除字符串中所有小写字母的程序有 3 处错误,
写出改正(`char *str="AmGhl"`, `while(*p; p++)`,
`printf("%c", p)`)

解: 第 3 行改 `char str[]="AmGhl"`; 第 10 行改
`for(p = str; *p; p++)`;
第 11 行改 `printf("%c", *p)`.
第 7 行的左移循环本身是对的, 不要改

例6-15: `s1 = "egjlnpw"`, `s2 = "fbla"` 调用 `ostr(s1, s2)`
后输出什么,
函数功能是什么

解: `abefgjllnpw`; 功能是把 s2 的每个字符按升序插入 s1, 即对 s1 做插入排序.
相等时继续后移, 所以第二个 l 排在第一个 l 之后

例6-16: 把二进制串转成无符号整数有 4 处错误
(`scanf("%s", &v2)`, `p = v2 + strlen(v2) - 1`,
`t = *p - 0`, 
`p+1;`)

解: 改 `scanf("%s", v2)`; 改 `p = v2`; 改 `t = *p - '0'`; 改
`p++`.
数组名本身就是地址; 秦九韶迭代必须从高位开始;
字符与数字差 `'0'`; `p+1;` 不动指针会死循环

## 6.6 指针作函数参数

C 只有值传递, 指针形参同样是副本; 能改到外部变量靠的是
"副本里存着地址, 再解引用去写那块内存"

(1) 交换指针本身 `t=a; a=b; b=t;` 影响不到实参
(2) 交换所指内容 `t=*a; *a=*b; *b=t;` 才能改到实参变量
(3) 暂存变量要存放的是值, 声明成 `int x` 而不是 `int *x`
(4) 调用时形参是指针就必须传 `&a`, 否则类型不匹配
(5) `printf("%d", &u)` 是把地址当整数打, 应写 `u`
(6) 改错题优先选改动最小的方案, 并注意错误数量限制

```c
void swap(int *a, int *b) { int t; t = *a; *a = *b; *b = t; }
swap(&i, &j);                          /* 传地址才能交换 */
printf("%d %d", i, j);                 /* 5 2 */
```

[注意] 形参是 `int *` 时, 函数体内 `z = *x;` 的 `z` 必须是 `int`,
写成 `int *z` 就变成"指针指向某处", `*y = z` 也随之出错

例6-17: `swap(int *a, int *b)` 内 `t=a; a=b; b=t;` 交换的是指针本身,
主函数 `int i=2, j=5, *p=&i, *q=&j;` 调用 `swap(p, q)` 后输出为

解: `2 5`, 没有交换. 形参是副本, 函数返回后消失, 主函数的 p, q 没变

例6-18: `short *x, *y` 的交换函数要求输出 `a=5, b=3`,
现有 `short *z; z = *x; *x = *y; *y = z;` 与 `swap(a, b);`,
指出错误

解: 第 2 行改 `short z;`; 第 9 行改 `swap(&a, &b)`.
暂存的是值不是地址, 调用要传地址

例6-19: `int u=8, v=4;` 调用 `func(u, v)` 要求输出 `u=4, v=8`,
现有 `int *x; x = *b;` 与 `printf("%d", &u, &v);`, 指出错误

解: 第 3 行改 `int x;`; 第 11 行改 `func(&u, &v)`;
第 12 行改 `printf("%d", u, v)`. `%d` 要的是值, `&u` 是地址

## 6.7 行指针与指针数组

二维数组名是行指针, 步长是一整行; `a[i]` 才是元素指针, 步长一个元素,
把两者混用就会跳到别的行

(1) `a[i][j]` 等价 `*(a[i] + j)` 等价 `*(*(a + i) + j)`
(2) `&a[i][j]` 等价 `a[i] + j` 等价 `*(a + i) + j`
(3) `a + i + j` 错, 两次都按行跳, 得到 `&a[i+j][0]`
(4) 行指针 `int (*p)[5]` 与指针数组 `char *p[2]` 是两回事
(5) 表达式是否为元素值, 看还需要几层解引用
(6) `p[1] = "456"` 改指针合法, `p[1][0] = 'B'` 改字面量非法
(7) `%s` 要字符串地址, `*temp` 是单个字符

```c
int c[4][5], (*p)[5] = c;
int x = *(p[0] + 2);        /* 就是 c[0][2] */

char *names[5] = {"Windows", "Word"};
temp = names[0];    /* names 退化为 char ** */
```

[注意] `char names[5]` 只能装 5 个字符, 装 5 个字符串要用
`char *names[5]` 或 `char names[5][20]`

例6-20: `a[i][j]` 的地址不能用哪个式子表达
A. `&a[i][j]`  B. `a[i]+j`  C. `*(a+i)+j`  D. `a+i+j`

解: D. `a` 是行指针, 加 i 与加 j 都按整行跳, 得到 `&a[i+j][0]`

例6-21: `int c[4][5], (*p)[5]; p = c;` 则能访问元素的是
A. `p+1`  B. `*(p+3)`  C. `*(p+1)+3`  D. `*(p[0]+2)`

解: D. 前三项都还是地址, 只有 D 出了元素值

例6-22: 表示 `int a[2][3]` 第 i 行第 j 列元素地址的正确语句是
A. `*(a[i]+j);`  B. `(a+i);`  C. `*(a+j);`  D. `a[i]+j;`

解: D. A 已解引用成元素值, B 是行地址, C 的行下标写错了

例6-23: `char a[]="123", *p[] = {a, "abc"};` 错误的表达式是
A. `p[1] = "456"`  B. `p[1][0] = 'B'`
C. `*(p+1) = "B"`  D. `*p = "B"`

解: B. 改指针本身合法, 改只读字面量的内容非法;
而 `p[0][0] = 'B'` 反而合法, 因为 `a` 是可写数组

例6-24: 在 5 个字符串中求最小串, 有 4 处错误
(`char names[5] = {...}`, `temp = names;`, 
`strcmp(temp, names[i]) < 0`, `printf("%s", *temp)`)

解: 改 `char *names[5]`; 改 `temp = names[0]`; 改 `> 0`; 改
`temp`.
求最小在"当前值大于新值"时替换, `%s` 不能收单个字符

## 6.8 综合阅读

一段程序里能同时埋进字符串结束符, 宏展开, 关系运算左结合与指针解引用,
识别这些点的办法是逐行算出类型与值

(1) `%s` 遇到第一个 `'\0'` 就停, 后面的字符不打印
(2) `str['\0']` 就是 `str[0]`, 字符常量的值是 0
(3) `0 <= x <= 3` 恒为真, 应写 `0 <= x && x <= 3`
(4) `#define M 1+2` 时 `2*M*3` 展开为 `2*1+2*3`, 得 8
(5) 宏只是文本替换, 加足括号才安全
(6) `for (i = 0; i <= 4; i++) b[i] = i*3;` 里 `b[4]` 是最后一格

```c
#define M (1 + 2)          /* 加括号后 2*M*3 才是 18 */
char str[6] = {'a', 'b', '\0', 'c', 'd', '\0'};
printf("%s", str);         /* 只输出 ab */
```

[注意] 宏不加括号时结果常常"看起来正常", 改对之后值反而变了,
写宏时参数与整体两层括号都不能省

例6-25: 输出 `str`, `b[4]`, `0<=x<=3`, `2*M*3`, `*p`,
`str['\0']`
六行,
其中 `#define M 1+2`, `x = 8`, `p = &x`, `b[i] = i*3`

解: `ab` 与 `12` 与 `1` 与 `8` 与 `8` 与 `a`.
字符串在第一个 `'\0'` 处截断; 关系运算左结合使中间那行恒为 1;
宏展开得 `2*1+2*3 = 8`; `str['\0']` 即 `str[0]`

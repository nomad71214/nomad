## 1.1 标识符的构成规则

标识符用于命名变量, 函数, 数组等实体; 合法性只由字符组成决定, 与名称含义无关

(1) 只能由字母, 数字, 下划线 `_` 组成, 合法的连接符只有 `_`
(2) 不能以数字开头
(3) 不能是关键字
(4) 区分大小写: `INT`, `Int` 合法, `int` 非法
(5) 关键字接其他字符后仍是普通标识符: `_int`, `int_`, `int2` 都合法
(6) 下划线的位置与个数不受限: `_`, `__a`, `x_`, `_0` 都合法

```c
int _tempVar;      /* 下划线开头, 合法 */
int count_;        /* 下划线结尾, 合法 */
int in1_3;         /* 字母开头, 后接数字与下划线, 合法 */
int A_BID;         /* 全大写只是普通标识符, 不构成关键字 */

/* int 2nd_var;      数字开头, 非法 */
/* int total-sum;    含减号, 非法 */
/* int var name;     含空格, 非法 */
```

[注意] 减号 `-` 与空格是最常被误当成连接符的两个字符, 合法连接符只有下划线

## 1.2 关键字

关键字是编译器保留的标识符, 不能用作变量名或函数名; C89 共 32 个, 后续标准继续增补

(1) C89 的 32 个, 见下方代码块
(2) C99 增补 `inline`, `restrict`, `_Bool`, `_Complex`,
`_Imaginary`
(3) C11 增补 `_Alignas`, `_Alignof`, `_Atomic`, `_Generic`,
`_Noreturn`, `_Static_assert`, `_Thread_local`
(4) `main`, `define`, `include`, `printf` 都不是关键字, 可作标识符
(5) 关键字必须整体匹配, `int_value`, `float1`, `Goto` 都不触发关键字

```c
/* C89 的 32 个关键字 */
auto      break     case      char      const     continue
default   do        double    else      enum      extern
float     for       goto      if        int       long
register  return    short     signed    sizeof    static
struct    switch    typedef   union     unsigned  void
volatile  while
```

[注意] C 没有 `string` 或 `String` 关键字(那是 C++ 的 `std::string`);
把 `float`, `const` 当普通名字, 或把 `String` 当关键字, 都是常见失分点

## 1.3 常量与转义字符

常量是程序中直接写出的值, 类型由书写形式与后缀决定;
字符常量用单引号, 字符串常量用双引号

(1) 整型: 十进制 `123`, 八进制前缀 `0`(`017` 即 15),
十六进制前缀 `0x`(`0x41` 即 65)
(2) 整型后缀: `u/U` 无符号, `l/L` 长整型, 可组合为 `UL`, `LL` 等
(3) 浮点: 小数 `3.14`, `.45`, `10.`, 指数 `1e-6`, `1.5E+3`
(4) 浮点后缀: `f` 单精度, `l` 长双精度
(5) 字符 `'A'`: 单引号内恰一个字符, 占 1 字节
(6) 字符串 `"A"`: 结尾自动补 `'\0'`, 故占 2 字节
(7) 八进制转义 `\ddd` 只允许 `0` 到 `7`;
十六进制转义 `\xhh` 可接多位十六进制数字

表1-1 常用转义序列 (C89)

| 写法 | 含义 | 备注 |
| --- | --- | --- |
| `\0` | 空字符 | 数值 0, 字符串结束标志 |
| `\ddd` | 八进制转义 | 只认 `0` 到 `7`, 遇 `8` 即截断 |
| `\xhh` | 十六进制转义 | `\x41` 即 `'A'` |
| `\\` | 反斜杠 | 结果是一个字符 |
| `\'` `\"` | 单引号, 双引号 | 在同类引号内表示字面字符 |
| `\n` `\t` `\r` `\b` | 换行, 制表, 回车, 退格 | 转义后仍是单个字符 |

```c
char a = '\x41';   /* 十六进制转义, 值为 65, 即 'A' */
char b = '\101';   /* 八进制转义, 同样是 'A' */
int  c = 0x41;     /* 十六进制整型常量, 值也是 65 */
char d = '\08';    /* 非法: 八进制不含 8, 按多字符常量处理 */
```

[注意] `'\08'` 被拆成 `'\0'` 与 `'8'`, 属于实现定义的多字符常量;
gcc 给出 multi-character character constant 警告, 值不保证

## 1.4 变量定义的正误

定义语句的形式为 `类型 标识符 [= 初值]`, 多个变量用逗号分隔;
初值合法是定义合法的前提

(1) 指针初值可用空指针常量: `int *p = NULL;`
(2) 字符数组可用字符串初始化, 长度含结束符:
`char s[] = "C Programming";` 的长度为 14
(3) 数组初始化列表可省略长度, 由元素个数推出:
`long a[] = {5L, 3L, -2L};` 的长度为 3
(4) 常量后缀须与类型一致: `5L` 配 `long`, `12345UL` 配
`unsigned long`, `1.5f` 配 `float`
(5) 浮点常量只能有一个小数点, 指数部分必须是整数

```c
int *p = NULL;                  /* 空指针常量, 合法 */
char s[] = "C Programming";     /* 长度 14, 含结束符 */
long a[] = {5L, 3L, -2L};       /* 后缀 L, 数组长度推出为 3 */
unsigned long id = 12345UL;     /* UL 即 unsigned long */

/* double r = .05.3;        非法: 出现两个小数点 */
/* double y = .45e-4.3L;    非法: 指数部分不是整数 */
```

[注意] `.45` 这种省略整数部分的浮点常量本身合法,
非法的是其后的第二个小数点; 判断题要看完整写法

## 1.5 典型题目

例1-1: 选出可作为 C 标识符的一组
A. `total-sum, _value`  B. `count_, String`
C. `float, num#`  D. `3data, while`

解: B. `count_` 以下划线结尾合法, `String` 不是关键字.
A 的 `total-sum` 含减号, C 的 `float` 是关键字且 `num#` 含 `#`,
D 的 `3data` 数字开头且 `while` 是关键字

例1-2: 选出可作为 C 标识符的一组
A. `2num, f1, total`  B. `main, case, _sum`
C. `print, int$, number_1`  D. `_data, sum1, Average`

解: D. `main` 是函数名而非关键字, `case` 才是关键字;
`int$` 含 `$`, `2num` 数字开头

例1-3: 选出不可以作为用户标识符的一组
A. `A_1, Goto, Ba`  B. `character, _0, AbC`
C. `_a, __a, x_`  D. `temp, x#, INT`

解: D. `x#` 含 `#`. `Goto` 与 `goto` 不同(大小写敏感),
`_0` 下划线开头后接数字合法

例1-4: 选出正确的 C 标识符
A. `int`  B. `in1_3`  C. `A_BID`  D. `const`

解: B. 按 C 规则 `A_BID` 同样合法, 此题材料的答案取 B,
属于选项设置不严谨

例1-5: 选出无效的变量名
A. `int_value`  B. `_tempVar`  C. `2nd_var`  D. `totalSum`

解: C. 数字开头即非法; `int_value` 中 `int` 只是前缀,
不构成关键字

例1-6: 选出合法的标识符
A. `123var`  B. `_var`  C. `var-name`  D. `var name`

解: B. 其余分别错在数字开头, 含减号, 含空格

例1-7: 选出错误的常量表示
A. `'\x41'`  B. `0x41`  C. `'\08'`  D. `"A"`

解: C. 八进制转义不含 `8`; 其余三者值均为 65, `"A"` 占 2 字节

例1-8: 选出正确的定义语句
A. `int 34x = 1234;`  B. `long a[] = {5L, 3L, -2L};`
C. `char b = 'Class';`  D. `double y = .45e-4.3L;`

解: B. A 的 `34x` 数字开头, C 的 `'Class'` 是多字符常量,
D 的指数部分不是整数

例1-9: 选出无效的变量定义
A. `int *p = NULL;`  B. `char str[]="C Programming";`
C. `double rate = .05.3;`
D. `unsigned long id = 12345UL;`

解: C. 常量中出现两个小数点; 其余三项的初值均合法

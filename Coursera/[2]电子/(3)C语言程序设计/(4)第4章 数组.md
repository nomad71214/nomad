## 4.1 数组名与数组定义

数组名代表首元素的地址, 不是变量, 不能赋值也不能自增;
它只在三处例外地不代表首元素地址: `sizeof`, `&` 与字符串字面量初始化

(1) `a = b;` 非法, 数组名不是左值, 拷贝数组只能用循环或 `memcpy`
(2) `a++;` 非法, 数组名不能自增
(3) `a == b` 合法, 比较的是两个地址, 结果恒为 0
(4) `a + 1` 合法, 是指向 `a[1]` 的指针
(5) `&(i + j)` 非法, `&` 只能作用于左值, 表达式结果是右值
(6) `int a[n];` 合法, C99 起支持变长数组 VLA, 长度可以是运行时变量
(7) `sizeof(a) / sizeof(a[0])` 才是元素个数, `sizeof(a)` 是字节数
(8) `{0}` 只显式初始化首元素, 其余全部自动补 0

```c
int a[3] = {0}, b[3], i = 3, *j;   /* 合法: j = a + 1 */

int n;
scanf("%d", &n);
int arr[n];            /* VLA, C99 起合法 */

sizeof(a) / sizeof(a[0])   /* 元素个数, 不是 sizeof(a) */
```

[注意] 判断"合法"只看能否通过编译, 不看是否有意义, `a == b` 就是典型

例4-1: 对于 `int a[3]={0}, b[3], i = 3, *j;` 下列合法的表达式是
A. `a = b;`  B. `*j = *(a+i);`  C. `a++;`  D. `j = a+1;`

解: D. A 与 C 都是改数组名; B 里 j 未初始化是野指针, 且 `a+3` 已越界

例4-2: 对于 `int a[3], b[3], i = 3, j;` 能通过编译的是
A. `j = a == b;`  B. `b = a;`  C. `&(i + j);`  D. `a++;`

解: A. 比较两个地址得 0 再赋给 j, 语法合法; C 取的是右值的地址

例4-3: `int arr[5] = {0}; printf("%d", arr[3]);` 的输出是
A. 未定义行为  B. 0  C. 3  D. 随机值

解: B. 给了初始化列表, 未列出的元素一律补 0;
只有未初始化的局部变量才是垃圾值

例4-4: 关于数组描述错误的是
A. 数组大小必须是常量表达式  B. 索引从 0 开始
C. 可用 sizeof 获得元素个数  D. 数组名是首元素地址且不可修改

解: A. C99 起数组长度可以是变量, 即变长数组

## 4.2 一维数组与冒泡排序

冒泡排序的内层边界是 `n-1-i`, 少写这个 `-1` 就会在 `a[j+1]` 处越界;
`>` 得升序, `<` 得降序

(1) 外层 `i < n-1`, 内层 `j < n-1-i`
(2) 内层要访问 `a[j+1]`, 所以 `j` 最大只能是 `n-2-i`
(3) 前者大于后者就交换, 大数往后送, 得到升序
(4) 前者小于后者就交换, 得到降序
(5) 输出元素要写 `a[i]`, 写 `a` 打印的是地址
(6) 下标可以是任意整型表达式, 字符按 ASCII 码参与运算

```c
int a[6] = {8, 2, 13, 4, 9, 15}, i, j, t;
for (i = 0; i < 6 - 1; i++)
    for (j = 0; j < 6 - 1 - i; j++)
        if (a[j] < a[j + 1]) {   /* 小于则交换, 得降序 */
            t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
        }
for (i = 0; i < 6; i++) printf("%d  ", a[i]);
```

[注意] `j < 6 - i` 在 i=0 时 j 可取到 5, 随后访问 `a[6]` 越界,
gcc 会直接 abort 或打印出地址值

例4-5: 用冒泡排序把 `{8, 2, 13, 4, 9, 15}` 排成降序, 找出三处错误

解: (1) 第 6 行 `j < 6 - i` 改为 `j < 6 - 1 - i`,
否则 `a[j+1]` 越界;
(2) 第 7 行 `a[j] > a[j+1]` 改为 `<`, 降序要小数往前换;
(3) 第 15 行 `printf("%d  ", a)` 改为 `a[i]`, 数组名是地址.
改正后输出 `15  13  9  8  4  2`

例4-6: `int a[12]={1,2,...,12};`
`char c = 'a', d, g;` 中值为 4 的是
A. `a[g-c]`  B. `a[4]`  C. `a['d'-'c']`  D. `a['d'-c]`

解: D. `'d'` 为 100, `c` 为 97, 差为 3, `a[3]` 是第 4 个元素 4;
A 里的 g 未初始化

## 4.3 sizeof 与字符串长度

`sizeof` 数的是字节数, 含结尾的 `'\0'`; `strlen` 数的是字符个数, 到第一个
`'\0'` 为止, 不含它

(1) 字符串字面量初始化数组时, 编译器自动补 `'\0'`, 所以 `char x[] = "12345"` 是 6
字节
(2) 用初值表初始化不会自动补 `'\0'`, 必须自己写
(3) `sizeof` 是编译期运算符, `strlen` 是运行时函数
(4) `sizeof(x++)` 不会真的自增
(5) 字符常量 `'A'` 的类型是 `int`, 占 4 字节; 字符串 `"A"` 占 2 字节
(6) 两种初始化写法 `char x[] = "12345"` 与
`char y[] = {'1',...,'\0'}` 完全等价

```c
char x[] = "12345";                      /* 自动补 '\0', 6 字节 */
char y[] = {'1','2','3','4','5','\0'};   /* 手写 '\0', 6 字节 */
/* sizeof(x) = 6, strlen(x) = 5 */
/* 若 y 不写 '\0', 则 sizeof(y) = 5 */
```

[注意] 题目问"长度"时要先判断指字节数还是字符个数,
两种理解下本题都选同一项, 但换成其他题就不同了

例4-7: `static char x[] = "12345";` 与
`char y[] = {'1','2','3','4','5','\0'};`
则
A. 两者长度相等  B. x 更长  C. x 更短  D. 两者存储区域相同

解: A. `sizeof(x)` 与 `sizeof(y)` 都是 6;
D 错在把"长度"换成了"存储区域", 两个数组各占一块内存

## 4.4 二维数组的定义与 sizeof

二维数组只能省略第一维, 第二维必须写; 第一维由初始化元素个数推算;
裸值会另起一行

(1) `int a[2][]` 非法, 编译器要靠第二维算行长度
(2) 初始化元素总数除以第二维得上取整的行数
(3) 每行不足的元素自动补 0
(4) `sizeof(a)` 是整个数组的字节数, 不是元素个数
(5) 裸值如 `{1,2,3,4,5}` 中的每个数都会开新行, 按第二维切分
(6) `char a[][3]` 的 `sizeof` 既是字节数也是元素个数, 因为 `char` 占 1 字节

```c
int a[][2] = {{1},{2},{3},4};   /* 4 个初始化元素 → int[4][2] */
/* sizeof(a) = 4 * 2 * 4 = 32 */

char b[][3] = {'1','2','3','4'};   /* 2 行 → char[2][3] */
/* sizeof(b) = 2 * 3 * 1 = 6 */
```

[注意] 裸值 `4` 不是接在上一行后面, 而是自己开一行

例4-8: `int a[][2]={{1},{2},{3},4};` 则 `sizeof(a)` 为
A. 48  B. 32  C. 16  D. 24

解: B. 4 个初始化元素各占一行, 得 `int[4][2]`, 共 8 个 int 即 32 字节

例4-9: `char a[][3]={'1','2','3','4'};` 则 `sizeof(a)` 为
A. 4  B. 6  C. 8  D. 12

解: B. 4 个字符按每行 3 个切, 得 `char[2][3]`, 共 6 字节

例4-10: 不能正确定义二维数组的是
A. `int a[2][]={{1,2},{3,4}};`  
B. `int a[][2]={1,2,3,4,5};`
C. `int a[2][2]={{1},{2}};`  D. `int a[2][2]={1,2,3};`

解: A. 第二维不能省略

## 4.5 二维数组遍历与矩阵运算

二维数组按行优先存储, 遍历时用双重循环;
`b[j][i] = a[i][j]` 得到转置, 矩阵乘法的内层指标 `k` 是两边共用的那个

(1) 矩阵乘 `c[i][j] = sum(a[i][k] * b[k][j])`, 中间指标是 `k`
(2) 直方阵的转置 `b[j][i] = a[i][j]` 让 `c = a * a转置` 得到对称矩阵
(3) 主对角线是 `x[i][i]`, 副对角线是 `x[i][n-1-i]`
(4) 副对角线下标的减数是最大下标 `n-1`, 不是长度 `n`
(5) 原地转置只扫下三角 `j < i`, 每对元素才交换一次
(6) 若内层写成 `j < n`, 每对会被换两次, 等于没换

```c
for (i = 0; i < 3; i++)
    for (j = 0; j < i; j++) {          /* 只扫下三角 */
        temp = a[i][j];
        a[i][j] = a[j][i];
        a[j][i] = temp;
    }

for (i = 0; i < 3; i++)
    printf("%d", x[i][2 - i]);         /* 副对角线 357 */
```

[注意] 交换类填空的两空通常就是一次交换的两个动作,
先暂存再写入最后回填, 顺序不能颠倒

例4-11: 程序先做 `b[j][i] = a[i][j]`, 再做
`c[i][j] += a[i][k] * b[k][j]`, `a` 为 1 到 9 的 3x3 矩阵, 输出 c

解: `14 32 50 32 77 122 50 122 194`. b 是 a 的转置, 所以 c 是 a
乘自己的转置,
`c[i][j]` 即第 i 行与第 j 行的内积, 结果对称;
每个数后面都带一个空格

例4-12: `int x[3][3] = {1,2,3,4,5,6,7,8,9};` 后循环打印
`x[i][2-i]` 输出
A. 147  B. 159  C. 357  D. 369

解: C. 取的是副对角线 `x[0][2]`, `x[1][1]`, `x[2][0]` 即 3, 5, 7;
主对角线 `x[i][i]` 才是 159

例4-13: 给 3x3 矩阵做原地转置, 填空
`temp = a[i][j], (17), (18);`

解: (17) `a[i][j] = a[j][i]`, (18) `a[j][i] = temp`.
走到第三步时 `a[i][j]` 已被覆盖, 原值只在 `temp` 里;
内层 `j < i` 保证每对只换一次, 改成 `j < 3` 会换回来

## 4.6 转义序列与 strlen

`strlen` 数到第一个 `'\0'` 为止; 八进制转义最多吃 3 位且只认 0-7,
十六进制转义 `\x` 可以吃多位

(1) `\x1f` 是一个字符, 十六进制 1F 即 31
(2) `\0` 会截断字符串, 后面的字符不计入
(3) `\07` 是八进制转义, 后面的 `8` 是普通字符
(4) `\08` 出现在字符常量里就成多字符常量, 非法
(5) `\\` 是一个反斜杠字符, 它用掉后 `x` 不再构成转义
(6) 字符串字面量末尾自动加 `'\0'`, 所以 `"\\xfds"` 是 5 + 1 = 6 字节
(7) `%s` 遇到 `'\0'` 停止输出

```c
printf("%d", strlen("abcd\x1f\0g"));    /* 4 + 1 = 5 */
printf("%d", strlen("hello\078world!")); /* 5+1+1+6 = 13 */
printf("%d", strlen("\\xfds"));          /* 5 */
sizeof("\\xfds")                         /* 6 字节 */
```

[注意] 数字符串长度前先把它逐字符拆开, 确认哪几位合成了一个转义

例4-14: `strlen("abcd\x1f\0g")` 的返回值是
A. 4  B. 5  C. 6  D. 报错

解: B. `abcd` 四个加上 `\x1f` 一个共 5, 遇到 `\0` 截断, `g` 不计

例4-15: `printf("%d", strlen("hello\078world!"));` 的输出是
A. 13  B. 12  C. 6  D. 5

解: A. `\07` 是一个转义字符, 后面的 `8` 是普通字符,
共 5 + 1 + 1 + 6 = 13

例4-16: `"\\xfds"` 在内存中占用的字节数是
A. 3  B. 4  C. 5  D. 6

解: D. `\\` 一个反斜杠加上 `x f d s` 四个普通字符共 5 个, 加 `'\0'` 得 6;
若写成单反斜杠 `"\xfds"`, `\xfd` 是一个字符, 只剩 2 个字符即 3 字节

例4-17: `char str[] = "ab%d\\tefgh/n\0";`
`printf("%s", str);`
输出
A. `ab%d\tefgh/n`  B. `ab%d\\tefgh/n`  C. `ab%d\tefgh`  D.
`ab\tefgh/n`

解: A. `\\` 是一个反斜杠, 后面的 `t` 只是字母 t, `/n` 是两个普通字符,
`%d` 在实参里也只是两个字面字符, 遇到 `\0` 停止输出

## 4.7 字符串原地逆序

双指针从两端向中间交换, 循环到中点即停;
两个空答案常常完全相同, 因为那就是一次交换的左右两端

(1) 左游标 `i` 从 0 递增, 右游标从 `len-1` 递减
(2) 循环条件写 `i < len/2` 或 `i < j - 1`, 两者都只换到中点
(3) 条件写成 `i < len` 会把换好的又换回去
(4) 若循环里 `j` 也在变, 条件不能用 `i < j/2`, 上界必须是常量
(5) `char str[] = "abcd"` 是数组, 可写; 字符指针指向只读字面量, 不可写
(6) 用 `int` 做倒着数的下标比无符号类型安全, 无符号在 0 处减一会溢出

```c
char str[] = "abcdef", t;
int len = strlen(str);
for (i = 0; i < len / 2; i++) {
    t = str[i];
    str[i] = str[len - i - 1];
    str[len - i - 1] = t;
}
```

[注意] `i < j/2` 看着像"到中点", 但 `j` 每轮变小, 只跑约 len/3 轮,
串只反转一半

例4-18: 把 `"abcd"` 倒序, 填 `int len = (1);`
`for (int i = 0; (2); i++) { t = str[i]; str[i] = (3); (4) = t; }`

解: (1) `strlen(str)`, (2) `i < len/2`, (3) `str[len-i-1]`,
(4) `str[len-i-1]`. 两空相同, 因为这就是一次首尾交换

例4-19: `for (i = 0, j = strlen(str); i < (1); i++, j--)`
`{ m = str[i]; str[i] = (2); str[j-1] = m; }` 中填空

解: (1) `j - 1`, (2) `str[j-1]`. `j` 初值是长度不是末下标,
`j-1` 才是右端; 条件保证奇长度串跳过中间字符, 空串一轮不跑

## 4.8 原地删除与字符统计

"原地删除"用双下标法, `i` 读 `j` 写, 最后补 `'\0'`;
字符计数先把字符映射到 0-25 的桶, 再扫桶求答案

(1) 保留条件成立时 `str[j++] = str[i]`, 循环结束写 `str[j] = '\0'`
(2) `j <= i` 恒成立, 写指针不会超过读指针, 原地覆盖安全
(3) 求最小值初值给足够大的数, 求最大值初值给足够小的数
(4) `scanf("%s", s)` 不写 `&`, 数组名本身就是地址
(5) 计数必须写 `cnt[s[i] - 'a']`, 否则下标是 97 到 122 会越界
(6) 第二趟遍历的是 26 个桶, 不是原串
(7) 求最小值时要加 `cnt[i] > 0`, 否则没出现过的 0 会把答案压到 0
(8) `while (str2[i])` 比每轮调 `strlen` 高效

```c
int i = 0, j = 0;
while (str1[i]) {
    if (!is_char_in_str(str1[i], str2))
        str1[j++] = str1[i];      /* 保留的字符往前挪 */
    i++;
}
str1[j] = '\0';                   /* 不要漏掉 */

int cnt[26] = {0}, res = 1000;
for (i = 0; s[i]; i++) cnt[s[i] - 'a']++;
for (i = 0; i < 26; i++)
    if (cnt[i] < res && cnt[i] > 0) res = cnt[i];
```

[注意] 漏写 `str1[j] = '\0'` 时, `printf("%s")` 会把残留的旧字符也打出来

例4-20: 输入 `str1` 与 `str2`, 删除 `str1` 中所有在 `str2` 出现的字符,
如 `Test is important` 与 `test` 得 `T i imporan`, 补全两个函数

解: `is_char_in_str` 用 `while (str2[i])` 逐个比较, 找到返回 1, 否则返回
0;
`remove_chars_from_str1` 用双下标, 不在 `str2` 中就存到 `str1[j++]`,
最后补 `'\0'`. 空格要保留, 不要一起删

例4-21: 输出字符串中出现次数最少的小写字母的次数, 程序有 5 处错误

解: 第 5 行 `int res = 0;` 改为 `1000`; 第 6 行 `scanf("%s", &s)`
改为 `s`;
第 8 行 `cnt[s[i]]++` 改为 `cnt[s[i]-'a']++`;
第 10 行改成 `for (int i = 0; i < 26; i++)`;
第 11 行改成 `if (cnt[i] < res && cnt[i] > 0)`.
例 `"aassddffd"` 输出 2, `"abbbac"` 输出 1

## 4.9 字符串比较与格式化输出

自己实现 `strcmp` 时, 循环条件是"字符相同且未到末尾";
`%6s` 右对齐补空格, `%-6s` 才是左对齐

(1) 循环条件 `a[i] == b[i] && a[i] != '\0'`, 前者判相同, 后者防越界
(2) `!= 0` 与 `==` 的优先级都高于 `&&`, 不必加括号
(3) 找第一处不同用 `==`, 若写成 `a[i] != b[i]` 则一轮都不执行
(4) 停在第一处不同时, `a[i] - b[i]` 就是两个字符的 ASCII 差
(5) 两串完全相同时停在 `'\0'` 处, 差为 0, 与 `strcmp` 语义一致
(6) 找 `'\0'` 得到的下标 `j` 就是字符串长度, 因为 `'\0'` 不计入
(7) `%6s` 最小宽度 6 右对齐, `%-6s` 左对齐

```c
char a[100] = "Hello World!", b[100] = "Hello Chengdu!";
int i = 0;
while (a[i] == b[i] && a[i] != '\0') i++;
printf("%d", a[i] - b[i]);   /* 'W'(87) - 'C'(67) = 20 */

char s[2][6] = {"Sun", "Moon"};
printf("%6s: %d", s[i], len);   /* 前面补空格, 右对齐 */
```

[注意] 找"第一处不同"要写"相同就继续", 条件是 `==` 而不是 `!=`

例4-22: 程序用内层循环找 `'\0'` 求 `len[i]`, 再 `printf("%6s: %d")`,
`a[2][6]={"Sun","Moon"}`, 输出为

解: 两行 `   Sun: 3` 与 `  Moon: 4`. `'\0'` 的下标就是长度,
`%6s` 使 Sun 前补 3 个空格, Moon 前补 2 个

例4-23: 比较两个字符串, 输出第一处不同字符的 ASCII 差值, 填空
`(13); while ((14)) { i++; } printf("%d", a[i] - b[i]);`

解: (13) `int i = 0;`, (14) `a[i] == b[i] && a[i] != '\0'`.
`i` 停在 6, `a[6]` 是 `'W'`, `b[6]` 是 `'C'`, 输出 20

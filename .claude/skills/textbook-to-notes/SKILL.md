# 输入

开始前确认三件事, 缺哪件就问用户

1. 教材 PDF 的路径, 通常在电子书根目录下, 见 `README.md` 的映射表
2. 要写的章节范围, 例如第 1 章到第 4 章, 或第 7 章
3. 写入的课程目录, 例如 `Coursera/[3]化学/(2)物理化学`

# 第 1 步: 对齐风格

- 读 `STYLES.md`, 逐节确认结构, 标点, 公式, 例题, 插图, 取舍六类规则
- 读同目录里已完成的笔记, 确认三件事
  - 节标题用 `#` 还是 `##`
  - 例题编号与图号的前缀写法
  - 块组之间用不用 `------`
- 同目录没有已完成笔记时, 按 `STYLES.md` 的默认: `#` 级标题
- 定文件清单, 一章一个文件, 命名为 `(N)章节名.md`, `N` 与全书章序一致
- 把这三项结论写进本次记录, 后面的每一步与每个子 agent 的提示词都带上
  不把「用哪个层级」交给子 agent 自行判断

# 第 2 步: 渲染页面

先看目录与页数

```
python .claude/skills/pdf-page-image/scripts/render.py info "<教材.pdf>" --json
```

- 目录不全或没有书签时, 先用 `pdf-bookmark` 补书签, 再回到这一步
- 判定扫描质量, `verdict` 为 `ok` 才继续, 为 `scanned` / `garbled` / `thin` 时先问用户要不要走兜底流程

渲染要写作的页面, 一章一批, 全部放进临时目录

```
$dir = "$env:TEMP\nomad-pdf\<教材名>"
New-Item -ItemType Directory -Force $dir

python .claude/skills/pdf-page-image/scripts/render.py render "<教材.pdf>" `
  --pages 12-45 `
  --out "$dir\ch1.png" `
  --manifest "$dir\ch1.json"
```

- 一次渲染不超过 30 页, 超过就按小节拆成多次
- `--pages` 用 PDF 页码, 不用书页页码, 两者的差由 `pdf-bookmark` 的 offset 决定
- manifest 里记了每页的 y 坐标, 后面裁图直接用它, 不靠目测

# 第 3 步: 读图写作

- 按页读渲染图, 读到哪一节就写哪一节, 不跳着写
- 一篇写完再开下一篇
- 每篇开头空三行, 标题层级按第 1 步的结论
- 公式用单个 `$`, 化学式用 `\ce{}`, 数据表转 Markdown 表格
- 插图位置先写空占位 `![图N-M]()`, 图号沿用教材原图号
- 例题保持原题, 原数据, 原解法, 写在引用块里
- 教材的导语, 史实, 习题不进笔记, 见 `STYLES.md` 的取舍一节
- 每篇写完立刻自检
  - 查全角标点与带圈序号
  - 查超过 60 个字符的行
  - 查图号与例题号有没有跳号或重复

# 第 4 步: 补插图

- 全部章节写完后, 再问用户要不要补图, 不在写作中途插进来
- 用户同意后, 按 `pdf-figure-crop` 从第 2 步的页面图裁出区域
- 图片命名 `fig-<章>-<序号>.png`, 存入 `Annex/assets/<年月>/`
- 把占位换成相对路径, 路径相对笔记文件所在目录
- 裁完抽两三张 Read 一眼, 确认没有裁到图注与相邻段落

# 产物与位置

| 内容               | 位置                                     |
| ------------------ | ---------------------------------------- |
| 笔记               | `Coursera/[N]学科/(N)课程名/(N)章节名.md` |
| 中间渲染图与 manifest | `$env:TEMP\nomad-pdf\<教材名>\`        |
| 最终插图           | `Annex/assets/<年月>/`                   |

临时目录不提交, 不入库
全部完成后可以删掉 `$env:TEMP\nomad-pdf\<教材名>\`

# 注意

- 不在仓库里放教材 PDF
- 不改 `STYLES.md`, 发现规则不合适就在报告里列出来, 由用户决定
- 渲染页数多时用子 agent 并行写不同章, 每个子 agent 的提示词都要带第 1 步的三项结论与本次的文件清单
